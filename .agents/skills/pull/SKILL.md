---
name: pull
description: 멘티가 개발을 시작하거나 최신 원격 main을 받아야 할 때 로컬 main을 안전하게 fast-forward한다.
---

프로젝트 작업을 시작하기 전에 에이전트가 실행합니다. 학생에게 Git 명령을 입력하라고 하지 않습니다. 저장소 루트에서 `python3 scripts/pull_main.py`를 실행하고 결과를 짧게 설명합니다. 이 스크립트는 `origin/main`을 가져온 뒤 로컬 `main`이 뒤처졌을 때만 `--ff-only`로 갱신합니다. 커밋·푸시·강제 갱신은 하지 않습니다.

작업 파일이 수정되어 있거나 Git 충돌 해결 중이면 내용을 보존하고, 현재 상태를 확인해 학생에게 필요한 다음 단계를 안내합니다. 로컬과 원격에 서로 다른 커밋이 있으면 이 스킬에서 rebase나 reset을 하지 않습니다. 어떤 변경이 있는지 확인한 후 `commit-push` 흐름으로 통합합니다. 인증이 필요한 경우 `.env`의 `GH_TOKEN`을 기존 Git 인증 도우미가 사용하며, 토큰을 출력하거나 원격 URL에 넣지 않습니다.

최신 커밋 반영이 완료되면 해당 시점의 작업판과 관련 파일을 읽고 멘티 작업을 이어갑니다. 오프라인이거나 원격 접근이 실패하면 최신 상태를 확인하지 못했다고 분명히 말하고, 오래된 데이터를 최신이라고 가정하지 않습니다.
