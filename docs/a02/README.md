# A-02 카페 폐업 예측 실험 가능성 점검

2026-10-24 · 김선경. 이번 범위는 질문·자료·시점·기준선 설계다. 모델 학습·점수 산출·DB 쓰기 없음. 에이전트 추천안이며 학생의 독립적인 해석으로 기록하지 않는다.

## 질문과 판단

**주변 카페 밀도를 추가하면 기본 정보만 쓸 때보다 카페의 개업 후 365일 내 폐업 신고 예측이 나아지는가?**

현재 자료로는 밀도 추가 실험을 정당하게 검증할 수 없어 보류한다. 상가 자료는 2026년 6월 설정 단면이며 개별 관측일·공개일 열이 없다. 이를 2010~2024년 개업 당시 주변 카페 수로 사용하면 미래 정보가 섞인다. 최신 자료의 정확한 좌표를 확보한 것과 당시 이용 가능했던 정보를 확보한 것은 다르다. 외부에 과거 자료가 전혀 없다는 결론은 아니다.

## 실제 확인한 자료

로컬 가공본 기준일 2026-10-13. 이번에는 DB에 재접속하지 않았다. 상세 수치·입력 해시는 [feasibility.json](feasibility.json).

| 항목 | 건수 / 판단 |
| --- | --- |
| 인허가 카페 | 11,170건: 일반·휴게음식점 중 커피숍/까페 |
| 2010년 이후 개업·365일 추적 가능 후보 | 9,554건 |
| 위 후보의 폐업일 미상 / 날짜 역전 | 각각 0건 |
| 상가 단면의 카페 | 5,513건: cat_s 정확 카페, 인허가와 개별 연결한 수 아님 |
| 과거 시점별 주변 카페 밀도 | 확보·공개시점 확인 안 됨 |

인허가 건수는 과거 개·폐업 기록이며 고유 점포 수가 아니다. 365일 추적 가능은 개업일이 기준일보다 최소 365일 이전이라는 의미다. 신고 지연·정정으로 결과가 변할 수 있으며 미래 스냅샷으로 확인된 실제 예측 성능은 아니다.

## 가능한 예비 실험 추천

밀도 없이 먼저 기본 정보의 기준선을 만든다. 이 실험만으로 원래 질문의 밀도 개선 효과를 답할 수는 없다.

- 관측 단위: 인허가 1건. 예측 시점: 개업 시점. 목표: 365일 이내 폐업 신고 여부. 폐업일·생존일수·현재 상태는 정답 생성에만 사용하고 입력에서 제외.
- 입력 후보: 업태(커피숍/까페), 구군, 개업 월. 현재 좌표로 계산한 주변 밀도·현 상권 구성·현재 생존상태는 제외. 기존 스냅샷의 업태·주소가 개업 당시와 같은지는 미검증이므로 회고적 예비 실험으로 한정.
- 기준선: 학습 구간의 사건 비율을 모두에게 동일하게 예측. 후보: 원핫 인코딩+로지스틱 회귀. 결측 처리·범주 학습은 학습 구간만 사용.
- 시간 분리 초안: 학습 2010~2018년 5,047건, 검증 2020~2021년 1,502건, 최종 시험 2023~2024년 1,078건. 2019·2022년은 365일 결과 관측을 위한 간격으로 제외. 분리 간 같은 건물 반복은 별도 집계하고 신규 건물만의 성능도 비교.
- 지표: Brier 점수·log loss·보정과 ROC-AUC, 구군별 표본 수·오류. 검증 데이터의 사건 양쪽 표본이 충분한지 확인한 후 진행. 최종 시험 점수는 설계 확정 전 열지 않음.
- D-03에서 같은 달력 기간의 일반음식점 시험을 이미 살펴봤으므로 완전히 새롭고 독립적인 시험이라고 주장하지 않는다. 시간순 반복 검증과 후속 미래 자료 확인이 필요하다.

학습·검증·시험의 좌표 누락은 46·15·35건이다. 기본 모형은 좌표를 쓰지 않으므로 이 이유만으로 제외하지 않는다. 전체 9,554건과 세 분할 합계가 다른 이유는 간격 연도와 2025년 일부를 분할에서 제외했기 때문이다.

## 밀도 실험을 재개할 조건

개업 전에 공개된 역사 상가 스냅샷과 해당 시점의 좌표·분류, 학습/검증/시험 기간의 공통 커버리지, 안정적인 인허가 연결 규칙이 필요하다. 확보 후 같은 표본·같은 분할에서 기본 모형과 밀도 추가 모형을 비교한다. 대안으로 현재 시점 자료를 고정하고 이후 365일을 관측하는 전향적 설계도 가능하지만 지금 즉시 성능을 낼 수는 없다.

## 오늘 완료와 다음 단계

가능성 점검·표본 집계·실험 설계 초안 완료. 다음 추천은 기본 정보 기준선과 로지스틱 회귀의 학습/검증 실험이며, 밀도 추가와 서비스 채택은 보류다. 아직 모델 성능 향상이나 폐업 원인을 확인한 결과가 없다.
