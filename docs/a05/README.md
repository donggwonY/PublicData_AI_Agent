# A-05 동네 생활서비스 공백 위험 예측

담당 김선경 · 2026-11-13 · 계획 수립

## 주제와 앱에서의 쓰임

동네에 남아 있는 생활서비스가 앞으로 1년 안에 사라질 위험을 예측하고, 이용자가 가까운 대체 점포를 찾도록 돕는다. 예를 들어 동네에 한 곳 남은 업종을 조회하면 현재 영업 표시 건수, 향후 1년 안에 영업 표시가 0건이 될 위험, 인접 동네의 대체 점포를 함께 보여준다.

예측 단위는 동·읍·면과 업종의 조합이다. E-05가 개별 빈자리의 재입점을 다룬다면, A-05는 주민이 동네에서 특정 서비스를 계속 이용할 수 있는지 판단하는 데 필요한 정보를 다룬다. 42개 업종의 인허가 이력부터 살펴보고, 이용자에게 필요한 정보인지와 검증할 사례가 충분한지를 함께 고려해 첫 업종을 고른다.

공백은 분석 대상 업종에서 해당 지역의 분기 말 영업 표시 인허가가 0건인 상태로 정의한다. 인허가 기록의 범위와 기준일을 화면에 표시하고, 실제 접근성은 인접 지역의 대체 점포까지 확인한다.

## 진행 계획

| 단계 | 할 일 | 산출물 |
| --- | --- | --- |
| 1. 분기별 이력 구성 | 앱의 42개 원천 업종을 대상으로 동·읍·면과 업종별 분기 말 영업 표시 건수를 집계한다. 개·폐업 날짜와 주소 매핑을 점검하고, 관측이 끝난 분기까지 사용한다. | 지역·업종별 분기 집계표와 품질 점검 결과 |
| 2. 공백 사례 집계 | 기준 분기에 영업 표시가 1건 이상인 지역이 이후 4분기 안에 처음 0건이 되는 사례를 찾는다. 같은 공백은 한 번만 세고, 다음 분기에 다시 영업 표시가 생기는 사례와 공백이 이어지는 사례를 구분한다. 추적 기간이 부족한 경우를 따로 표시한다. | 업종별 공백 건수, 관측 가능한 지역·분기 대비 발생률, 지속 기간 비교표 |
| 3. 대상 업종 선택 | 공백이 생기면 이용자가 대체 점포를 찾을 필요가 있는지, 인접 지역의 대체 점포를 조회할 수 있는지, 학습·평가 기간 모두에 공백 사례가 충분한지 확인한다. | 후보 업종 2~3개와 첫 모델 대상 선정 근거 |
| 4. 기준선과 모델 비교 | 현재 한 곳만 남은 지역을 먼저 보는 규칙을 기준선으로 삼는다. 남은 점포 수와 영업 기간, 최근 개·폐업 흐름을 활용한 모델을 과거 자료로 학습하고 이후 기간으로 평가한다. 같은 점검 건수에서 실제 공백 탐지와 오경보를 비교한다. | 기준선·모델 비교표와 오경보 사례 |
| 5. 앱 시안 검증 | 기준선 대비 개선과 점수의 신뢰도를 확인한 뒤 현재 영업 표시 건수, 향후 1년 공백 위험, 인접 지역의 대체 점포를 함께 보여주는 시안을 검토한다. | 앱 시안과 실제 조회 예시 |

첫 산출물은 42개 업종의 공백 건수·발생률·지속 기간 비교표다. 이 표를 바탕으로 첫 모델의 대상 업종과 검증 기간을 정한다. 현재는 계획 단계다.
