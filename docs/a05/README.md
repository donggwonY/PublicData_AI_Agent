# A-05 대구 상권의 업종별 시간대 소비 패턴 예측

담당 김선경 · 주제 및 평가 방향 확정 · 학습용 소비 자료 조사 중

## 연구 질문과 앱 기능

같은 업종으로 창업할 때, 대구의 후보 상권마다 손님이 몰리는 시간대는 어떻게 다를까? 첫 실험은 음식점 한 업종부터 시작한다. 행정동·업종별로 다음 분기 전체 카드매출 금액에서 점심과 저녁이 각각 차지하는 비중을 예측한다. 시간대는 실제 자료의 구간 정의를 확인한 뒤 고정한다.

앱에서 같은 업종과 후보 상권 두 곳을 선택하면 예상 점심·저녁 매출 비중을 나란히 보여준다. 사용자는 운영하려는 시간대에 맞춰 어느 상권부터 더 살펴볼지 판단할 수 있다. 지표의 지역 단위, 카드 자료의 범위, 예측 대상 분기와 기준일을 함께 표시한다. 카드매출 금액 비중은 방문객 수나 신규 점포의 매출액과 구분해 설명한다.

## 단계별 계획과 진척도

| 단계 | 할 일 | 현재 상태 |
| --- | --- | --- |
| 1. 연구 질문과 앱 기능 정의 | 대구 음식점 한 업종의 후보 상권 두 곳을 비교한다. 예측 목표는 다음 분기 점심·저녁 카드매출 금액 비중으로 잡는다. | 완료 |
| 2. 데이터 조사와 확보 | 대구 지역·업종·시간대·기준월이 같은 기록에 들어 있는 시계열을 찾는다. 실제 확보 가능 기간, 시간대 분류, 공개 앱에서의 결과 이용 조건을 확인한다. | 진행 중. 자료 후보는 확인했으나 학습용 시계열은 미확보 |
| 3. 분석용 자료와 기준선 구성 | 동·업종·시간대 정의를 통일하고, 누락·소표본 및 관측 기간을 점검한다. 직전 분기와 전년 같은 분기의 매출 비중을 단순 기준선으로 둔다. | 시작 전 |
| 4. 모델 학습과 시간순 검증 | 계절과 과거 비중을 사용하는 회귀 모델부터 비교한다. 시점이 맞는 경우 역 하차량을 추가했을 때의 개선도 별도로 검증한다. 이전 분기로 학습하고 이후 분기에서 비중 오차를 퍼센트포인트로 평가한다. 비슷한 상권의 비교 결과도 확인한다. | 시작 전 |
| 5. 앱 시안 검증 | 기준선 대비 개선이 확인되면 두 상권 비교 시안을 만든다. 자료 이용 조건과 예측 갱신 가능 여부를 확인하고 앱 반영을 검토한다. | 시작 전 |

## 현재 확인한 자료와 다음 작업

- 대구 빅데이터 활용센터 설명서에서 시간대별 카드 자료를 확인했다. 현대카드 상세 항목의 관측 기간은 2019년 1월~2022년 8월이다. 공개 다운로드로 학습 원본을 확보하지 못했다. [센터 데이터 설명서](https://cfiles.dacon.co.kr/competitions/236548/대구%20빅데이터%20활용센터%20활용%20가능%20데이터%20설명서.pdf)
- 소상공인365는 지역과 업종을 고르면 상권 분석 리포트를 제공한다. 다음 작업은 대구의 두 지역에서 동일 음식점 업종을 조회하고, 시간대별 매출 항목과 과거 기준월 전환이 가능한지 확인하는 것이다. 현재 집계와 과거 시계열의 확보 여부를 구분한다. [공식 상권분석 안내](https://www.data.go.kr/data/15143517/fileData.do)
- 대구교통공사 원본으로 역별 점심·저녁 하차 인원 예측은 별도로 실험했다. 해당 실험의 정답은 실제 역 하차 인원이었다. 하차량은 향후 소비 모델을 위한 보조 변수 후보이며, 지역·업종별 카드매출 비중을 학습하거나 검증한 결과는 아직 없다. [대구교통공사 원본](https://www.data.go.kr/data/15002503/fileData.do)
