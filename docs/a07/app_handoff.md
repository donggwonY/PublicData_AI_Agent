# A-07 앱 연동용 전 연령 예측표

김선경 · 2026-11-17 · 로컬 연동 자료

## 결과 파일

[전 연령 예측표 CSV](population_forecast_2027-10.csv)는 UTF-8 BOM 형식이다. 2026년 10월의 대구 152개 읍·면·동과 12개 인구 집단을 조합한 1,824행을 담았다. 141개 지역의 1,692행에 2027년 10월 예측값을 제공하며, 11개 지역의 132행은 산출을 보류했다. 전체 집단과 0~9세부터 90~99세까지의 10세 단위 집단 및 100세 이상 집단을 제공한다.

| 컬럼 | 형식과 의미 |
| --- | --- |
| `admin_code` | 행정기관코드 10자리 문자열 |
| `admin_area` | 기준월의 광역시·구군·읍면동 명칭 |
| `age_band` | `total`, `age_00_09`~`age_90_99`, `age_100_plus` |
| `base_month`, `target_month` | `YYYY-MM` 형식의 관측월과 12개월 뒤 예측월 |
| `current_population` | 기준월 주민등록 거주자 수 |
| `forecast_population` | 예측월 주민등록 거주자 수 추정치 |
| `forecast_change` | 추정치에서 현재 인구를 뺀 값 |
| `forecast_change_pct` | 현재 인구 대비 증감률(백분율). 현재 인구가 0이면 빈 값 |
| `status` | `available` 또는 `withheld` |
| `withheld_reason` | 보류 시 `incomparable_12_month_history`, 그 외 빈 값 |

## 조회와 표기

- `admin_code + age_band + base_month`로 조회한다. 두 후보지는 같은 기준월과 연령대를 사용한다.
- 카드에는 현재 인구, 1년 뒤 추정 인구, 예상 증감과 기준월을 표시한다. 예측 대상은 행정안전부 주민등록 거주자다. 고객 수 추정과는 범위가 다르다.
- 산출 보류 행에는 현재 인구를 표시하고, “최근 12개월의 비교 가능한 인구 이력이 부족해 예측을 보류했습니다”라고 안내한다. CSV의 빈 값은 결측으로 읽는다.
- 첫 연동 범위는 두 후보지의 수치 비교다. 어느 쪽이 더 많이 늘거나 덜 줄어들지를 판정하는 문구는 후속으로 검토한다.
- 전체 인구와 각 연령대는 별도 릿지 모형이므로 연령대별 추정치의 합과 전체 추정치는 다를 수 있다. 집단별 과거 평가 결과는 [전 연령 검증 기록](README.md#전-연령-확장-2단계-분석표와-모델-검증)에 있다.

## 생성 및 검증

`python scripts/export_a07_all_age_forecast.py`를 저장소 루트에서 실행하면 `output/a07_population_forecast_2027-10.csv`가 생성된다. 공유용 CSV는 그 파일의 줄바꿈을 LF로 통일한 버전이다. 과거 평가와 동일한 입력과 릿지 설정으로 기준월까지 실제값이 알려진 관측을 학습했다. 0~9세의 저장된 예측값과 산출 보류 여부는 기존 고정본과 전체 지역에서 일치했다.
