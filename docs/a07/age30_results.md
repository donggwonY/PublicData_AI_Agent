## 판정: 두 연령대 모두 잠정 반영 기준 미통과
- 새 개발 구간에서 두 연령대 모두 B2가 뽑혔다. 참고 구간에서 B2는 기준선보다는 낫지만 기존 A-07 릿지(R1)보다 오차가 크고, 증감 방향 적중률도 기준선보다 낮다.
- **1단계 새 변수는 도움이 되지 않았다.** 새 변수를 넣은 B3는 새 개발 구간에서 B2보다 나빴다(30대 111.7 대 108.0, 0~9세 72.1 대 70.7). 트리 모델 H3는 더 나빴다.
- **0세 인원으로 출생 유입을 넣은 C3도 C2보다 낫지 않았다**(새 개발 73.9 대 73.5).
- 계획대로 30대·0~9세는 지금 방법(R1)을 유지하고, 두 연령대의 증감 방향 문구는 쓰지 않는다.

## 해석 (검증한 인과는 아니다)
- 가족 이사·구 안의 흐름 같은 변수는 모두 **이미 일어난 변화**다. 30대 이사는 앞으로 생길 입주·전출 같은 일에 좌우되므로, 과거 인구 흐름에서 뽑은 신호로는 미리 알기 어려운 것으로 보인다.
- 30대에서 기준선(지난 1년 증감 반복)의 방향 적중률이 가장 높다. 이사 흐름이 1~2년 이어지는 경우가 많다는 뜻으로 읽힌다(예: 새 단지 입주가 여러 해에 걸침). 크기 예측은 A-07 릿지가 낫고, 방향은 기준선이 낫다.
- 새 개발 구간(2019~2022)은 코로나 시기를 포함한다.
