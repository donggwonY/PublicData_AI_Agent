# A-07 대구 창업 후보지의 배후 거주 인구 변화 예측

담당 김선경 · 2026-11-16 · 5단계 로컬 앱 시안과 연구 결과 정리 완료

## 연구 질문과 앱 화면

창업 후보지 주변의 거주 인구는 1년 뒤 어떻게 달라질까? 대구의 후보 행정동 두 곳과 관심 연령대를 선택하면 최신 공표 인구, 같은 달의 1년 뒤 예상 인구, 예상 증감 인원과 증감률을 나란히 보여준다. 첫 실험은 아동 대상 업종을 예로 들어 0~9세부터 검증한다. 후보지 주변은 해당 행정동 단위로 정의하고, 화면에는 주민등록 인구라는 지표명과 기준월을 표시한다.

첫 실험의 입력과 정답은 주민등록 인구 파일에서 만든다. 행정안전부 조회 화면의 등록구분은 수집 단계에서 하나로 통일한다. 지도 없이 후보 행정동을 선택하는 화면은 원본의 코드와 이름으로 구성할 수 있다.

## 절차와 산출물

1. **원본 확보** — 행안부 월간 조회의 전체읍면동 자료에서 대구를 추린다. 우선 최신월과 1년 전 동일 월을 내려받아 행정동 코드, 0~9세 집계, 등록구분을 확인한 뒤 수집 기간을 넓힌다. 산출물은 원본과 출처·기간 목록이다.
2. **월별 분석표 구성** — 행정동 코드와 기준월로 정렬해 중복, 누락, 연령 합계와 경계 변경을 점검한다. 경계가 달라 비교하기 어려운 관측은 표시하고 첫 평가 범위에서 제외한다. 산출물은 행정동·월별 분석표와 품질 점검표다.
3. **기준선과 평가 구간 고정** — 현재 인구 유지와 직전 12개월의 증감 인원 반복을 기준선으로 둔다. 1세별 자료가 있으면 현재 0~8세가 한 살씩 올라가고 신규 0세가 유입되는 연령 이동 기준선도 검토한다. 최신 12개 관측월을 결과 평가 구간 후보로 두고, 검증용 예측을 만들 때 그 기준월까지 결과가 공표된 학습 사례만 사용한다.
4. **모델 학습과 시간순 평가** — 현재 인구와 최근 3·6·12개월 변화로 12개월 뒤 증감 인원을 추정하는 회귀부터 비교한다. 평균 절대오차(명), 증감 방향 적중률, 학습 전에 고정한 후보지 쌍의 증감 순서 적중률을 보고한다. 작은 동과 큰 동의 오차도 따로 본다. 산출물은 기준선·모델 비교표와 오차 사례다.
5. **앱 시안과 논문 결과 정리** — 기준선 대비 개선을 확인한 모델로 후보지 두 곳의 인구와 예상 변화를 보여주는 시안을 만든다. 개선이 약하면 그 결과와 오차가 큰 동의 특징을 기록하고, 화면의 예측 채택 여부는 검증 결과에 따라 결정한다.

첫 완료 기준은 대구 두 행정동의 동일 연령대 인구를 12개월 간격으로 정확히 연결하고, 연속 시계열을 만들 수 있는 기간과 행정동 범위를 기록하는 것이다.

## 1단계 수집·점검 기록

- 등록구분은 행안부 조회 화면의 **거주자**를 선택했다. 전체읍면동 CSV의 대구 행정기관코드로 추렸고, 시·구·군 집계 행을 읍·면·동 개수에서 제외했다.
- 2025-10은 152개 읍·면·동 135,395명, 2026-10은 152개 읍·면·동 129,004명이었다. 각 월에 0~9세 연령별 합계와 원본 연령구간 인구가 일치했고, 대구의 읍·면·동 합계가 시 집계 행과 일치했다.
- 동일 코드와 명칭으로 151개를 연결했다. 달성군 구지면 `2771038000`과 구지읍 `2771026800`은 해당 월에만 각각 존재해 연결 대상에서 제외했다. 전후 관할 범위는 변경 자료로 확인한다.
- 원본은 Git 제외 경로인 `data/raw/a07_population/`에 있다. `2025-10.csv` SHA-256은 `6977b4c86ca6261ae5b3c5167a30b4c45aa75e6109308ee08dcd2b233ceab367`, `2026-10.csv`는 `00b4d99e7d757ddfb880ae34cb4cae241100c730f9448ee8ea4f6c76edcbdfd5`다. 두 파일의 인코딩은 CP949다.
- 2016-01~2026-10 **130개월**을 44회에 걸쳐 받았다. 장기 자료는 저장 공간을 줄이기 위해 대구 행만 추출했으며, 각 요청 URL과 전국 원본 바이트 SHA-256은 `monthly_sources.json`에 남겼다. 장기 자료에서 확인한 읍·면·동 코드는 총 157개이며, 전 기간에 값이 있는 코드는 136개다. 경계 일치 여부는 2단계에서 확인한다.
- 130개월 모두 읍·면·동 인구 합계가 대구시 집계와 일치했다. `pilot_2025-10_2026-10.csv`에 검증용으로 두 달의 동일 코드 151개와 증감 인원을 저장했다. 장기 자료의 1세 단위 연령 이동 기준선을 실험하려면 해당 연령 자료를 추가 수집해야 한다.

증감 방향은 증가·유지·감소로 비교했다. 순서 적중률은 같은 기준월에서 가능한 행정동 쌍 중 실제 증감 인원이 다른 쌍을 대상으로 하며, 예측 동률은 적중으로 세지 않았다. 인구 유지 기준선은 모든 동에 0명 변화를 예측하므로 순서 적중률은 정의상 0%다. 최종 구간에서 지난 1년 증감 반복은 비교한 133,918쌍 중 110,375쌍의 순서를 맞혔다. 같은 행정동과 쌍이 여러 기준월에 반복되므로 독립 표본 수로 해석할 수 없다.

다음 모델의 비교 기준은 **지난 1년 증감 반복**이다. 모델 후보와 설정은 개발 검증에서 정하고 최종 구간에서는 고정한 모델을 평가한다. 예측을 만드는 각 기준월에는 해당 월 관측치가 공표된 시점까지 결과를 알 수 있는 행만 학습에 사용한다. 최종 구간의 기준선 집계는 이번에 확인했고 모델 점수는 아직 산출하지 않았다.

## 4단계 모델 학습과 시간순 검증

현재 0~9세 인구와 직전 3·6·12개월 증감 인원을 입력으로 사용했다. 목표는 12개월 뒤 인구의 증감 인원이다. 릿지 회귀와 히스토그램 기반 기울기 부스팅을 후보로 두고, 예측 기준월마다 그 달 인구가 공표된 시점까지 결과월이 도달한 행만 학습했다. 예측 인구를 정수로 반올림하고 최솟값을 0명으로 제한했다.

앱 시안 확장 시 네 연령대에는 검증한 증감 순서 문구를 적용할 수 있다. 나머지 집단은 현재 인구·1년 뒤 추정치와 함께 증감 순서의 근거가 부족하다는 안내를 표시하는 안으로 검토한다. 이 결과는 기존 최근 평가 자료를 재사용했으며 반복된 지역 쌍을 독립 표본으로 해석할 수 없다. 새 관측 자료 검증과 전 연령 화면 반영은 다음 단계다.

`python scripts/evaluate_a07_all_age_comparison.py`로 재현한다. 연령대별 차이 구간, 두 방법의 기준 및 표시 건수 대조 결과를 `data/raw/a07_population/all_ages/comparison_evaluation_all_ages.json`에 저장했다.
