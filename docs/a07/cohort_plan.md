# A-07 추가 실험: 코호트 이동 기준선과 보정 모델 (계획, 2026-11-18 고정, 실행 전)

담당 염동권(에이전트 수행) · A-07(김선경)의 추가 실험. 기존 A-07 결과와 파일은 바꾸지 않는다.

## 왜 하는가
A-07 전 연령 릿지는 60·70·80대에서 기준선(지난 1년 증감 반복)보다 인구 평균 오차가 컸다(최근 평가 51.30→52.01, 35.68→39.14, 21.91→31.75명). 지금 모델은 연령대마다 **자기 연령대의 현재 인구와 최근 3·6·12개월 변화만** 입력으로 쓴다(`scripts/evaluate_a07_all_ages.py` `make_examples`). 고령층 변화의 큰 몫은 나이 듦(아래 연령대에서 들어오고 위 연령대로 나감)과 사망인데, 이 정보가 입력에 없다. 인구학의 소지역 추계 방법(Hamilton-Perry 코호트 변화율)으로 이 몫을 먼저 계산하고, 남는 차이만 모델이 배우게 해 전 연령대 예측을 개선할 수 있는지 확인한다.

## 자료와 평가 틀 (A-07과 같음)
- 입력: A-07과 같은 출처의 대구 읍·면·동 월별 연령별 주민등록 **거주자**(2016-01~2026-10, 10세 구간 11개와 전체). 행안부 [연령별 인구현황](https://jumin.mois.go.kr/ageStatMonth.do) 전체읍면동 CSV, 등록구분 거주자.
- 행 사용 규칙: A-07 분석표의 `usable_for_baseline_comparison=1`(관할 변경 제외, 12개월 이력 있음) 행만 쓴다.
- 구간: 개발 기준월 2023-11~2024-10, 최근 평가 기준월 2024-11~2025-10.
- 학습: 기준월 m의 예측은 기준월 ≤ m−12 행(결과가 공표된 행)으로만 학습한다.
- 예측값은 0 이상으로 자르고 반올림한다(A-07과 같음).

## 비교하는 방법
연령대 b(10세 구간), 바로 아래 연령대 b−1, 기준월 t, 행정동 d.

| 이름 | 1년 뒤 인구 예측 |
|---|---|
| R0 기준선 | 지난 1년 증감 반복: P_b(t) + [P_b(t) − P_b(t−12)] (A-07 기준선) |
| R1 A-07 릿지 | 기존 A-07 설정 그대로(자기 연령대 변수만, alpha=10) |
| **C1 코호트 변화율** | 나이 이동 몫 S_b(t) = 0.9·P_b(t) + 0.1·P_{b−1}(t). 지난 1년의 변화율 r = P_b(t) / S_b(t−12). 예측 = S_b(t) × r̂ |
| **B 코호트 + 보정 릿지** | 목표 = 실제 − C1 예측. 입력: 자기 연령대 현재·3/6/12개월 변화, 아래 연령대 현재·12개월 변화, C1 예측, r_동, r_구. 예측 = C1 + 보정 |

- 0~9세는 아래 연령대가 없으므로 S = 0.9·P(t)로 두고 출생 유입은 r에 담는다. 전체 인구는 S = P(t)로 둔다(나이 이동 없음, 변화율 반복).
- 100세 이상은 아래 연령대를 90~99세로 쓴다. 위로 나가는 연령대가 없는 열린 구간이므로 S = P(t) + 0.1·P_{90~99}(t)로 둔다(실행 전 보완, 2026-11-18).
- 입력은 같은 행안부 자료를 다시 내려받아 만든다(사용자 결정, 2026-11-18). A-07 원본 파일과 바이트가 같은지는 확인할 수 없으므로, **행 수(18,863 / 16,292 / 13,832)와 A-07이 발표한 최근 평가 R0·R1 오차 12개 집단을 모두 재현**해야 진행한다.
- 10세 구간 안에서 나이가 고르게 분포한다고 가정한다(0.1 이동). 베이비붐처럼 고르지 않은 구간에서 생기는 오차는 B의 보정이 일부 흡수하는지 본다.
- **작은 동 보정**: r̂ = w·r_동 + (1−w)·r_구, w = S_동(t−12) / (S_동(t−12) + k). k ∈ {0, 100, 1000, ∞}(∞ = 구 비율만). r_구는 같은 구 모든 동의 합으로 계산한다.
- B의 릿지 alpha ∈ {1, 10, 100}. 입력은 표준화한다.

## 선택 규칙 (개발 구간만 사용)
1. 연령대마다 C1의 k를 개발 구간 인구 평균 절대오차로 고른다.
2. 연령대마다 B의 alpha를 같은 방식으로 고른다(C1은 1에서 고른 k 사용).
3. 연령대마다 {R0, R1, C1, B} 중 개발 구간 평균 절대오차가 가장 작은 방법을 **표시 후보**로 정한다.

## 최근 평가 구간 판정
- 보고: 12개 집단 × 4개 방법의 인구 평균 절대오차, 증감 방향 적중률, 후보지 증감 순서 적중률(A-07과 같은 정의).
- **표시 기준(연령대별)**: 표시 후보가 R0보다 평균 절대오차가 작고, 행정동 단위 블록 부트스트랩(1,000회, seed 0) 95% 개선 구간 상한이 0보다 작으면 그 연령대는 앱에 추정치를 표시한다. R0가 표시 후보로 뽑힌 연령대는 추정치를 표시하지 않는다.
- 최근 평가 구간은 A-07에서 이미 여러 번 사용했다. 이번 결과는 독립 시험이 아니며, 2027-10 공표 인구로 다시 검증해야 한다는 점을 결과에 적는다.

## 통과 후 할 일
- 통과한 연령대는 기준월 2026-10 → 2027-10 예측을 같은 방법으로 만든다. 학습은 기준월 ≤ 2025-10 행.
- 앱 표시 범위와 문구는 김선경과 확인한 뒤 정한다.

## 하지 않는 것
기존 A-07 파일·결과 덮어쓰기, 1세 단위 자료 수집(C안), 결과를 본 뒤 후보 설정 추가, DB 적재, 앱 반영.
