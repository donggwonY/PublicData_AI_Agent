30대·0~9세 이사 신호 실험([age30_results.md](age30_results.md))이 1·2단계 모두 통과하지 못한 뒤 정했다.

- 근거: 30대·0~9세는 선택된 방법(R1)의 증감 방향 적중률이 기준선(지난 1년 증감 반복)보다 낮다(30대 62.9% 대 71.4%, 0~9세 81.0% 대 83.6%). 방향은 최근 1년 실제 변화가 이어지는 경우가 더 많았다.
- 30대 추정치는 기준선보다 오차가 작지만 "변화 없음"보다 약 9%만 낫다. 이 한계는 문서에만 남기고 화면에 별도 안내를 띄우지 않는다.
- E-06에서 개업을 "최근 실제 기록"으로 보여 준 것과 같은 원칙이다(예측·과거 기준 범위·실제 기록을 구분).
- 화면에는 "거주자 기준"이라는 점만 밝힌다. 2027-10 공표 인구로 다시 검증하는 일은 내부 계획으로 문서에만 남기고 화면에 띄우지 않는다.

### 화면 카드 변경 (2026-11-18, 염동권)
30대만 따로 카드로 보여 주지 않는다. 카드는 **전체 1년 뒤 추정**, **많이 들어온 연령대**, **많이 나간 연령대** 3개다.
- 들어온·나간 인원은 최근 1년(2025-10 → 2026-10) **나이를 한 살씩 밀어 비교한 순이동**이다. 2026-10에 a세인 인원 − 2025-10에 (a−1)세였던 인원. 나이 드는 효과를 빼서, 연령대 단순 증감보다 이사를 잘 보여 준다(예: 중구 성내1동 30대는 단순 증감 +103명이지만 이사로는 −12명. 20대가 30대로 올라온 효과다).
- 들어온 사람과 나간 사람을 각각 알 수는 없어 "유출입이 많은"이 아니라 "들어온 사람 − 나간 사람"이 큰 연령대로 표시한다.
- 70대 이상은 사망이 섞여 순위에서 빼고 표에 "사망 포함"을 붙인다. 0~9세는 올해 태어난 0세를 빼고 1~9세만 센다. ±10명 미만이면 "뚜렷하지 않음". 보류 11곳은 계산하지 않는다.
- 접기 표는 모든 연령대에 같은 열(현재·1년 뒤 추정·최근 1년 인구 변화. 2026-11-19 열 이름을 '최근 1년 이사로 바뀐 인원'에서 바꾸고 70대 이상 '(사망 포함)' 표시는 표 아래 안내 문구로 옮김)을 둔다. 30대·0~9세의 "최근 1년 실제 변화" 칸은 화면에서 뺐다(예측 증감을 보이지 않는다는 위 원칙은 유지: 표에는 추정 인구만 있고 증감 열이 없다).
- 파일: [net_move_2026-10.csv](net_move_2026-10.csv)(UTF-8 BOM, LF, 152곳 × 11연령대 1,672행, 계산 141곳·보류 11곳), SHA-256 `bafb48a12f356dc5de3f3054196ebd44976c664bf7c55c8b4a217cc8095bc5cf`. 코드: [net_move_2026.py](../../scripts/a07_cohort/net_move_2026.py). 점검: 1세 합계 = 10세 구간 표(cohort_eval.load_single), 모든 계산 지역·0~99세 구간에서 "단순 증감 = 순이동 + 나이 드는 효과(아래에서 들어온 나이 − 위로 나간 나이)" 일치.
