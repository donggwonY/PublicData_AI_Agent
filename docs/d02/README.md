# D-02 분석 정의 감사와 탐색 분석

상태: 완료. 시작일: 2026-10-07. 담당: 김세은.

## 범위와 완료 기준

1. 자리·주소·층·업종 별칭·행정동 매핑 정의를 코드와 표본으로 검증한다.
2. 폐업 상태·공실 후보(90일~3년)·생존 코호트(2010년 이후)와 관측 종료를 검증한다.
3. 정의를 바꾼 민감도 표와 구·동·업종·개업연도별 EDA를 작성한다. 표본 크기·누락률·관측 기간 차이를 표시한다.
4. 학생의 해석과 사용하면 안 되는 경우, 보조 데이터 결합용 키·기준일을 기록한다.

## 완료한 첫 점검

[자리 정의 민감도 보고서](unit_sensitivity.md), [기계 판독 결과](unit_sensitivity.json), 재현 스크립트 `scripts/audit_d02_units.py`.
기준일은 2026-09-23이며 오늘 시점의 실시간 데이터가 아니다. D-01 입력 해시 14개 일치와 기존 자리 결과 대조 3개를 통과했다.

허용 기간 0·30·60·90일을 비교했다. 60일 기준 단일 자리 52,273곳 중 현재 영업 인허가가 여러 개인 곳은 31곳이다. 실제 양도양수 여부는 아직 확인하지 않았다.

## 두 번째 점검

[경계·실제 이력 보고서](boundary_audit.md), [검증 결과](boundary_audit.json). 31곳의 현재 영업 기록 62건을 확인했고, 영업 중 관측 종료를 보존하면 모두 다점포로 바뀌었다. 0일→60일 변경 404곳은 다점포→단일 377곳과 단일→다점포 27곳으로 분해됐다. 역방향 27곳은 당일 기록 최소 1일 처리만으로도 재현됐다. 합성 경계 사례 5개 통과. 실제 양도양수 여부는 미확정이다.

## 세 번째 점검

[폐업·공실·생존 정의 보고서](outcome_audit.md), [검증 결과](outcome_audit.json). 생존 501행·공실 297행 재현 일치. 기준일 2026-09-23, 전체 공실 후보 5,473/46,124자리(11.87%). 대기 기준 30·60·90·180일 민감도와 생존 시작연도 2000·2010·2015·2020 비교를 기록했다. 원본 상태 문자열이 없어 폐업 판정의 원천 타당성은 미검증이다.

## 네 번째 점검

[주소·층·별칭 및 EDA](eda_audit.md), [전체 집계](eda_audit.json). 층 재추출과 80% 보충 uid 전체 일치. 층 보충 기준 60/80/100%에서 자리 수 74,952/76,363/76,884곳. 커피숍·분식의 정확 업태 우선 처리를 확인했다. 지역 결측 포함 구·동·업종·업태·개업연도 표본 합계와 전체 개폐업 사건 합계를 검증했다.

## 다섯 번째 점검

[지역·업종별 사건 연도 비교](annual_comparison.md): 구 523행·동 9,074행·업종 379행을 만들고 각 개업/폐업 총합을 검증했다. 2024~2026년 1월 1일~9월 23일 비교도 포함했다. [정의·사용 제한·팀 전달 문서](handoff.md)에 결합 키·기준일과 잠정 권고를 통합했다.
