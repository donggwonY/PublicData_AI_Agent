## 사용하면 안 되는 경우

- 공실 후보 11.87%를 대구 전체 건물의 실제 공실률로 발표하는 경우.
- 31곳을 근거 없이 오류로 삭제하거나 실제 양도양수라고 확정하는 경우.
- 관측기간이 다른 개업연도 집단의 누적 폐업 비율로 우열을 정하는 경우.

## 학생 해석

김세은 의견 원문:

> 공실 후보율 11.87%는 실제 공실률이라고 보기보다는, 폐업 후 일정 기간 새 영업이 없는 자리의 비율 정도로 설명하면 될 것 같다.
> 31곳은 애매한 경우라서 따로 표시해두고, 포함했을 때와 제외했을 때 결과가 많이 달라지는지만 비교하면 좋을 것 같다.

운영 설명의 정확한 범위: 수집한 업종의 인허가 기록상 영업 중인 기록이 없고 마지막 종료 후 90~1095일 지난 자리의 비율. 분모는 영업 중이거나 마지막 종료 후 1095일 이하인 자리다. 실제 현장 공실·새 영업 부재를 확인했다는 의미가 아니다.

31곳을 별도 표시하고 포함·제외 민감도를 비교하는 방향을 채택한다. 첫 공실 후보율 비교는 포함 11.8658%, 제외 11.8738%로 약 0.0080%p 차이. 후보 분자 5,473곳은 같고 분모만 46,124→46,093으로 바뀐다. 31곳의 전체 인허가 이력은 91건이며 그중 현재 영업 기록은 62건이다. 이 작은 차이를 다른 지역·생존·전이 결과에도 영향이 없다는 뜻으로 일반화하지 않는다.
