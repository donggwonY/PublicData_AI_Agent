# A-08 대구 상권 업종 구성 추정의 공간 단위 비교

담당 김선경 · 2026-11-17 · 구·군·2km 블록 검증, 민감도 비교와 오차 분석 완료

## 연구 질문

일부 지역의 업종 정보가 부족할 때, 주변 상가와 주민등록 인구로 그 지역의 업종 비중을 추정한다면 행정동, 250m 격자, 500m 격자 중 어느 단위가 더 적합할까? 첫 실험은 업종 대분류 10개의 구성비를 추정한다. 분석 대상 상가의 위치와 행정동 코드를 사용하고, 평가 구·군의 업종은 가린다.

## 자료와 첫 실험 설계

| 자료 | 기준월과 사용 범위 |
| --- | --- |
| 소진공 상가업소 공식 파일 | 2026-09 대구 CSV, 116,628개 상가업소, 9개 구·군 |
| 소진공 상가업소 재게시 파일 | 2025-06 대구 CSV, 114,924개 상가업소. 같은 검증을 적용한 참고 시점 |
| 행안부 주민등록 인구 | A-07에서 확보한 같은 달의 행정동 전체 인구와 11개 연령대 비중 |

각 시점에서 상가업소번호는 유일하고, 사용한 좌표 범위와 대구 구·군 코드 검사를 모두 통과했다. 소진공의 8자리 행정동 코드에 00을 붙여 행안부 자료와 연결했으며 두 파일 모두 미연결 행은 0건이다. 면적 격자는 WGS84 점 좌표를 EPSG:5179에 투영한 뒤 250m와 500m로 나눴다. 구·군 경계에 걸치는 격자는 구·군별로 나눴다. [소진공 공식 자료](https://www.data.go.kr/data/15083033/fileData.do) · [2025년 6월 파일 재게시본](https://huggingface.co/datasets/ginipick/market/blob/main/%EC%86%8C%EC%83%81%EA%B3%B5%EC%9D%B8%EC%8B%9C%EC%9E%A5%EC%A7%84%ED%9D%A5%EA%B3%B5%EB%8B%A8_%EC%83%81%EA%B0%80%28%EC%83%81%EA%B6%8C%29%EC%A0%95%EB%B3%B4_%EB%8C%80%EA%B5%AC_202506.csv) · [행안부 인구](https://jumin.mois.go.kr/ageStatMonth.do)

1. 9개 구·군을 하나씩 통째로 평가에 남겼다. 그 구·군의 상가와 같은 500m 칸에 있거나, 평가 상가까지 500m 이내인 외부 상가는 학습과 주변 참조에서 모두 제외했다.
2. 각 공간 단위의 평가 또는 학습 상가 좌표 평균을 기준점으로 삼았다. 주변 업종 비중과 거리는 학습에 남은 자료 중 기준점의 구·군 밖에서 가장 가까운 상가 200개로 계산했다. 인구 변수는 단위에 포함된 상가들에 해당 행정동 값을 붙인 뒤 평균했다. 작은 격자에도 행정동 인구 특성을 사용한다.
3. 릿지 회귀(alpha=100)를 사용해 공간 단위별 업종 비중을 추정했다. 학습 가중치는 단위별 상가 수다. 주변 상가만 쓴 모형과 인구를 추가한 모형을 모두 평가했다. 주 기준선은 해당 평가 구·군을 뺀 학습 상가 전체의 평균 업종 구성이다.
4. 세 모형의 예측을 공통 평가 상가에 적용하고 같은 250m 평가 단위로 다시 묶었다. 구성 오차는 10개 업종 비중의 절대 차이를 더해 절반으로 나눈 값이다. 주 표에는 상가 수 가중 평균을 %로 표시한다. 개별 상가 업종에 배정한 확률은 로그 손실로 별도 평가한다.

이 비교는 완전히 가린 구·군을 외부 구·군 자료로 추정하는 조건에 해당한다. 평가 상가의 위치는 알려져 있고 업종만 가렸으므로, 상가 위치나 개수를 모르는 지역의 업종 구성을 추정하는 경우에는 적용 범위가 달라진다. 두 스냅샷의 상가가 중복될 수 있으므로 독립적인 반복 표본으로 해석하지 않는다. 단일 격자 원점과 한 가지 권역 분리 방식으로 얻은 결과라 공간 단위를 하나로 확정하기 어렵다.

## 2km 블록 검증과 격자 원점 비교

대구 상가를 2km 정사각형 블록으로 묶고, 블록 안 업소들이 같은 평가 묶음에 속하도록 5개 묶음으로 분리했다. 2025-06은 307개 블록·114,924개 상가, 2026-09는 305개 블록·116,628개 상가다. 각 상가의 업종은 한 번씩 평가했다. 평가 상가에서 500m 이내이거나 두 예측 격자 원점 중 하나에서 평가 상가와 같은 500m 칸에 속한 외부 상가를 공통으로 제외했다.

같은 구·군의 상가도 주변 참조에 사용할 수 있도록 했다. 릿지가 학습에 사용할 업종과 주변 업종 특징이 같은 상가에서 나온 경우를 피하기 위해 남은 상가를 상가업소번호 해시로 약 절반씩 나눴다. 한쪽은 적합 대상, 다른 쪽은 200개 최근접 참조 상가를 고르는 데 썼다. 평균 기준선에는 두 집합을 모두 사용했다. 구·군과 행정동 기준선은 각각 상위 지역 분포에 해당하는 가상 관측 100건을 추가해 작은 표본을 보정했다.

예측 단위는 행정동·250m·500m이고, 두 격자의 원점을 각각 동·북 방향으로 125m 옮겨 다시 실험했다. 평가 블록과 **공통 250m 평가 격자의 원점은 고정**했다.

| 방식 | 2025-06 구성 오차 | 2026-09 구성 오차 |
| --- | ---: | ---: |
| 학습지역 전체 평균 | 27.76% | **27.88%** |
| 같은 구·군 평균 | **27.73%** | 28.12% |
| 같은 행정동 평균 | 28.08% | 28.46% |
| 행정동 릿지 · 주변 상가와 인구 | 28.23% | 28.37% |
| 250m 릿지 · 기본 원점 | 30.87% | 30.83% |
| 250m 릿지 · 125m 이동 | 30.54% | 30.72% |
| 500m 릿지 · 기본 원점 | 29.66% | 29.71% |
| 500m 릿지 · 125m 이동 | 30.05% | 30.02% |

릿지의 공간 단위 순위는 두 시점과 두 원점 모두 **행정동, 500m, 250m** 순이었다. 최신 시점에서 행정동 릿지 오차는 전체 평균보다 0.49%p 높았다. 10개 이상 상가를 담은 평가 칸의 동일 가중 오차와 개별 업종 로그 손실도 최신 시점에서는 전체 평균이 가장 낮았다. 구·군 단위 평가와 블록 검증은 가림 범위와 주변 참조 풀의 구성 방식이 함께 달라, 결과 차이를 가림 범위 하나의 효과로 해석하기는 어렵다.

두 시점 모두 모델과 기준선의 평가 칸 수가 일치하고, 학습·참조·제외·평가 행의 합이 원본 행 수와 일치함을 검증했다. 재현 명령은 `python scripts/evaluate_a08_spatial_blocks.py data/raw/a08/daegu_stores_202609.csv 2026-09`이며 2025-06도 같은 방식으로 실행한다. 상세 결과는 `data/raw/a08/spatial_block_evaluation_2026-09.json`과 `spatial_block_evaluation_2025-06.json`에 저장했다. 후속 실험에서 가림 범위의 효과를 비교하려면 주변 참조 구성 방식을 고정한 상태에서 제외 거리만 바꿔 평가한다.

## 평가 상가 주변 제외 거리 비교

2km 평가 블록, 5개 평가 묶음, 두 예측 격자 원점과 상가업소번호 해시로 학습·참조를 나누는 규칙을 고정했다. 평가 상가와 같은 500m 칸의 제외 규칙도 고정했다. 평가 상가까지의 거리 조건만 0·250·500·1,000m로 바꿨다. 0m에서도 동일 좌표와 같은 500m 칸의 상가는 계속 제외된다. 제외 거리가 길어질수록 각 평가 묶음에서 이용 가능한 학습·참조 상가 수가 줄어드는 것을 확인했다. 예를 들어 2026-09에는 0m에서 묶음당 81,098~85,976개였고, 1,000m에서 47,852~57,489개였다.

아래는 같은 250m 평가 격자에서 계산한 상가 수 가중 구성 오차다. 릿지 세 열은 모두 주변 상가와 인구를 사용했으며 격자는 기본 원점이다.

인구를 추가한 릿지의 순서는 양 시점에서 제외 거리와 격자 원점을 바꿔도 행정동, 500m, 250m 순으로 유지됐다. 1,000m에서는 주변 상가만 쓴 행정동 릿지가 인구를 추가한 행정동 릿지보다 소폭 앞섰다. 주 지표에서 가장 우수한 평균 기준선은 2025-06에는 구·군 평균, 2026-09에는 학습지역 전체 평균이었다. 두 시점의 모든 거리에서 가장 낮은 평균 기준선이 모든 릿지 모형보다 낮은 오차를 보였다. 이는 평가한 모델·업종 대분류·공간 분리 조건에서의 결과다.

기존 재현 명령에 `--buffer-meters 0`, `250`, `500`, `1000`을 각각 추가한다. 500m는 기본 파일명이고 다른 조건에는 `_buffer_<거리>m` 접미사가 붙는다. 각 조건의 평가 블록 수·평가 상가 수·평가 칸 수와 원본 해시가 동일함을 확인했다.

업종 표는 **비중 평균 절대오차 / 부호 있는 평균 오차**이며 단위는 %p다. 양수는 과대, 음수는 과소 추정이다. 예를 들어 250m 릿지는 소매를 평균 5.31%p 낮게, 과학·기술을 평균 3.11%p 높게 추정했다. 음식은 부호 있는 오차가 작아도 평균 절대오차는 커서, 칸에 따라 과대·과소 추정이 상쇄될 수 있다. 업종 10개 전체는 결과 JSON에 남겼다.

대표 사례는 상가 50개 이상 칸에서 기준선 대비 오차 차이가 큰 극단값을 골랐다.

- 격자 (4404, 7041), 101개 상가. 실제 음식 비중 17.8%, 250m 모형 52.1%. 구성 오차는 기준선 21.70%, 250m 모형 52.36%였다.
- 격자 (4390, 7056), 1,060개 상가. 실제 소매 비중 93.8%, 기준선 24.4%, 250m 모형 45.5%. 구성 오차는 기준선 69.41%에서 250m 모형 48.26%로 줄었다.
- 격자 (4409, 7051), 179개 상가. 실제 교육 비중 22.3%, 기준선 5.7%, 행정동 모형 17.4%. 구성 오차는 기준선 36.34%에서 행정동 모형 22.50%로 줄었다.

`python scripts/evaluate_a08_spatial_blocks.py data/raw/a08/daegu_stores_202609.csv 2026-09 --error-analysis`로 재현한다. 업종별 오차와 사례 좌표를 `data/raw/a08/spatial_errors_2026-09.json`에 저장했다. 구간별 오차를 상가 수로 가중해 합산한 결과가 기존 종합 오차와 일치함을 확인했다.

## 동일한 평가 블록에서 행정동과 250m 비교

두 기준월의 500m 제외 실험에서 기본 원점과 주변 상가·인구 입력을 사용한 행정동 릿지와 250m 릿지를 비교했다. 같은 2km 평가 블록 안의 공통 250m 평가 칸을 상가 수로 가중해 블록별 오차를 구했다. 아래의 차이는 250m 모형 오차에서 행정동 모형 오차를 뺀 값이다. 양수일수록 행정동 모형의 오차가 작다.

| 기준월 | 평가 블록 | 행정동 우세 | 250m 우세 | 블록별 차이 중앙값 | 전체 상가 수 가중 차이 | 상가 수 상위 10% 블록 제외 후 가중 차이 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 2025-06 | 307 | 207 (67.4%) | 100 | +1.19%p | +2.64%p | +2.35%p |
| 2026-09 | 305 | 189 (62.0%) | 116 | +1.09%p | +2.46%p | +2.02%p |

두 시점 모두 동률은 없었다. 상가가 가장 많은 31개 블록은 각 시점의 전체 상가 중 약 76%를 포함했다. 이 블록들을 제외하고도 행정동 모형의 가중 오차가 더 낮았다. 두 시점 모두 관측된 303개 블록에서 행정동이 두 번 모두 앞선 블록이 149개, 250m가 두 번 모두 앞선 블록이 59개, 앞선 방식이 바뀐 블록이 95개였다. 따라서 전체적으로 행정동이 우세했지만, 개별 블록에서의 우세가 시점에 따라 바뀌는 사례도 있었다.

각 기준월의 `--error-analysis` 결과 JSON의 `paired_blocks`에 블록별 행과 요약을 저장했다. 블록별 상가 수 합계가 기존 평가 표본과 일치하고, 블록별 오차를 다시 가중한 차이가 기존 종합 오차 차이와 일치함을 확인했다. 공간적으로 인접한 블록과 두 시점에 반복 등장하는 상가가 있어 이 결과는 기술통계로 해석한다.
