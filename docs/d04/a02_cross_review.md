# A-02 교차 검토와 A-04 해석 확인

2026-10-30. 김세은 작업에서 에이전트가 수행한 검토 초안. 학생 본인의 독립 검토와 구분한다. 재학습·최종 시험 평가·DB 변경 없음.

A-04의 D-03 해석은 현재 완료 보고의 의도와 일치한다. 같은 기초 RF와 보정 모델을 비교하고, 평균 확률 개선을 개인별 확률 정확성 보장으로 확대하지 않으며, 개선 구간의 0 포함·하위집단 악화·연구용 활용 및 개인별 공개 예측 보류 권고를 유지한다. A-04가 참조한 3개 결과 파일의 해시도 현재 파일과 일치했다. 이후 임대료 공개자료 탐색은 재개했지만 새 모델 성능이나 서비스 채택 결정은 아니다.

A-02는 일반·휴게음식점 중 커피숍/까페 인허가를 대상으로, 가공본 종료 표시가 있고 종료일이 개업일부터 365일 이내인 경우를 사건으로 삼는다. 날짜 역전은 먼저 제외하므로 당일 및 365일째 종료가 포함된다. 현재 가공 코드상 종료에는 폐업·취소·말소가 포함되고 취소일 대체도 가능하므로 실제 사업 실패나 현장 영업 중단과 동일시하지 않는다. 현재 상태·종료일·기간을 입력으로 사용하지 않는 구현을 확인했다.

독립 집계 확인: 검증 2015~2016년 1,352건/201건, 2017~2018년 1,348건/231건, 2020~2021년 1,502건/132건이 저장 결과와 일치했다. 학습은 각각 2010~2013/2010~2015/2010~2018년이며, 학습 마지막 개업일+365일이 검증 첫 개업일보다 앞선다. 학습 건수·사건 수 및 입력 해시도 일치했다. 원핫 인코딩은 학습 구간에서만 적합한다. 2023~2024년은 이번 확인에서도 읽어 평가하거나 라벨을 만들지 않았다.

세 창의 회귀 Brier·log loss가 평균 기준선보다 나쁘다는 저장 수치와 채택 보류 결론은 일치한다. 재학습이나 개별 예측 재현은 수행하지 않았다. 확장형 검증에서 앞선 검증 연도가 후속 학습에 들어가며, 2020~2021은 기존 검증 재사용이다. 365일 간격은 신고 지연·정정이나 당시 입력 정보 가용성을 보장하지 않는다. D-03과 달력 기간이 겹치는 최종 시험을 완전한 신규 독립 증거로 표현하지 않는 제한도 적절하다.

제안: A-02 요약에도 사건을 '폐업·취소·말소를 포함한 가공본의 종료 신고'로 한 번 풀어 쓰면 오해를 줄일 수 있다. 가공 코드·기간 분할과 보고서 사이에서 확인 범위 내 중대한 불일치는 발견하지 못했다. 원천 상태 판정 자체의 정확성은 미검증이다.
