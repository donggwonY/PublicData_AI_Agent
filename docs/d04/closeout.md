## 반복 점검 기준

현재 scripts/audit_d04_*.py, preview_d04_links.py, check_d04_db.py는 이 스냅샷의 재현·검증 도구다. 새 버전에서 기존 해시·행수가 다르면 중단하고 입력 버전과 변화 원인을 먼저 확인한다. 기대값을 자동으로 새 값에 맞춰 덮어쓰지 않는다.

- 차단: 잘못된 DB 대상·쓰기 계정, 동일 버전 비교의 기준일 불일치, 복합키 중복·누락, 다대일 연결 위반·행수 증가, 같은 버전의 로컬/DB 집계 불일치.
- 검토: 업종/지역별 미연결·상태/날짜 변화, 원본 제외 수, 대표 매핑 혼재. 관측된 전체 1.332%를 모든 지역의 허용 임계값으로 쓰지 않는다. 범용 실패율 임계값은 아직 확정하지 않았다.
- 해석: 현재 검증은 집계·키 수준이다. 모든 행의 값·모든 지표·원천 상태의 정확성이나 과거 공간 소속까지 검증하지 않았다.

## 후속으로 남기는 사항

1. 2,518건과 추가 193건의 독립 원본·행정경계 확인 전 운영 보정 보류. 미연결 원본은 삭제하지 않는다.
2. 상태·날짜 108건은 원천 상세 상태·날짜 출처 확인 전 수정 보류. 당일/단기 종료도 자동 제외하지 않는다.
3. 과거·현재 기존 업종 행의 개별 추가·삭제·수정 이력은 이번 집계 분해로 확정하지 않는다.
4. 과거 DB 설계 의도·삭제 가능 여부·생성 코드 미확보 질문은 미확인 유지. 삭제나 외부 자료 요청은 하지 않는다.

위 사항은 해결 완료가 아니라 후속 인계다. 운영 DB·공개 앱·배포는 변경하지 않았다.
