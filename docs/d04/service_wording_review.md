# 서비스 설명 대조 — 2026-11-04

대상: 공실 후보 해석, 폐업 신고와 사업 실패 구분, 원천16업종/분석15그룹 설명. 코드와 로컬 도구를 점검했으며 공개 배포 화면은 확인하지 않았다.

## 변경

- 대시보드와 지역비교 표의 공실률 표기를 인허가 공백 후보율로 수정. 지도·건수에도 같은 용어 적용. 실제 공실·임대 매물 미확인 안내 추가, 방법론의 유효 매물 표현 제거.
- 대시보드의 1년 내 폐업을 1년 내 폐업 신고로 수정. 실제 사업 실패와 다르며 행사장 영업 종료 등이 포함될 수 있음을 설명.
- config.SERVICES는 원천16개이고 서비스 조회는 의원·병원을 각각 유지한다. D-03/D-04 분석 보고서의15그룹은 두 업종을 합친 기준이다. 이를 화면과 README에 명시했다. 서비스 통계가 이미15그룹으로 합쳐져 있다고 주장하지 않는다.
- LLM 도구 설명과 공통 수치 지침의 공실률 용어도 맞췄다. 지표 계산·데이터·DB 필드명은 변경하지 않았다.

## 검증과 남은 범위

서비스 단위검사33개 통과, 로컬 parquet smoke20사례 통과(없는 주소 오류는 기대된 결과). Python 구문 검사 통과. 초기 검사의 로컬 plotly 누락은 requirements의7.1.0 설치로 해결했고 데이터 소스는 parquet로 지정했다. 공개 앱 배포·실제 AI 응답 재검증은 수행하지 않았다. 배포는 담당자 염동권의 범위다.


## 통계 근거 표시 보완 — 2026-11-04

대시보드 1년 내 폐업 신고 수치는 100−KM 1년 생존율로 계산되는 추정치여서 단순 신고건수 비율과 구분하도록 이름·설명을 수정했다. 기준일·지역/업태·인허가 코호트·표본 수를 함께 표시한다. 생존 그래프와 순위에는 KM/중도절단의 쉬운 설명과 최소표본·표시그룹 수를 추가했다. 개폐업 차트에는 비교기간·기준일·폐업 신고 분모를, 지역비교에는 대상/코호트/기준일을 표시한다. 후보 지도에는 전체 후보 수와 조회 목록 수, 좌표 누락 가능성을 표시한다.

검증: 단위33개 통과. 실제 parquet 도구 결과를 사용해 생존곡선·그룹순위·사이클·지역비교4분기의 캡션 필드가 미제공 없이 채워지는 것을 확인했다(Streamlit 출력은 mock, 화면 렌더링 검증과 구분). smoke 실행 exit0. 통계 계산·DB/배포 변경 없음. 앞서 푸시한 표현 수정과 이번 변경을 함께 배포 담당자에게 전달할 예정이다.
