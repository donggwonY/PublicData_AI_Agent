# 7업종과 15업종 연결 실패 비교

현재 가공본을 같은 연결 규칙으로 나눠 비교했다. 의원·병원을 합쳐 원천 16업종을 분석 15업종으로 계산한다. 검토용 주소 보정 후보는 적용하지 않았다.

## 증가분 해석

과거 대비 미연결 증가 1,232건 = 기존 7업종의 순증 11건 + 추가 업종의 미연결 1,221건이다. 기존 업종의 행수도 580건 달라졌으므로 기존 표본이 그대로라고 가정하지 않는다.

비율의 순차 비교: 기존 업종 자료 변화 0.0029%p + 업종 확장 0.4290%p = 전체 변화 0.4319%p. 업종 확장 효과는 현재 7업종을 기준으로 8분석업종을 더한 산술 차이이며 인과효과 추정이 아니다.

과거 manifest와 현재 연결표·맥락표의 바이트 해시 일치: {'legal_admin_map': True, 'area_context': True}. 이 표 자체의 버전 변화와 인허가 자료의 변화는 구분한다. 과거 원본 행과 현재 행을 직접 대조하지 않았으므로 순증을 신규 실패 행수나 시간 경과만의 효과로 해석할 수 없다.
