## 이번 PC의 접속 사전 점검

실제 점검 프로세스 환경변수와 저장소 루트 `.env`를 비밀값 출력 없이 확인했다. `.env`는 읽을 수 있었으나 `APP_DATABASE_URL`과 `APP_READER_DATABASE_URL` 모두 설정되지 않았다. 따라서 실제 프로젝트·계정 권한·현재 버전·스키마 조회는 수행하지 못했다. 다른 프로젝트나 관리자 계정으로 우회하지 않았다.

다음에 필요한 준비: 염동권에게 공유 프로젝트의 읽기 전용 app_reader 접속 정보를 안전한 경로로 받아 이 PC의 Git 제외 `.env`에 설정한다. 대화·문서·커밋에 접속 문자열을 붙이지 않는다. 기존 Git 토큰 등 다른 설정은 보존한다. 이 문서는 요청 초안이며 외부 메시지를 전송하지 않았다.

## 설정 후 한 번에 수행할 비교

1. 프로그램이 실제 선택한 연결 대상이 공유 프로젝트인지 확인하고 읽기 전용 연결로 현재 사용자·권한·스키마·current_version을 확인한다.
2. DB 기준일과 로컬 기준일 2026-10-13, 입력 버전을 비교한다. 다르면 행수 차이를 적재 오류로 단정하지 않고 대응 버전을 먼저 맞춘다.
3. 같은 버전에서 stores 행수 225,858, 복합키 누락·중복, 종료 표시 154,315, 업종별 행수와 행정동 미연결 3,008을 대조한다. 검토용 2,518 후보 연결은 운영 DB 기대값에 섞지 않는다.
4. 결과에는 확인 시점·프로젝트·버전·조회 범위·일치/차이를 기록한다. 접속 문자열·비밀번호는 남기지 않는다. 불일치가 나도 자동 적재·삭제·버전 전환을 하지 않는다.
