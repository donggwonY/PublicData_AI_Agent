# A-01 출구·상가 결합 교차 검토

2026-11-03. 김세은의 요청으로 에이전트가 코드·저장 결과를 검토하고 동대구역을 독립 재계산했다. 학생 본인의 독립 검토, 팀원의 답변 수신 또는 A-04 전체 완료로 표시하지 않는다.

## 판정

확인한 범위에서 집계 불일치를 발견하지 못했다. A-01의 함수는 호출하지 않고 동일 구면 반경(6,371,008.8m)에 atan2 거리 공식을 사용해 로컬 POI와 보유 출구 1·2·3번을 재계산했다. 원본 해시를 두 저장 결과와 대조했다.

| 반경 | 상가 전체/동일행 제거 | 카페 전체/동일행 제거 | 최근접 출구 카페(1/2/3) | 동일행 제거 후 |
| --- | --- | --- | --- | --- |
| 300m | 732 / 724 | 42 / 41 | 3 / 21 / 18 | 3 / 20 / 18 |
| 500m | 1,294 / 1,272 | 72 / 70 | 11 / 38 / 23 | 10 / 37 / 23 |

## 결합·중복 기준

- 출구 중 하나라도 반경 이내면 포함하는 합집합이며, 같은 POI 행을 여러 출구 때문에 중복 합산하지 않는다. 300m 포함집합이 500m에 포함됨을 검증했다.
- 출구별 개별 반경 건수는 겹치므로 합산하면 안 된다. 분포표는 최근접 출구 하나로 배정한다. 동률은 제외·별도 표시하는 구현이며 이번 카페 표본은 동률 0건이다. 최근접 배정 합계가 합집합과 일치했다.
- 카페는 cat_s가 정확히 카페인 행이다. 키워드 부분일치 서비스 도구와 동일한 정의라고 가정하지 않는다.
- 동일행 제거는 상가 원래 모든 열 기준이다. 거리 필터 전후 중복 제거가 이번 자료에서 일치함을 확인했다. 원천 점포 ID가 없어 고유 점포/현재 영업 확인을 대신하지 않는다.
- 전체역 결합 코드는 환승 호선을 묶고 역 사이 중복은 유지·계량하며, 미확인 출구를 0으로 취급하지 않는다. 이 부분은 코드 검토이고 이번에 전체역을 재계산한 것은 아니다.

## 한계와 전달 의견

수치·중복 처리에 대한 수정 요청은 없다. 기존 문서의 직선거리, 출구 자료 시점, 좌표계 datum 미확인, 최신 실제 영업 미확인, 출구별 고객 유입·매출로 해석 불가를 유지해야 한다. 보유 출구 3개가 현재 모든 출구를 완전히 반영한다는 현장 검증은 하지 않았다.

이번은 로컬 스냅샷 대조다. 현재 공유 DB 재접속·현장 좌표 검증·전체역 재계산·실제 AI 응답/지도 재검증은 하지 않았다. DB 과거 검증 기록을 이번 직접 검증으로 표현하지 않는다.

선경님의 D-03 혼합 결과 해석(일부 기간 전체 평균 개선에도 지역별 악화, 일관된 개선으로 보기 어려움)은 기존 D-03 결과와 일치한다. 후속 건물 이력·재표집은 별도 실험이며 선경님이 그것까지 검토했다고 확장하지 않는다. A-02 취소·말소 포함 피드백의 문서 반영도 확인했다.
