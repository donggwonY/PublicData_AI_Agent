# A-04 D-03 데이터·모델 교차 검토

2026-10-30 · 담당 김선경 · 실행·판정 Codex. 학생 본인의 독립 검토나 세은의 답변으로 간주하지 않는다.

## 범위와 결론

[D-03 완료 보고](../d03/closeout.md)의 면적·확률 보정·하위집단·지역/업태 보정 결론을 저장된 JSON 및 구현과 대조했다. 별도 계산 스크립트의 329개 일관성 검사를 통과했다. 이번에 확인한 핵심 주장과 근거 사이의 수치 불일치는 발견하지 못했다. 현재 결과를 연구용 집계로 보존하고 개인별 공개 예측 채택을 보류한다는 권고와 모순되지 않는다.

이번 범위는 저장된 결과의 산술·비교 정의 검토다. 원자료 전체 재수집, 모델 재학습, 개별 예측 재계산, 새로운 지역·업종·기준일에서의 외부 검증은 하지 않았다. A-04의 상호 검토 전체를 완료한 것으로 표시하지 않는다. D-03 원본 보고서는 수정하지 않았다.

## 확인한 내용

| 검토 항목 | 확인 결과 | 해석 |
| --- | --- | --- |
| 평가 표본 일치 | 보정 비교 4모델 모두 1,608건·168건 신고, 실제 10.4478% | 같은 표본 비교임을 저장 집계에서 확인 |
| 보정 효과의 비교 대상 | 같은 기초 RF의 Brier 0.090100 → 보정 후 0.084253 | 전체 기간 학습 RF 0.084579와 비교해 보정 효과라고 부르면 안 됨 |
| 평균 확률 | 같은 기초 RF 7.5112% → 보정 후 9.9942%, 실제 10.4478% | 평균이 가까워졌다고 개별 확률 정확성이나 미래 성능이 입증되지는 않음 |
| 개선 불확실성 | Brier 차이 -0.005847, 저장된 95% 재표집 구간 -0.019042~0.002194 | 0 포함. 안정적인 개선으로 단정하지 않는 보고서 표현과 일치 |
| 하위집단 합계 | 업태 19·구군 9·면적 5그룹 각각 표본·사건 합계 및 가중 지표가 전체와 일치 | 보정 후 Brier 악화는 11/19·6/9·3/5로 재확인 |
| 시간별 지역 보정 | 2015~2016만 전체 보정보다 Brier와 log loss 개선; 나머지 두 기간 악화 | 3기간·두 전체 기준선 공통 통과 후보 없음 재확인 |
| 평가 설계 구현 | 학습→보정→평가 사이 365일 추적 간격 assertion, 보정 표본에서만 범주 인코더 fit 확인 | 코드 정적 검토이며 이번에 재학습 실행한 것은 아님 |
| 사건 정의 | 개업 후 365일 내 폐업·취소·말소 신고 | 실제 사업 실패·현장 공실·매출 감소와 구별해야 함 |

AUC는 집단별 값을 표본 수로 가중 평균해 전체와 비교하지 않았다. Brier·log loss·실제 비율·예측 평균만 가중 합계를 검증했다. 저장된 신뢰구간은 차이와 0 포함 여부를 확인했으며 재표집 자체를 다시 수행하지 않았다.

## 남은 한계와 질문 초안

1. **서비스 표현 범위:** 연구용 집계 화면에 결과와 한계를 표시하는 수준으로 우선 마무리할지 팀 결정이 필요하다. 이번 검토는 공개 앱 적용 승인이나 성능 보장이 아니다.
2. **당시 입력 정보:** 현재 면적·주소가 개업 당시와 동일한지 미확인이라는 한계는 유지한다. 향후 예측을 재개할 때 확보해야 할 과거 자료·공개 시점을 명시할 필요가 있다. 기존 자료 요청 보류 결정을 바꾸거나 새 요청을 보내지 않았다.
3. **한시영업:** 집중 사례를 단기 행사·팝업으로 의심할 수 있어도 전체 오차 원인으로 확정하거나 자동 제외할 수 없다. 개별 허가 근거와 예측 시점 가용성 확인 전에는 삭제·재학습하지 않는 현재 원칙이 적절하다.
4. **상호 검토:** 2026-11-02 사용자가 전달한 세은의 A-02 검토 답변을 아래에 기록했다. A-01 결합에 대한 별도 피드백과 김선경 본인의 사용성 의견은 확인되지 않았다.

현재 첫 상호 검토의 답변 수신·문구 보완까지 완료했다. 기존 329개 검사는 10월 30일 당시 저장 결과에 대한 검사이며 이후 D-03의 새 모델 혼합·건물 이력 실험까지 검증한 것으로 확장하지 않는다. 새 지역·업종·기준일 검증 및 A-01 상호 검토는 이번 범위 밖이다. 모델 재학습·DB·서비스 배포는 변경하지 않았다.

## D-03 혼합 모델 후속 교차 검토 — 2026-11-02

질문: 전체 평균의 소폭 개선이 지역·업태·기간에 걸쳐 일관되는가?

[혼합 모델 저장 결과](../d03/ensemble_results.json)를 별도 스크립트 `scripts/audit_a04_ensemble.py`로 대조했다. [검사 결과](ensemble_review.json): 1,181개 일관성 검사 통과. 하위집단 사건 수를 의도적으로 1건 바꾼 복사본은 검사에서 거부했다. 원본은 변경하지 않았다.

| 검증 기간 | 표본 / 사건 | 로지스틱 혼합 Brier 차이 | 구군 악화 | 업태 악화 |
| --- | ---: | ---: | ---: | ---: |
| 2015–2016 | 5,328 / 317 | +0.00002001 | 5/9 | 11/23 |
| 2017–2018 | 5,552 / 421 | -0.00000239 | 5/9 | 9/21 |
| 2020–2021 | 5,558 / 386 | -0.00008467 | 6/9 | 8/21 |

비교 대상은 `global_regularized`이며 차이는 혼합 모델 - 비교 대상이다. 음수는 오차 감소다. 전체 오차가 줄어든 기간에도 구군 다수에서 오차가 증가한다. 모든 과거 기간에서 두 RF 보정 기준선보다 Brier·log loss가 모두 낮은 후보는 없다는 D-03 결론과 일치한다. 유의성·미래 성능·개별 예측 정확성의 증거로 해석하지 않는다.

검사 범위: 모델 간 표본·사건 수, 구군/업태 집단 키 중복, 전체와 집단 표본·사건 합계, 가중 Brier/log loss/평균확률/실제비율, 저장된 연도 분할의 관찰 간격, 후보 통과 판정. AUC는 집단 가중 평균하지 않았다. 실제 행별 날짜의 365일 경계, 모델 재학습, 새 기준일 데이터, 건물 이력 후속 실험은 이번 검사 대상이 아니다. 기존 모델의 새로운 업종 일반화 실험도 아니며, 기존 평가 표본의 업태별 결과를 대조한 것이다.
