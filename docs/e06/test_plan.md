# E-06 시험 구간 평가 계획 (2026-11-15 고정, 시험 구간을 열기 전)

시험 구간은 **목표 연도 2023·2024·2025**다. 입력 기준일은 2026-11-06이라 2025년 사건은 한 해가 모두 관측되어 있다. 2026년 사건은 쓰지 않는다. 이 평가는 **한 번만** 실행한다. 결과를 본 뒤 설정을 바꾸지 않는다. 오류 수정으로 다시 실행하면 그 사실과 이유를 기록한다.

## 고정한 서비스 구성 (검증까지의 결정 그대로)
| 항목 | 구성 |
|---|---|
| 1층 폐업 | **G1 포아송 회귀(L2, λ=0.3)**. 변수는 [models.py](../../scripts/e06_competition/models.py)와 같다 |
| 1층 개업 | B2(직전 3년 평균) |
| 2층 개업 | B4(구 B2 × 동의 과거 5년 개업 점유율) |
| 2층 폐업 | 구 G1 폐업 × 같은 점유율 |
| 순증감 | 개업 예측 − 폐업 예측 |
| 80% 범위 | 1층 폐업: 포아송. 개업(두 층): 음이항, α는 목표 연도 ≤ y−1 행의 기준선 잔차로 적률 추정 |
| 업종별 단위 | [models.json](results/models.json) `industry_units`의 개발 구간 결정을 그대로 쓴다(동 6 / 구 39 / 대구 추세만 77). 다시 계산하지 않는다 |
| 방향 표시 후보 | 경양식·일식(구) |
| 선택 후보 | 주점 묶음(동) |

- 학습은 검증과 같은 시점 이동 방식이다. 시험 연도 y의 G1은 목표 연도 2010 … y−1 행으로 학습한다. 그래서 2024년 모델은 2023년 실제값을 학습에 쓴다. 매년 갱신하는 운영 방식을 흉내 낸 것이다.
- **사전 점검**: 같은 스크립트로 검증 연도(2020–22) G1 폐업 MAE를 다시 계산한다. 2.5035가 나와야 시험 계산을 진행한다.
- G2(LightGBM) 폐업은 참고 수치로만 보고한다. 결정에는 쓰지 않는다.

## 판정 기준
| 대상 | 통과 조건 | 통과하면 |
|---|---|---|
| 1층 폐업 G1 | ① 2023·24·25 모두 B1·B2·B3보다 MAE 작음 ② 연도×업종 블록 부트스트랩(1,000회) 95% 개선 구간 상한 < 0 ③ 포아송 80% 적중 75–85% | 서비스 후보 확정 |
| 개업 범위(업종별 혼합 단위) | 음이항 80% 적중(동 칸 수 가중) 75–85% | 범위 표시 확정 |
| 개업 층별 | 1층 B2·2층 B4 각각 음이항 80% 적중 | 보고만 |
| 방향 표시(경양식·일식) | 시험 방향 정확도 ≥ 65% 그리고 다수 방향 + 5%p 이상 | 해당 업종 방향 표시 확정 |
| 주점 묶음(동) | 음이항 80% 적중 75–85% | 선택 후보 유지 |

- 다른 업종의 방향 정확도, 모든 업종을 동으로 할 때와 혼합 단위의 비교는 보고만 한다.
- 통과하지 못한 항목은 서비스에 쓰지 않는다. 같은 시험 구간으로 다시 조정하지 않는다.

## 하지 않는 것
DB 적재, 앱 반영, 시험 결과를 본 뒤의 재조정.
