## 2. 입력 변수 (모두 이어받은 가게 개업 시점에 알 수 있는 것)

- **이어받는 쪽**: 업종(인허가), 업태, 면적, 층 구분, 구, 개업 월.
  - 업종·업태는 창업자가 정한 계획이다. 면적은 계약 때 알 수 있다.
- **직전 가게**:
  - 업태, 같은 업태로 이어받는지 여부, 영업 기간(직전 가게 인허가일부터 min(폐업일, 이어받은 가게 개업일)까지)
  - 면적, 겸업 인허가 수
  - 폐업과 개업의 간격, 겹침 여부(간격 ≤ 0)
- **자리 이력**: E-05 `history_features`를 예측 시점 = 개업일 − 1일로 다시 계산한다(이어받은 가게 자신은 들어가지 않음).
  - 과거 가게 수, 교체 횟수, 평균 공실 기간, 첫 개업 이후 연수, 업종 다양성
- **주변·동·지하철·인구**: E-05 함수로 예측 시점 = 개업일(직전 달 말 상태)로 다시 계산한다. 겹침 사례에서 폐업일 기준 값에 이어받은 가게가 섞이지 않게 하기 위해서다.
  - 반경 약 300m 영업·개폐업·같은 묶음·공실
  - 동 공실률·3년 변화, 지하철 거리·승차, 행정동 인구·연령 비중·변화
- **쓰지 않는 것**: 이어받은 가게의 폐업일·현재 상태·영업 기간(정답), 상호(사업자 동일성 확정 불가).

## 3. 기준선과 모델

- **B1 업종 평균**: 학습 구간 업종(인허가)별 3년 안 폐업 비율. 30건 미만인 업종은 묶음(E-05 11개) 평균, 그것도 없으면 전체 평균을 쓴다.
- **B2 업종 × 직전 가게 영업 기간 구간**: 구간은 ≤1년, 1~3년, 3~10년, >10년이다. 칸 표본이 30건 미만이면 B1과 섞는다(가중 n/30).
- **M1**: 로지스틱 회귀(L2, 표준화, 결측 표시). **M2**: LightGBM. 전처리·격자는 E-08·E-09와 같은 방식이다.
- **조정**: 학습 구간 안 시간 분할(개업 2012–2016 학습 → 2017–2018 확인)로만 한다. 검증 구간은 비교에만 쓴다.
- **최종 평가**: 최종 모델과 기준선은 학습+검증으로 다시 만들고, 평가 구간은 한 번만 본다.
- **환경**: `C:\claude_workspace\e06_env`.

## 4. 평가와 채택 기준

- **주 지표**: Brier. **보조**: AUC, 로그 손실, 보정 곡선(10구간). 신뢰구간은 자리 단위 부트스트랩 1,000회로 구한다.
- **선택**: 검증 구간에서 B1·B2 중 Brier가 낮은 것을 비교 기준선으로, M1·M2 중 Brier가 낮은 것을 후보 모델로 정한다.
- **채택(평가 구간)**: 두 조건을 모두 만족해야 한다.
  - 후보 모델의 Brier가 비교 기준선보다 낮을 것(차이 95% 구간 상한 < 0)
  - AUC가 0.02 이상 높을 것
- **미달하면**: "업종(× 직전 영업 기간) 평균으로 충분하다"를 결론으로 보고한다.
- **오류 분석**: 업종별, 직전 가게 영업 기간 구간별, 자리 교체 횟수별, 구별, 개업 연도별, 겹침 여부별로 본다.
- **보정 확인**: 시기별 업종 구성 차이(담배 비중) 때문에 평균 예측과 실제 비율의 차이를 따로 확인한다.
- **누수 테스트**: 별도 단계는 두지 않는다. 변수 계산을 예측 시점 기준으로 하고, 이어받은 가게 자신이 변수에 들어가지 않는지 코드에서 확인(assert)한다.
