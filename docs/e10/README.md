# E-10 같은 업종 인수 창업 — 0단계 자료 확인

담당 염동권 · 2026-11-19 · [작업판](../WORKBOARD.md) E-10

창업자 질문: "문 닫는(닫은) 이 가게 자리를 **같은 업종으로 이어받아** 시작하면 얼마나 버틸까? 이전 가게의 이력이 판단에 도움이 될까?"

이 문서는 모델을 만들기 전에 자료만 확인한 기록이다. 정답·입력·평가 계획은 다음 단계(계획 고정)에서 정한다. 수치는 Python 계산 결과이고, 보정하지 않은 단순 비교다.

## 1. 자료와 정의

**자료**
- E-03에서 만든 사례 표(`C:/claude_workspace/e05_data/serve/asof_episodes_2026.parquet`, 저장소 밖)를 그대로 쓴다.
  - 점포형 42종, 단독 자리, 2012~2026년 폐업 35,113건(일괄 등록 중도절단 제외)
  - 같은 자리의 다음 가게와 그 가게의 영업 기간은 E-05 고정 빌드(기준일 2026-11-06)에서 가져온다.

**이어받기(인수) 정의**
- 같은 자리의 다음 가게가 **같은 인허가 업종**이고, 폐업일 기준 −60~+90일 안에 인허가를 받은 경우다.
- 겹침 −60일은 양도 때 새 인허가가 먼저 나는 경우를 허용한 것으로, 서비스·E-05와 같은 기준이다.

**데이터로 볼 수 없는 것**
- 식품위생법의 "영업자 지위승계"는 기존 인허가 번호가 그대로 이어진다. 그래서 인허가 자료에서는 **새 가게로 보이지 않는다.**
  - 이 자료에서 잡히는 이어받기는 "폐업 신고 → 같은 업종 새 신고" 방식뿐이다.
  - 한 가게의 영업 기간 안에 지위승계로 바뀐 주인이 섞여 있을 수 있다.
- 상호가 같다고 같은 사업자로 확정할 수도 없다([D-01](../d01/update_comparison.md), [D-02](../d02/boundary_audit.md)).

## 2. 확인 결과

**이어받기 규모**
- 다음 가게가 들어온 14,745건 가운데 같은 업종이 90일 안에 이어받은 경우가 **5,330건**이다. 전체 폐업의 15.2%이고, 폐업 연도별로 240~462건이다.
  - 같은 업태(예: 한식 → 한식)까지 같은 경우: 3,572건
  - 새 인허가가 폐업보다 먼저 난 경우(겹침): 907건
  - 상호까지 같은 경우: 18.8%
- 업종별: 일반음식점 2,246, 담배소매 1,401, 미용 580, 휴게음식점 540, 즉석판매 167.

**이어받은 가게의 생존 (2023-11 이전 개업, 3년 추적 가능)**

| --- | ---: | ---: |

| 그 밖의 다음 가게 (3년 7,200곳) | 88.4% | 67.7% |

  - 일반음식점 71.3% / 71.8%: 차이 없음

  - 3년 안 폐업 비율은 연도별 29.7~45.0%로 한쪽에 치우치지 않는다.

## 3. 판단

- **"이어받은 가게가 3년 안에 닫는가"는 예측 문제로 세울 수 있다.** 표본 4,328건에 양성 30~45%다.
- **기존 D-03(개별 생존 예측)과의 차이**:
  - D-03은 일반음식점 개업 후 1년 폐업을 업태·구·개업 월로 예측했고 AUC 0.51~0.62에 머물렀다.
  - E-10은 대상을 이어받기로 좁히고, D-03에 없던 **직전 가게·자리 이력**을 핵심 입력으로 쓴다.
- **비교 기준은 높다.** 업종 평균만으로 AUC 0.62가 나온다. 모델 채택 기준은 이 기준선보다 확실히 나아야 한다.
- **서비스에서 쓰는 방식**: 자리 이력 화면 또는 AI 상담에서 "이 자리를 같은 업종으로 이어받으면 3년 안 폐업 위험이 같은 업종 평균보다 높은/낮은 편"으로 쓴다. 대상은 폐업 직전·직후 자리다.

## 다음 단계

**계획 고정(추천안)**

- **모델**: 로지스틱 회귀, LightGBM
- **기간 나누기**(개업 연도)
