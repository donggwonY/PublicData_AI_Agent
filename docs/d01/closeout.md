## 미해결 항목을 남기고 종료하는 근거

- 원본 CSV가 없어 CP949 인코딩·원천 컬럼 차이·정제에서 제외된 행은 독립 재현하지 못했다. 현재 Parquet에서 확인 가능한 사실과 구분했다.
- POI 완전 중복 초과 673행은 원천 ID가 없어 원인을 확정하지 못했다. 원본 확보 후 검증할 항목이며 임의 삭제하지 않았다.
- 남구 407건은 연결 보정 후보이나 과거 행정 경계 검증은 남았다. 2건의 비정상 주소는 공식 주소 확인이 필요하다. 전체 실패 1,776건의 모든 원인을 이번 범위에서 분류한 것은 아니다.
- 보조 자료별 기준월이 다르고 일부 원본 출처/정확한 수집일은 미확정이다. 인허가 기준일을 모든 보조 자료의 기준일로 쓰지 않는다.
- 대표 매핑 사용 108,328행은 오배정 확정 건수가 아니다. 실패율 외에도 위치 배정 정확도와 편향을 D-02/보조 데이터 분석에서 고려한다.

## 다음 작업

D-02에서는 자리·폐업·공실·생존 정의를 표본과 민감도 분석으로 검증한다. 시작 후보는 단일 자리 판정에 쓰는 60일 허용 규칙과 다점포 주소의 영향이다. D-02는 아직 시작/완료 처리하지 않았다.

실시간 갱신 관련 API 실험·장애 복구 실험은 부록 성격의 후속 산출물이다. D-01 완료를 위해 운영 자동화·배포·DB 이전까지 진행하지 않는다.

현재 완료 상태는 로컬 작업판에 반영했다. 미커밋 파일 때문에 pull이 중단되어 원격 최신 상태를 새로 확인하지 못했으며, 원격 커밋/푸시는 하지 않았다. 이전 개별 실험 문서의 ‘진행 중’ 표기는 당시 기록이고 현재 상태는 이 완료 보고서와 WORKBOARD를 따른다.
