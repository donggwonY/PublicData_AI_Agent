## 재현

허브 저장소와 데모 저장소를 같은 상위 폴더에 둔다. Python 3.12 환경에 pandas 3.0.1, pyarrow 24.0.0이 필요하다. 이는 읽기 전용 프로파일링에 검증한 버전이며 데모 배치/배포 환경과 같다고 주장하지 않는다.

```powershell
python scripts/profile_data.py --demo ../daegu_lifecycle_agent --output docs/d01
python scripts/audit_joins.py
python scripts/finish_d01.py
```

실제 이 PC에서는 기본 python 명령이 없어 앱 제공 Python 3.12.14를 사용했다. 상위 폴더의 `.d01-packages`를 PYTHONPATH에 추가해 pyarrow를 읽었다. 패키지 설치 폴더 접근 권한 때문에 사용자 권한으로 실행했으며, 실행 종료 코드 0과 검사 10개 통과를 확인했다. 원본 데이터와 앱 파일은 변경하지 않았다.

스크립트는 원본 데이터를 읽고 각각의 보고서/JSON만 생성한다. 보고서의 표본은 조건을 만족하는 앞부분 행이며 무작위 대표 표본이 아니다. 원본 CSV가 없어 정제 과정에서 제외된 행은 독립 재검증할 수 없다.
