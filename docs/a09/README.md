# A-09 대구 유사 상권 추천

담당 김선경 · 2026-11-17 · 창업 목적별 추천 비교와 로컬 시안 검증 완료

## 질문과 화면

창업자가 지금 보고 있는 대구 읍·면·동과 업종 구성 및 배후 거주 인구의 연령 분포가 비슷한 곳은 어디일까? 기준 상권을 한 곳 선택하면 비슷한 읍·면·동 5곳을 추천하고, 각 후보지의 주요 업종과 연령대 비중을 나란히 보여준다. 상가 수와 거주 인구 수도 함께 표시해 비율과 규모를 같이 읽을 수 있게 한다.

## 자료와 추천 방식

A-08의 2025-06·2026-09 대구 상가 파일과 A-07의 같은 월 읍·면·동별 주민등록 거주자 자료를 재사용했다. 소진공 업종 대분류 10개의 상가 비중과 행안부 11개 연령 구간의 인구 비중을 사용했다. 초기 추천 실험은 상가 50개 이상인 동을 대상으로 정했다. 2026-09에 146곳이 이 기준을 충족했다. 구지면의 기존 코드는 해당 월에 등록 인구가 0명이라 연령 비중을 구할 수 없었고, 해당 코드로 기록된 상가 674개는 추천 프로필에서 제외했다. 새 코드와의 합산은 별도 검토한다. [소진공 상가업소 자료](https://www.data.go.kr/data/15083033/fileData.do) · [행안부 인구 자료](https://jumin.mois.go.kr/ageStatMonth.do)

업종과 연령을 각각 전체가 1이 되는 비중으로 바꾼 뒤, 각 분포에 제곱 헬링거 거리를 적용했다. 두 거리의 평균이 작은 순서로 후보지 5곳을 고르고 자기 자신은 제외했다. 가중치 50:50은 첫 시안의 설정이며 학습된 값은 아니다. 전체 상가 수와 총인구는 화면에서 비교할 수 있으나 순위 점수에는 넣지 않았다. 상가와 거주 인구의 구성이 비슷하면 규모가 다른 동도 추천될 수 있다.

## 두 시점의 추천 목록 비교

두 달에 공통으로 조건을 충족한 146곳을 같은 후보 목록으로 사용했다. 2025-06과 2026-09의 상위 5곳 목록에서 일치한 후보 수를 비교했다.

| 추천에 쓴 정보 | 상위 5곳 중 평균 유지 | 3곳 이상 유지한 기준 상권 | 1순위 유지 |
| --- | ---: | ---: | ---: |
| 업종과 연령 분포 | 3.76곳 | 95.21% | 63.01% |
| 업종 분포 | 3.66곳 | 89.73% | 56.16% |
| 연령 분포 | 3.86곳 | 94.52% | 61.64% |

추천 목록의 변동성을 본 결과다. 안정성 수치로 창업 적합성이나 추천의 실제 유용성을 판단하기 어렵다. 두 시점의 상가에는 같은 업소가 포함될 수 있다.

2026-09의 **중구 성내1동**을 기준으로 하면 성내2동, 삼덕동, 산격3동, 대명2동, 대명5동 순으로 나왔다. 성내1동은 음식 30.2%, 소매 35.8%, 거주자 중 20대 30.4%였고, 1순위 성내2동은 음식 29.7%, 소매 40.2%, 20대 19.9%였다. 전체 분포로 순위를 매기므로 추천 지역과 기준 지역 사이에 차이가 큰 항목도 있을 수 있다. 시안에서는 분야별 비중이 큰 항목 네 개를 두 지역 수치와 함께 보여준다.

## 재현과 다음 작업

1. `python scripts/evaluate_a09_similar_areas.py`로 `data/raw/a09/similar_areas.json`을 생성한다.
2. `python scripts/build_a09_preview.py`로 `output/a09_similar_areas_preview.html`을 생성한다.

146개 추천 목록에서 자기 자신 제외, 추천 중복 없음, 업종·연령 분포 합계 1을 검사했다. Chrome 헤드리스에서 상권 선택을 바꾸면 추천 5곳과 비교표가 갱신되는지 확인했다. 운영 앱 연동은 별도이며, 다음 단계는 창업 목적이 다른 사례에서 상가·인구 규모를 추가 비교하는 옵션과 추천 이유가 유용한지 확인하는 것이다.

## 창업 목적별 추천 비교

2026-09 기준 상권 146곳 각각에서 기본 추천과 음식업 비중, 0~9세 거주자 비중, 규모를 우선한 추천을 비교했다. 우선 항목별 후보 순위에 65%, 기본 구성 유사도 순위에 35%를 둔 첫 시안이다. 가중치는 초기 설정이며 사용자 평가로 정한 값은 아니다. 규모 차이는 상가 수와 거주자 수 각각의 절대 차이를 두 지역 중 더 큰 값으로 나눈 비율의 평균이다.

| 추천 기준 | 음식업 비중 차이 | 0~9세 비중 차이 | 규모 차이 |
| --- | ---: | ---: | ---: |
| 기본 | 3.97%p | 1.27%p | 33.88% |
| 음식업 우선 | **1.11%p** | 1.70%p | 36.21% |
| 0~9세 우선 | 5.35%p | **0.37%p** | 35.50% |
| 규모 우선 | 5.16%p | 1.60%p | **15.90%** |

표는 각 기준 상권에서 선택한 상위 5곳의 차이를 평균한 값이다. 우선한 항목의 차이는 줄었으나 다른 항목과 전체 구성 거리에서는 차이가 커지는 경우가 있었다. 추천 규칙이 의도한 특성을 반영하는지 확인한 결과다. 실제 창업 성과나 사용자 선호는 평가하지 않았다.

| 기준 상권 | 기본 1순위 | 음식업 우선 1순위 | 0~9세 우선 1순위 | 규모 우선 1순위 |
| --- | --- | --- | --- | --- |
| 중구 성내1동 | 중구 성내2동 | 중구 성내2동 | 달서구 신당동 | 중구 성내2동 |
| 수성구 범어3동 | 수성구 범어2동 | 북구 복현2동 | 중구 남산2동 | 수성구 범어2동 |
| 달서구 월성1동 | 북구 침산2동 | 수성구 고산3동 | 북구 침산2동 | 수성구 고산1동 |

로컬 시안에 네 기준의 선택을 추가했다. 목적별 우선 항목의 실제 수치를 표시하고, 업종·연령 각각의 주요 네 항목 중 차이가 가장 작은 항목과 큰 항목을 설명에 보여준다. Chrome 헤드리스에서 네 옵션을 바꾸고 기준 상권을 변경했을 때 화면의 5개 추천 순서가 결과 파일과 일치함을 확인했다. 다음 단계는 팀원이 창업 상황을 가정해 추천 설명을 읽고 후보지를 더 찾을 수 있는지 확인하는 것이다.

[팀원 사용성 점검안](usability_check.md)에 창업 상황별 과제, 응답 양식과 내부 확인표를 마련했다. 참가자 응답은 수집 전이다.

## 추천 옵션 확장

기본 추천과 상가·거주자 규모 옵션에 더해 소진공 업종 대분류 10개, 주민등록 거주자 연령대 11개를 각각 선택할 수 있다. 총 23개 옵션을 제공한다. 업종과 연령 우선 모드는 선택한 항목 비중의 차이를 우선하며, 기존과 같이 우선 항목 순위 65%와 기본 유사도 순위 35%를 반영한다. 후보별 카드에 선택한 항목의 실제 비중과 기준 상권과의 차이를 표시한다.

146개 기준 상권의 22개 우선 옵션에서 추천 5곳의 중복·자기 추천 여부를 점검했고, 모든 옵션의 전체 평균에서 해당 우선 항목의 차이가 기본보다 작았다. JavaScript 테스트에서 기본을 포함한 23개 옵션의 화면 전환과 결과 순서를 대조했다. 확장본의 Chrome 헤드리스 검증은 제한 시간 안에 끝나지 않았다. 기존 음식업·0~9세·규모 과제는 확장본에서도 진행할 수 있다.

[앱 연동 자료](app_handoff.md)에 팀 공유용 추천 JSON, HTML 시안과 조회 방법을 정리했다.
