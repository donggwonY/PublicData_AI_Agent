# A-09 팀원 사용성 점검

## 진행 방법

`output/a09_similar_areas_preview.html`을 브라우저에서 연다. 팀원에게 전달할 때는 HTML 파일을 함께 첨부한다. 한 사람당 아래 세 과제 중 하나를 맡아 기본 추천과 목적별 추천을 모두 본다. 여러 명이 같은 과제를 하면 화면을 보는 순서를 번갈아 적용한다. 예상 추천이나 아래 내부 확인표는 응답을 받기 전에 보여주지 않는다.

| 과제 | 상황 | 기준 상권 | 비교할 옵션 |
| --- | --- | --- | --- |
| 1 | 현재 후보지와 음식점이 차지하는 비중이 비슷한 동네를 더 찾고 싶다. | 중구 성내1동 | 기본 / 음식업 비중 |
| 2 | 아동 대상 업종을 검토 중이며 0~9세 거주자 비중이 비슷한 동네를 찾고 싶다. | 수성구 범어3동 | 기본 / 0~9세 거주자 비중 |
| 3 | 점포와 거주자 규모가 비슷한 동네를 추가로 보고 싶다. | 달서구 월성1동 | 기본 / 상가 수와 거주자 수 |

두 목록을 보고 실제 더 살펴보고 싶은 곳을 한 곳 고른다. 순위와 상관없이 선택할 수 있다. 후보가 없다면 그 이유를 적는다.

## 응답 양식

- 과제 번호와 먼저 본 추천 방식
- 더 살펴볼 동네 한 곳 또는 해당 없음
- 선택에 도움이 된 수치나 문구 한 가지
- 다른 후보와 비교하기 어려웠던 점이나 필요했던 정보 한 가지
- 후보지 찾기에 더 도움이 된 방식(기본 / 목적별 / 둘 다 비슷 / 둘 다 어려움)

## 내부 확인표

아래는 2026년 9월 데이터에서 다시 계산한 화면 확인용 수치다. 팀원이 다른 후보를 선택할 수 있으므로 예상 답안으로 채점하지 않는다.

| 과제 | 기준 상권 수치 | 기본 1순위 수치 | 목적별 1순위 수치 |
| --- | --- | --- | --- |
| 1 | 성내1동 음식업 30.15% | 성내2동 29.70% | 성내2동 29.70% |
| 2 | 범어3동 0~9세 9.99% | 범어2동 7.02% | 남산2동 10.06% |
| 3 | 월성1동 상가 1,448개·거주자 39,259명 | 침산2동 600개·17,790명 | 고산1동 1,120개·30,910명 |

과제 1은 1순위가 두 방식에서 같다. 참가자가 두 목록에서 추가로 발견한 후보와 설명을 본다. 과제 2의 남산2동은 아동 비중이 비슷하고 총거주자는 7,416명으로 기준 상권의 17,006명과 차이가 있다. 비중과 규모를 구분해 읽었는지 확인한다. 과제 3은 상가 수와 거주자 수를 각각 읽었는지 확인한다.

## 검토 기록

현재는 과제와 화면 수치 확인까지 완료했다. 팀원 응답 수집 후 실제 답변, 선택을 바꾼 정보, 이해하기 어려웠던 표시를 기록한다. 먼저 세 과제별 응답을 최소 한 건씩 모아 공통으로 나온 문구 개선점과 비교에 필요한 추가 정보를 정리한다. 이 점검은 팀 내부 사용성 확인이다.
