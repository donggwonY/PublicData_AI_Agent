# 분석 스냅샷 해시와 줄바꿈

## 원인과 적용 범위

2026-10-14 macOS 체크아웃에서 D-01 manifest의 `meta.json`과 A-01 중간 JSON의 해시 검사가 실패했다. 내용이 같은 파일도 Windows CRLF와 macOS/Linux LF 줄바꿈의 SHA-256은 다르다. 기존 CRLF로 되돌린 임시 복사본에서는 기록된 해시와 일치했다.

`.gitattributes`는 저장소의 Python·JSON·Markdown·HTML을 LF로 체크아웃하고 Parquet·XLSX·PNG에는 줄바꿈 변환을 하지 않도록 지정한다. 전역 Git 설정을 바꾸거나 원본 파일 전체를 재저장할 필요는 없다. Python이 Windows에서 새로 쓰는 텍스트나 기존 작업 폴더에는 CRLF가 남을 수 있으므로 분석 해시도 공통 함수로 처리한다.

## 생성과 검증

`scripts/snapshot_hashes.py`는 저장소 분석 스냅샷에 사용한다.

- `snapshot_sha256(path)`: JSON·Python은 UTF-8 여부를 확인하고 CRLF만 LF로 바꾼 바이트의 SHA-256을 생성한다. Parquet 등 나머지 파일은 원래 바이트를 해시한다.
- `verify_snapshot_hash(path, expected)`: 위 해시와 비교한다. 기존 보고서를 계속 재현할 수 있도록 JSON·Python에 한해 현재 내용의 LF/CRLF 바이트 해시도 인정한다. 불일치하면 파일 경로를 포함한 `ValueError`로 중단한다.
- JSON 키 순서·공백·숫자·문자열·마지막 줄바꿈·인코딩은 정규화하지 않는다. 내용이 바뀌면 검사가 실패해야 한다. 기대 해시를 현재 값으로 덮어써서 통과시키지 않는다.
- 다운로드한 원본 CSV·XLSX·OSM·JSON 등의 출처 증빙은 계속 `hashlib.sha256(path.read_bytes()).hexdigest()`로 기록한다. 특히 원본 JSON에는 분석 스냅샷 함수를 사용하지 않는다.

예전 보고서의 해시를 일괄 교체하지 않는다. 수정한 D-01 manifest 생성기, D-02 감사, A-01 분석 스크립트가 앞으로 생성하는 스냅샷·코드 해시는 LF 기준이다. 상위 분석의 JSON 내용이 갱신되면 하위 분석도 순서대로 재실행해야 한다. 내용 변경으로 인한 불일치는 줄바꿈 호환으로 허용되지 않는다.

## 검증 방법

저장소 루트에서 Python 3.12로 실행한다. 이 회귀 검사는 표준 라이브러리만 사용한다.

```sh
python3.12 -m unittest discover -s tests -p test_snapshot_hashes.py -v
```

LF/CRLF 호환, 기존 D-01·A-01 해시, 숫자·공백·마지막 줄바꿈 변경 거부, 바이너리 바이트 보존, 잘못된 UTF-8 거부, `core.autocrlf=true`인 임시 Git 저장소의 실제 체크아웃을 확인한다. 실제 분석을 재검증할 때는 Python 3.12 가상환경에서 수행하고, 보고서를 덮어쓰지 않으려면 스크립트·문서를 임시 작업 폴더에 복사해 실행한다. 입력 Parquet는 변경하지 않는다. Windows 줄바꿈 모의 검증과 실제 Windows PC 실행 여부는 구분해서 기록한다.

## 2026-10-14 검증 기록

- macOS, 임시 Python 3.12.14 가상환경에서 회귀 검사 6개 통과. 서비스 코드·가공 데이터·기존 분석 보고서는 변경하지 않았다.
- D-01 `profile_data.py`를 임시 출력 경로로 실행해 기존 일치 검사 10개 및 새 manifest의 14개 입력 해시 검증 통과.
- D-02 6개 감사 스크립트(자리·경계·폐업/공실/생존·EDA·연도·제외 민감도)와 A-01 6개 스크립트(공간 결합·가설·시간대·주거 맥락·상담 사례·출구 비교) 재실행 통과. 생성된 JSON의 해시 관련 필드를 제외한 분석 결과가 기존 보고서와 일치했다.
- 기존 보고서 해시를 읽는 경로와 상위 결과를 새로 생성한 뒤 하위 분석을 실행하는 경로를 확인했다. D-02 폐업/공실/생존 및 A-01 상담·출구·시간대·주거 맥락은 JSON·스크립트를 CRLF로 변환한 임시 복사본에서도 재실행했다.
- 실제 Windows PC 실행은 미수행이다. 실행 로그의 기존 pandas 결측값 비교 경고와 macOS 한글 폰트 경고는 이번 해시 수정과 별개이며, 이미지의 플랫폼 간 동일성은 검증하지 않았다.
