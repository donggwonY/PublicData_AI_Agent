# 실험 ① 확장: 상가정보 변수 — 사전 계획 (2026-11-09 고정)

상위 계획 [vacancy_fill_plan.md](vacancy_fill_plan.md), 본 모델 결과 [models.md](models.md). **결과를 보기 전에** 고정한다. 변경은 아래 "변경 기록"에 덧붙인다.

## 1. 목적
인허가에 나오지 않는 자유업 점포(의복·화장품·휴대폰·학원·부동산 등)를 상가정보로 반영하면 공실 해소 예측이 좋아지는지 측정한다.

## 2. 자료
- 소상공인시장진흥공단 상가(상권)정보(공공데이터포털 15083033), 대구 분기 44개(2015-12 ~ 2026-09). 스크래치 `dl_aux_20261108/sangga/`.
- 확인 사항: 44개 분기 모두 같은 업종 체계(대분류 10, 소분류 243~247, 2015년 코드 243개 전부 2026년에 존재) → 연도 간 대응표 불필요. 상가업소번호가 분기를 넘어 유지. 층정보 기재 34%(2015) → 55%(2026), 호정보 거의 없음.
- 한계: 옛 분기 파일은 새 분류로 재발행된 것이라 당시 공개본과 같다고 보장할 수 없다.

## 3. 업종 대응표
- 소분류 247개 → "42종 대응"(인허가 점포형 42종에 해당) / "42종 밖"(자유업 등). 경계 업종은 표시.
- 에이전트 초안 → 사용자에게 요약 확인 후 확정. 확정 전에는 변수를 만들지 않는다.

## 4. 시점 규칙
- 분기 자료는 분기 말 + 60일부터 사용 가능하다고 본다(실제 등록은 약 1개월 후, 보수적 가정).
- 각 사례는 예측 시점에 사용 가능한 가장 최근 분기를 쓴다. "최근 새로 나타난 점포"는 그 분기와 직전 분기를 비교한다.

## 5. 변수(2단계: 폐업 + 90일 시점, 1단계: 폐업일 시점)
- `sg_floor_total`: 같은 건물(지번 건물 키)·같은 층의 상가정보 점포 수
- `sg_floor_other`: 그중 42종 밖 점포 수
- `sg_bldg_other`: 같은 건물 전체의 42종 밖 점포 수
- `sg_floor_new_other`: 같은 층에 직전 분기에는 없던 상가업소번호의 42종 밖 점포 수
- `sg_nb_total`, `sg_nb_other_share`: 반경 300m 점포 수, 42종 밖 비율
- `sg_nb_change_1y`: 반경 300m 점포 수의 4분기 전 대비 변화율
- 건물 키는 서비스 주소 정규화(`core.address.parse_jibun`)로 만든다. 층은 숫자·지하 표기를 맞춘다. 반경은 좌표 기준.

## 7. 비교와 판정
- 같은 2016년 이후 표본에서 B1, M1 Cox, M3 RSF, M4 치유 모형을 상가정보 없이 / 포함해 각각 학습(튜닝 후보는 [models_plan.md](models_plan.md) 4절과 동일).
- **판정:** 같은 모델에서 "포함 − 없음" C-index 차이의 부트스트랩(1,000회) 95% 신뢰구간 하한 > 0이면 "상가정보가 도움된다". IBS 차이는 함께 보고.
- 1단계(90일 안, 정의 수정본)도 로지스틱·LightGBM으로 같은 비교(AUC 차이 신뢰구간 하한 > 0).

## 8. 검증
- 누수 테스트: 기준 시점 이후 분기 파일을 뺀 데이터로 재계산해도 변수가 같아야 한다.
- 연결률(사례 건물에 상가정보 점포가 연결된 비율) 보고.
- 한계 기록: 재발행된 옛 분기, 폐업 후 남은 점포(약 17%), 층 결측, 상호 표기 차이.
