## 0. 질문과 정의
- 질문: **점포형 업종 기준으로 90일 넘게 빈 자리에 앞으로 6개월·1년·2년 안에 점포형 가게가 다시 들어올 확률.**
- 사례: 단독 자리(폐업 시점까지의 기록으로 판정)에서 가게가 폐업한 시점. 사건 = 같은 자리에 다음 가게 개업.
- 두 단계: 1단계 = 폐업 후 90일 안에 채워지는가(분류), 2단계(본 실험) = 90일 넘게 빈 자리가 그 뒤 언제 채워지는가(생존분석).
- 분할: 학습 2012–2019 폐업(관측 종료 2021-12-31) / 검증 2020–2021(2023-12-31) / 평가 2022–2023(2026-11-06, 한 번만 열기).

## 1. 데이터 준비
- 16종으로는 "다른 업종 가게로 채워진 자리"가 공실로 잡혀 점포형 42종으로 확장(195종 중 26종 추가, 검토 15종 제외). 대구 압축 원본(2026-11-07 추출).
- 정제 규칙: 미래 날짜 제외, **같은 자리·같은 상호·겹치는 기간 = 한 가게(겸업 묶기)**, **비점포 업태 제외**(건강기능식품 전자상거래·방문판매 등 11,278건, v2에서 추가).
- 원본 점검: 기록 삭제는 거의 없음, **2000년 이전 폐업은 사실상 누락** → 자리 이력은 2003년 이후만 사용, 업종별 등록 시작 연도 차이(2018 동물 업종 일괄 등록 → 중도절단), 늦은 신고(대부분 30일 이내) → 폐업은 한 달 늦게 반영.
- 보조 자료(과거 시계열 확보): 지하철 월별 승차(1997~), 행정동 인구(2011~, 월별), 상가정보 44개 분기(2015-12~), 역 좌표.

## 2. 시점 기준 사례·변수
- 사례 28,570건, 90일 넘게 빈 사례 21,627건(사건 5,746). 최종 기록으로 단독 자리를 판정하면 놓치는 사례 2,143건.
- 변수(모두 예측 시점 기준 재계산): 직전 가게(업종 그룹 11개·영업 기간·면적·겸업 수·층·구·폐업 월·코로나), 자리 이력, 반경 약 300m(영업·개폐업·공실), 동 공실률·변화, 지하철(개통일 반영), 인구, 상가정보(같은 층 자유업 점포 등).
- 누수 테스트 통과: 단독 여부·자리 이력 400건 불일치 0, 주변·동·지하철·인구 기준 달 3개 불일치 0, 상가정보 기준 분기 3개 불일치 0.

## 8. 결론과 한계
- **시점 기준 모델(M3·M1 + 상가정보)이 평가 구간에서 현재 방식(구×업종 평균)을 순서·확률 모두에서 넘었다**(C-index 0.68 vs 0.58).
- 절대 성능은 중간 수준: 같은 업종·같은 층 안의 개별 자리 구분력은 제한적이고, 자유업 입점은 인허가로 볼 수 없다.
- 핵심 정보는 직전 가게와 주변 상권. 지하철·인구·자리 이력은 거의 기여하지 않는다.
- 평가 구간을 두 번 열었다(두 번째는 데이터 정의 오류 수정, 모델·설정 불변). 오래 빈 자리의 조건부 확률은 2026-11-10 사후 점검했다([결과](conditional_check.md)): 곡선을 경과일 조건으로 읽으면 2년까지 순서가 B1보다 낫고(+0.10~0.13), 확률은 약 1%p 높게 나온다(180일은 보정 기준 근소 실패). 조건 없이 읽으면 2배 이상 과대.
