# 실험 ① 4단계: 평가 구간 최종 평가 — 사전 계획 (2026-11-09 고정)

상위 [vacancy_fill_plan.md](vacancy_fill_plan.md), 근거 [models.md](models.md), [sangga.md](sangga.md). **평가 구간을 열기 전에** 고정한다.

## 1. 원칙
- 평가 구간(2022–2023 폐업)은 한 번만 연다. 결과를 본 뒤 모델·변수·설정값을 바꾸지 않는다.
- 코드 오류가 드러나면 오류만 고쳐 재실행할 수 있고, 무엇을 왜 고쳤는지 기록한다.

## 2. 대상 모델
| 단계 | 모델 | 설정값(출처) |
|---|---|---|
| 2단계 | **M3 RSF + 상가정보(주 후보)** | `models_sangga.json` 의 선택값(최소 잎 30, 변수 비율 0.3) |
| 2단계 | M1 Cox + 상가정보(설명용) | 같은 파일(alpha 0.1) |
| 2단계 | B1 구×업종 KM | — |
| 1단계 | LightGBM + 상가정보 | 확장 실험과 같은 튜닝 절차(2016–17 학습 → 2018–19 AUC)로 다시 선택, 결정적 |
| 1단계 | B1 구×업종 비율 | — |
변수는 인허가·지하철·인구·상가정보(시점 기준, 누수 테스트 통과).

## 3. 데이터
| 용도 | 폐업 연도 | 정답 관측 종료 |
|---|---|---|
| 최종 학습 | 2016–2021 | 2023-12-31 |
| 평가 | 2022–2023 | 2026-11-06 |
1단계 대상은 폐업 시점에 다음 인허가가 없는 사례(정의 수정본).

## 4. 지표·판정
- 2단계: Uno C-index(τ 730), AUC 180·365·730일, IBS(30~720일), 1년 보정표. 1단계: AUC, PR-AUC, Brier, 보정표.
- 판정(B1 대비, 부트스트랩 1,000회): C-index 차이 ≥ +0.02 이고 하한 > 0, IBS 차이 < 0 이고 상한 < 0. 1단계는 AUC 차이 하한 > 0 과 Brier 차이 상한 < 0.
- 미달이어도 그대로 보고한다.

## 5. 오류 분석(M3, 평가 구간)
- 하위 집단: 직전 업종 그룹, 구, 층 구분, 폐업 연도, 상가정보 층 정보 유무. 각 사례 수·사건 수·C-index(사건 30건 이상만)·1년 예측 평균·1년 실제 KM.
- 크게 틀린 사례(진단용으로 결과 이후 자료를 봄, 모델 반영 없음):
  - 1년 예측 상위 10% 인데 2년 안에 안 채워진 사례: 최신 분기(2026-09) 상가정보에 같은 건물·층의 42종 밖 점포가 있는 비율.
  - 1년 예측 하위 10% 인데 180일 안에 채워진 사례: 들어온 업종 분포.

## 6. 누수 비교(논문용)
- 같은 사례·같은 모델(M3, M1)로 ⓐ 시점 재계산 변수 vs ⓑ 최종 기록 변수.
- ⓑ 정의: 자리 이력 = `units` 최종 값(인허가 수·폐업 수·최대 동시 영업·평균 영업 기간·업종 수·업태 수), 주변·동·지하철·인구·상가정보 = 기준일(2026-11-06) 시점 값. 직전 가게 변수는 같다.
- 검증(학습 2016–19 → 검증 2020–21)과 평가(학습 2016–21 → 평가 2022–23) 모두에서 ⓑ − ⓐ 를 보고한다. ⓑ 의 점수는 실제 서비스에서 낼 수 없는 값이다.
- 사례 선택 누수(최종 기록 단독 자리 28,063건 vs 시점 기준 30,288건)도 함께 기록한다.
