# 실험 ① 3단계: 모델 학습 — 사전 계획 (2026-11-09 고정)

상위 계획 [vacancy_fill_plan.md](vacancy_fill_plan.md), 기준선 [baseline.md](baseline.md). **결과를 보기 전에** 고정한다. 이후 변경은 아래 "변경 기록"에 덧붙인다.

## 1. 목적
변수 여러 개를 함께 쓰는 모델이 검증 구간(2020–2021 폐업)에서 현재 서비스 방식(B1 구×업종 KM)을 넘는지 확인한다. 평가 구간(2022–2023)은 열지 않는다.

## 2. 데이터
- 입력: `$E05_WORK/asof_episodes.parquet`(시점 기준, 누수 테스트 통과).
- 2단계(본 실험): 90일 시점에도 빈 사례, 시간 원점 = 폐업 + 90일, 변수는 `s2_`(폐업 + 90일 시점). 1단계: 전체 사례, 90일 안 채워짐, 변수는 `s1_`(폐업일 시점).
- 분할과 관측 종료:

| 용도 | 폐업 연도 | 관측 종료 |
|---|---|---|
| 튜닝 학습 | 2012–2017 | 2019-12-31 |
| 튜닝 검증 | 2018–2019 | 2021-12-31 |
| 최종 학습 | 2012–2019 | 2021-12-31 |
| 비교 평가(검증) | 2020–2021 | 2023-12-31 |

## 3. 변수(본 모델)
- 인허가: 직전 가게(업종 그룹, 영업 기간, 면적, 겸업 수, 층, 구, 폐업 월 sin/cos, 코로나), 자리 이력(`h_`), 반경 약 300m(`nb_`), 동(`dong_`)
- 지하철(`sub_`), 인구(`pop_`)
- 전처리: 학습 구간 중앙값 대치 + 결측 표시 변수, 개수·면적·승차·인구·거리·과거 공실 기간은 log1p, 범주는 원-핫, 회귀 모델은 표준화(학습 구간 기준).

## 4. 모델과 튜닝 후보
| 모델 | 구현 | 튜닝 후보 |
|---|---|---|
| M1 Cox | scikit-survival `CoxPHSurvivalAnalysis` | alpha ∈ {0.1, 1, 10} |
| M2a 이산시간 로지스틱 | 30일 구간 사람-기간 표(최대 24구간), 구간 원-핫 + 변수, sklearn 로지스틱 | C ∈ {0.01, 0.1, 1} |
| M2b 이산시간 LightGBM | 같은 표, 구간 번호 수치 | (잎 15·31) × (트리 200·500), 학습률 0.05, 최소 잎 100 |
| M3 RSF | scikit-survival `RandomSurvivalForest`, 300그루, 학습 시간은 10일 단위 올림 | 최소 잎 {30, 100} × 변수 비율 {sqrt, 0.3} |
| M4 치유 모형 | 직접 구현: 채워질 확률 u(x) 로지스틱 + 와이불 AFT 시간, 우도 직접 최적화(L-BFGS, 해석적 기울기) | L2 {0.1, 1, 10} |
| 1단계 | 로지스틱 / LightGBM | C ∈ {0.01, 0.1, 1} / 위 LightGBM 격자 |

- 설정값 선택: 튜닝 검증 C-index 최대(동점이면 IBS 최소). 1단계는 AUC.
- 이산시간 모델의 생존확률은 30일 구간 끝 기준이며 1년 = 12구간(360일), 2년 = 24구간(720일)으로 근사한다.

## 5. 판정 기준(검증 구간, B1 대비, 부트스트랩 1,000회 같은 재표본)
1. C-index 차이 점추정 ≥ +0.02 **그리고** 차이 95% 신뢰구간 하한 > 0
2. IBS 차이 점추정 < 0 **그리고** 차이 95% 신뢰구간 상한 < 0
- 두 조건 모두 만족해야 "B1을 넘었다". C-index만 통과하면 그대로 보고한다.
- 여러 모델이 통과하면 C-index가 가장 높은 모델이 4단계(평가 구간 1회) 후보.

## 6. 함께 보고할 것
- 변수 묶음 기여: 튜닝 검증 기준 최고 모델 유형으로 인허가만 → +지하철 → +인구.
- 묶음별 순열 중요도(검증 구간, 5회 반복, C-index 감소량).
- 1년 보정표(예측 10구간 vs 실제 KM). 확률이 계속 높게 나오면 "예측 시점까지 결과가 확인된 최근 공실들의 대구 채워짐 비율" 변수를 별도 시험(누수 테스트 포함)하고 변경 기록에 남긴다.
- Cox 비례위험 가정 점검(lifelines Schoenfeld 검정, p < 0.01 변수 수).

## 변경 기록
- 2026-11-09 **1단계 대상 정의 변경(결과를 본 뒤의 변경).** 첫 실행에서 검증 양성의 30.6%가 다음 가게 인허가가 폐업일 이전(당일 포함)에 이미 등록된 사례였고, 모델이 이를 "자리 가게 수 − 폐업 수"로 읽어 AUC가 0.793까지 올랐다([models.md](models.md)). 예측 시점에 이미 채워진 자리이므로 서비스 질문("이 빈 자리가 90일 안에 채워질까")에 맞지 않는다. 1단계 대상을 **폐업 시점에 다음 인허가가 아직 없는 사례**(다음 인허가일 > 폐업일 또는 없음)로 바꾸고, 기준선 B0~B2와 모델(로지스틱·LightGBM)을 같은 튜닝·판정 절차로 다시 평가한다. 첫 실행 결과는 문서에 남겨 둔다. 2단계는 영향 없음.
