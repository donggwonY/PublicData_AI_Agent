# 고정 면적 RF의2025년 추가 시간 평가 계획

2026-10-28. 결과 열람 전 고정. 기존 프로토콜에서 미사용으로 표시된2025년 중1~9월 개업을 새 시간 평가로 사용한다. 스냅샷 기준2026-10-13이므로 전원365일 관측 기회 확보. 완전한 월만 사용하며10월 중간까지 잘라서 쓰지 않음. 이미 평가한2023~2024 최종시험은 재채점하지 않는다.

학습2010~2023년,2024년 목표 학습 제외(365일 관측 간격),평가2025-01-01~2025-09-30. 업종일반음식점·유효좌표·양수유한면적. 기존면적파서/결측쉼표복구규칙,주변500m·개업60일전·최근365일맥락,범주와log면적 유지.2024/2025 인허가는 목표 학습에 쓰지 않되 각 대상 개업60일전의 이웃정보로만 사용 가능. RF150나무/깊이8/최소잎30/max_features sqrt/seed0 고정. 상수·면적없는RF·면적RF3개만 비교. 평가결과로 튜닝/보정/필터 변경 금지.

2025 신규 시간 평가이지만 동일 최신 스냅샷의 과거 재구성이며 개업 당시 면적/주소와 실제 공개일 미확인이다. 외부 독립표본 또는 완전맹검/실서비스예측으로 부르지 않는다. 이전 시점에서 일부2023집계는 이미 열람했으며 이 기간은 이번에 학습자료로 포함한다.

기준:면적RF가 두 기준선보다Brier/logloss가 낮은지,예측평균/실제비율/AUC와 고정확률구간별 관측비율 확인. 신규건물·구군별 결과,좌표/면적 제외수 기록. 건물paired bootstrap2000회(seed42)차이구간 진단 포함. 결과 불리해도 공개하고 재튜닝하지 않음. 운영/DB/기존데이터 변경 없음.
