# 면적 없는 주변 이력 비교

기존 전체대상 RF 비교의 세 기간, 모든 대상 및 모델 설정을 유지한다. 개업 60일 전 기준 반경 500m 일반음식점 영업 수·최근365일 개업/폐업 수(log1p)를 추가한다. 현재 좌표로 과거를 재구성하며 실제 당시 주소·정보 공개일은 미확인이다. 미래 사건과 대상 자신은 집계하지 않는다.
좌표 없는 행도 유지하며 주변 이력은 학습표본 중앙값으로 대체한다. 좌표·면적 누락 여부 자체는 입력하지 않는다. 면적 제외 그룹은 유효좌표인 행으로 정의된 기존 그룹을 그대로 사용한다.
같은 기본 RF 대비 세 기간 전체 및 면적 제외 그룹에서 Brier/log loss가 모두 개선되는지 각각 확인한다. 상수/회귀도 함께 보고한다. 고정150 trees/depth8/leaf30/sqrt/seed0, 추가 설정 탐색 없음. 2023~2025 재평가 없음. 반복 탐색으로 독립 성능 입증이 아니며 운영 변경 없음.
