# 건물이력 효과의 불확실성 점검

기존 고정 모델·같은 세기간·표본을 재현해 예측을 복원한다. 새 후보 탐색이나 설정 조정 없음. 같은 건물의 관측을 함께 뽑는 paired cluster bootstrap 2000회(seed42)로 후보-대조 Brier/log loss 차이의 95% 백분위 구간을 구한다. 대응쌍: building_rf/uncalibrated, building_calibrated/global_regularized. 음수는 개선.

각 재표집에서 모델 재학습은 하지 않으므로 학습·모델선택 불확실성, 미래 시기 변동을 포함하지 않는다. 반복 사용한 검증기간의 조건부 진단이며 독립 검증이나 인과 증거가 아니다. 여섯 비교의 다중비교 보정 없음. 기존 점수/입력해시 일치, 0차이 테스트·재현성·전체 손실차 일치를 검증한다. 2025 재평가·DB/운영 변경 없음.
