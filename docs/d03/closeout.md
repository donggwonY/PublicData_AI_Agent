# D-03 실험 완료 보고

## 최신 정리 — 2026-10-29

**합의한 추가 실험·하위집단 진단 범위 완료.** 연구용 비교 화면은 구현됐으며 공개 서비스에 개인별 예측을 적용하는 결정은 남아 있다. 아래 2026-10-17 결과는 첫 실험 기록으로 보존한다.

추가로 주변 상권·월별 승하차·모델14후보·업태별 실험·면적 입력·확률 보정을 비교했다. 면적이 있는 일반음식점2025년1~9월1,608건에서 면적RF는 면적 없는RF 대비Brier6.12% 감소했다. 별도2010~2021학습RF를2023년 자료로 보정한 후 평균 예측9.99%, 실제 신고10.45%였다. 두 실험의 학습 범위가 달라 보정 효과는 같은 기초RF와 비교했다. 보정의Brier 개선 재표집 구간은0을 포함한다.

[하위집단 진단](area_subgroups.md)에서 동구14.05%/실제26.16%, 한식9.60%/실제7.59% 등 차이가 남았다. 전체 개선은 일부 집단에 집중됐으며 여러 집단에서Brier가 악화했다. 집단 평균이 가깝다는 이유로 해당 집단을 서비스 가능 대상으로 선정하지 않는다.

현재 면적·주소가 개업 당시와 같은지는 미확인이다. 2026-10-28 공식 일반음식점 API 내장 Swagger 재확인 결과 이력 조회 가능 기간은2026-01-01부터 전일까지로, 이 API만으로2010~2025 개업 당시 면적을 복원할 수 없다. [공식 안내](https://www.data.go.kr/data/15154916/openapi.do). 당시 자료나 별도 변경 이력 확보는 후속 과제다.

지금 결과는 이미 확인한2025표본의 후속 탐색이며 신규 독립 검증이 아니다. 표본/사건/가중지표 합계·기존4모델 점수·보정계수·입력 해시·면적 경계 검증을 통과했다. 현재 작업은 분석 스크립트와 문서만 변경했고 DB·운영 모델·배포는 변경하지 않았다. 연구용 결과 공개 범위는 팀과 논의하고, 미래 검증은 별도 후속 과제로 관리한다.

근거: [면적2025평가](area_2025.md), [확률보정](area_calibration.md), [하위집단진단](area_subgroups.md), [연구용화면](experiment_viewer.md).

## 첫 실험 기록 — 2026-10-17

2026-10-17. 완료 범위는 생존 기준선 재현, 일반음식점 첫 예측 실험, 과거 인구 추가 비교와 한계 정리다. 서비스에 사용할 예측 모델 완성이나 15개 업종별 모델 개발 완료를 뜻하지 않는다. 에이전트 추천은 현재 후보의 서비스 적용 보류이며 팀의 최종 제품 결정은 별도다.

## 수행 범위

- 기준일 2026-10-13 인허가 225,858건. 원천 업종 16개를 보존하고 의원·병원만 묶어 분석 그룹 15개로 집계했다.
- 기존 생존 요약 685행과 기간 계산을 재현했다. 2010년 이후 365일 추적 기회가 있는 인허가는 107,168건이다.
- 일반음식점의 개업 후 365일 이내 폐업·취소·말소 신고를 예측했다. 실제 사업 실패·수익성·현장 공실을 예측한 것은 아니다.
- 업태·구군·개업 월을 사용하고, 폐업일·현재 상태·영업기간 등 결과를 알려주는 정보는 입력에서 제외했다.
- 학습 2010~2018년, 검증 2020~2021년, 최종 시험 2023~2024년으로 나눴다. 결과 관측을 위한 2019·2022년 간격을 뒀다.

## 결과와 판단

| 실험 | 평가 표본 | 핵심 결과 | 판단 |
| --- | --- | --- | --- |
| 첫 후보 검증 | 일반음식점 5,681건 | AUC 0.510. Brier 0.07299로 상수 기준선 0.07227보다 큼 | 확률 오차 개선 실패 |
| 설정 고정 최종 시험 | 일반음식점 5,837건 | AUC 0.619. 평균 예측 9.09%, 실제 신고 비율 18.31% | 위험을 과소예측, 적용 보류 |
| 인구 추가 후속 검증 | 군위군 제외 동일 8개 구군 5,643건 | AUC 0.511→0.516. Brier 0.07298→0.07382, 평균 예측 8.98%→10.70% (실제 7.83%) | 인구 추가도 채택 보류 |

Brier는 낮을수록 확률 오차가 작다. 인구 추가 비교는 모집단이 달라 첫 검증과 직접 비교하지 않고 동일 8개 구군 기본 모델과 비교했다. 개업 3개월 전 인구를 쓴 민감도 비교도 결론이 유사했다. 인구 추가 모델은 이미 확인한 최종 시험 기간을 다시 채점하지 않았다.

## 남은 한계

1. 시기에 따라 실제 신고 비율이 달라져 예측 확률이 안정적이지 않았다. 변화의 원인은 분리해 입증하지 못했다.
2. 최신 인허가 스냅샷으로 과거를 재구성했다. 당시 주소·업태와 수정 이력, 실제 정보 공개 시점을 완전히 확인하지 못했다.
3. 현재 보조자료 6종은 과거 시점 정보가 부족해 그대로 과거 예측에 넣을 수 없다. 현재 상권 설명에 쓸 수 있는지와는 별개다.
4. 확보한 구군 인구는 지역 범위가 넓고 군위군 편입 전 자료가 부족하다. 2·3개월 시차는 과거 공표일 확인을 대체하는 가정이다.
5. 첫 시험의 연도별 요약은 이전에 확인해 완전히 눈가림한 시험은 아니다. 인구 실험 역시 기존 검증 결과를 본 뒤 진행한 후속 탐색이다.
6. 작은 AUC 차이의 유의성이나 인구의 인과 효과는 주장하지 않는다. 다른 업종이나 미래 시기의 성능도 보장하지 않는다.

## 데이터 보관과 재현

인구 원본 4개는 `data/raw/d03_population/`에 로컬 보관하며 Git 제외 대상이다. 출처·해시·정규화 결과는 [population_monthly.json](population_monthly.json)에 기록했다. 팀원이 원본부터 재현하려면 원본 CSV 별도 전달 또는 동일 자료 재확보가 필요하다. Supabase 적재는 이번 로컬 실험에 필요하지 않아 수행하지 않았다. 팀 공용 조회·서비스 사용이 확정될 때 적재 범위를 결정한다.

분할·해시·동일 표본·모델 수렴·확률 범위 검사 및 첫 검증 수치 재현을 수행했다. 상세 실행과 환경은 각 보고서 및 JSON에 기록되어 있다. 로컬 분석 환경은 서비스 배포 고정 패키지와 완전히 같지 않으며 배포 검증은 수행하지 않았다.

## 팀에서 결정할 후속 범위

- 우선 기존 생존·폐업 통계와 한계를 설명하는 기능에 집중할지, 예측 모델 개발을 별도 후속 실험으로 계속할지 결정한다.
- 예측을 계속한다면 과거 시점의 동네 단위 경쟁 점포 수·유동인구·매출 같은 후보 중 하나를 정해 확보 가능 기간·공간 단위·공개 시점·비용부터 조사한다. 이 자료들이 성능을 높인다는 보장은 아직 없다.
- 팀 교차 검토에서 신고 사건 정의, 기간별 변화, 서비스에 표시 가능한 표현을 확인한다. 새 실험은 평가 계획부터 고정하고 기존 시험 결과에 반복해서 맞추지 않는다.

## 추가 원인 진단 — 동구

[동구 점검](donggu_concentration.md)에서 신고62건 중53건이3곳에 집중됐다. 야외13건은 행사 일정과 겹치고 백화점40건 중39건은30일 이내 신고다. 개별 행사/팝업 허가 확정이나 오차 원인 전체 입증은 아니다. 동구 업태94.94%가 기타인 분류 한계도 확인했다. 한시영업을 결과와 독립적으로 식별하기 전에는 삭제/재학습하지 않는다.

[공식 팝업 근거](popup_evidence.md)로 롱브르378의 브랜드·장소·기간이 연결됐다. 폐업 결과와 독립적인 근거지만 공지일이 허가일보다 늦고 관리번호가 없어 당시 예측입력/행정허가 확정으로 사용하지 않는다. 전체 집중 사례의 자동제외나 재학습 근거는 아직 부족하다.

## 지역·업태 보정 추가 비교 — 2026-10-29

[고정계획 비교](group_calibration.md)에서 과거자료만으로6후보를3기간 평가했다. 지역보정은첫기간만개선,업태보정과동시보정은세기간모두전체보정보다Brier/log loss악화. 정규화전체보정대조포함공통개선기준통과후보없어미채택.2025/기존최종시험재평가없음. 자료요청보류유지,현재실험범위완료·연구용집계활용권고·개별공개확률은보류권고를유지한다.
