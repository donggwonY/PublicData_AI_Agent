## 검증과 한계

월 연속/중복·수치·좌표 키 검사, 미래 월 값을 바꿔도 입력 불변인3개 표본, 0기록/부분 이력 결측 처리, 시간 분리·365일 간격·기존 모델 지표 재현·수렴·확률 범위 검사 통과. 세 기간7후보21평가와 역 연결 여부별 결과를 JSON에 기록.

현재 출구 위치의 과거 일치와 실제 월별 공개일은 미확인이다. 양수 기록 조건은 개통일 검증이 아니며 일시 중단 역도 제외될 수 있다. 좌표 미연결·1km 밖을 수요0으로 해석하지 않는다. 가장 가까운 역·호선만 사용하므로 주변 전체 교통량이 아니다. 역 이용객은 가게 방문객/매출이 아니며 개업 전 과거의 간접 수요 지표다. 이미 반복 활용한 검증기간이므로 개선되어도 독립 성능 입증이나 인과 효과가 아니다.

운영 서비스·DB 변경 없음. 기존 공유 DB 연결 미설정 상태에서 로컬 분석만 수행. 원본 파일 보존. [사전 계획](transit_experiment_plan.md), [전체 결과](transit_experiment.json).

재현: 기존 D-03 분석 환경에서 `python scripts/fit_d03_transit.py --raw-dir "월별 CSV가 있는 폴더"`.

## 결과 해석

두 알고리즘 모두 세 기간에서 이용량 추가 모델이 접근성만 추가한 모델보다 Brier와 log loss가 커졌다(6개 비교 모두). 이번 설정에서는 이용량의 추가 이득이 확인되지 않았다. 역 접근성 자체와 승하차 변화의 효과를 분리해 비교한 결과이며 모든 지하철 활용 방식의 실패를 뜻하지 않는다. 예측 서비스 채택의 근거로 삼지 않고 상권 배경 설명 자료로 보존한다.

추가 독립 검사: 월별 합계의 일평균 변환, 3개월 중0인 경우 결측 유지, 동일점 거리0, 하위집단 표본·사건·가중 Brier 합계 대조를 통과했다.
