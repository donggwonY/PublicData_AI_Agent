## 실패 사례 집계

```text
{
  "events_predicted_below_10pct": 619,
  "nonevents_predicted_at_least_20pct": 8

```

10%·20% 기준은 오류를 설명하기 위한 집계 구간이며 서비스 분류 임계값으로 최적화한 것이 아니다. 새 건물 집단은 학습·검증에 없던 건물의 인허가이며 고유 건물 수가 아니다. 전체와 구성 자체가 다르므로 성능 차이를 주소 누출 효과로 단정하지 않는다.

## 해석 제한

실제 사건 비율과 평균 예측 확률 차이는 기간 이동에서의 확률 오차를 보여준다. 업태 구성·신고 지연·최신 스냅샷 선택·사회환경 변화 중 어느 원인이 얼마나 기여했는지는 이 실험만으로 분리할 수 없다. 인과적 설명 또는 실제 영업 실패 확률로 사용하지 않는다. 동일 건물 반복 관측을 독립 표본으로 간주한 유의성 주장을 하지 않았다.

최종 평가 점수로 이 후보를 다시 튜닝하지 않는다. 추가 변수·최근 학습 기간 등의 개선 실험은 별도 프로토콜과 새 평가 설계를 요구한다. 운영 DB·앱에는 적용하지 않았다.

재현: `python scripts/evaluate_d03.py`. 검증 결과·입력 해시 불일치 시 중단한다.

## 최종 판단: 첫 후보 서비스 채택 보류

전체 시험 5,837건에서 AUC 0.61861, Brier 0.15553(상수 기준선 0.15885)로 기준선보다 개선됐다. 그러나 평균 예측 9.09%에 비해 실제 사건 18.31%로 약 9.22%p 과소예측했다. 새 건물 2,715건에서도 AUC 0.63923이지만 평균 예측 9.18% 대비 실제 15.32%로 약 6.14%p 과소예측했다.

검증기간의 AUC 0.50977과 최종 기간 0.61861은 기간별 성능 차이가 있음을 보여준다. 시험에서 개선됐다는 이유로 검증 단계의 보류 결정을 뒤집거나 운영 확률로 채택하지 않는다. 인허가 사건 비율은 학습 8.70%, 검증 7.83%, 최종 18.31%로 달랐다. 기간별 구성·선택·상태 갱신 등의 영향은 추가 조사 대상이며 상승 원인은 미확정이다.

폐업 사건 1,069건 중 619건은 예측 10% 미만이었다. 이 집계는 낮은 확률을 ‘안전한 창업’으로 해석할 수 없음을 보여주는 사례이며 10%가 최적 의사결정 기준이라는 뜻은 아니다.

후속 선택: 이 결과를 첫 기준선 실험의 실패·한계 근거로 보존한다. 추가 실험은 과거 시점에 이용 가능했던 보조자료의 존재와 최근 학습기간 사용 가능성을 먼저 검토하고 별도 계획으로 시작한다. 현재 시험기간을 반복 최적화용으로 사용하지 않는다.
