## 이번 실험의 판단

보정 후 전체96분기 중29분기 두 오차 개선,53분기 두 오차 악화,14분기 혼재였다. 최근12분기는7분기 개선·2분기 악화·3분기 혼재다. 따라서 이번 C1 설정의 업종별 운영기간 효과 추가 모델을 공통 운영기간 모델의 일괄 대체안으로 채택하지 않는다. 이는 모든 상호작용 모델이 무효라는 결론이 아니다.

최근 업종별 개선은 즉석판매제조가공12/12, 미용11/12, 체육도장9/12, 제과점6/12, 일반음식점5/12, 세탁5/12, 이용0/12다. 일부 업종의 결과로 전체 성능을 대표하지 않으며, 사후에 유리한 업종만 골라 서비스 성능으로 주장하지 않는다.

최신2025-10 동일85951행에서 Brier 0.07967318→0.07966187(상대 약0.014% 감소), log loss 0.29215110→0.29187202, AUC 0.62441→0.62677였다. 최신 시점 개선만으로 전체 기간의 악화를 무시하지 않는다. 최근12분기 Brier 상대 변화는 약0.061% 악화~0.278% 개선 범위다.

공통 스플라인 유지·업종별 상호작용 배치·미관측 업종의 공통효과 대체 검사 통과. 96시점 표본과 신고 건수·기준선 오차1e-12 이하 재현·파일 해시 검산 통과. 모델 표현은 공유 계수와 업종별 추가 계수의 L2 정규화이며 베이지안 계층모형으로 부르지 않는다. 현재 공개 앱과 DB는 변경하지 않았다.
