# E-06 구·업종별 폐업 건수 모델 교차 검토

## 확인 범위

E-06 보고서의 고정된 G1 포아송 모델(λ=0.3)만 다시 계산했다. 설정을 재선택하지 않았으며 E-06 원본 코드와 결과를 변경하지 않았다. 이미 공개된 시험 결과의 재현성 확인으로, 새 독립 시험이나 추가 모델 선정이 아니다. G2·개업·동 단위 결과는 이번 범위에 포함하지 않는다.

## 추가 코드 검사

- 입력 원본 해시가 저장된 시험 결과와 일치했다.
- 2022년 이후 개업·폐업 사건 날짜를50년 뒤로 옮겼을 때, 2022년까지의 평가 대상·폐업 목표·입력 변수는 변하지 않았다. 이 검사는 미래 사건의 직접 혼입을 점검하며 최신 주소·업종·대표 인허가 처리의 역사적 유효성까지 보장하지 않는다.
- 직접 구현된 포아송80% 구간의 양 끝값을 scipy.stats.poisson.ppf와 대조하여 평가행 전체에서 일치했다.
- 유지된244,027건에서 폐업 상태이지만 폐업일이 없는 기록, 폐업일이 개업일보다 빠른 기록, 구군 누락은 각각0건이었다. 다른 종류의 품질 문제가 없다는 뜻은 아니다.

## 설명 보완점

1. 추세 변수의 분모: 코드에서 목표연도 y의 개업 추세는 y−1년 개업 수를 y−2~y−4년 평균과 비교한다(분자·분모에1 추가 후 로그). 보고서의 ‘직전3년 평균’이 y−1~y−3을 뜻하는 것으로 읽히지 않도록 연도를 명시할 수 있다. 계산 오류를 발견했다는 뜻은 아니다.
2. 최신 자료의 업종·구군·is_primary와 전체 스냅샷의 분류 목록을 사용한다. 사후 정정·이전·신고 지연 한계는 유지된다.
3. 2023년 실제값으로2024년 모델을 학습하는 것은 매년 갱신하는 시점 이동 방식으로 계획에 명시돼 있다. 2023–25년 전체를 처음부터 학습에서 제외한 고정 모델 시험과는 다르다.
4. 동 단위 폐업 예측 품질은 이번 구 단위 결과로 확인되지 않는다.

## D-03과의 관계

D-03의 개별 인허가 영업 지속 비교와 E-06의 구·세부업종별 다음 해 폐업 신고 건수는 목표와 평가 단위가 다르다. 정제(대표 인허가), 세부 업종, 최근 사건 변수, 학습 방식도 다르므로 성능 차이를 지역 집계 하나의 효과로 단정할 수 없다. E-06의 결과를 D-03 자체의 개선 실험 결과로 기록하지 않는다.
