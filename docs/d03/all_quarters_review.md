# 전체 기간의 분기별 범위 점검 및 평가

1960~2026의 모든 분기 시작일을 점검하고, 동일한 학습·보정 최소조건을 충족하는 시점만 평가했습니다. 이전2013년 시작은 자료 한계가 아닌 실험 일정이었으며 이번 점검으로 대체합니다.

총 268개 분기 시작일 점검, 96개 분기 평가. 평가 범위 2002-01-01~2025-10-01. 제외된 시점과 학습/보정/평가 표본은 all_quarters_coverage.csv에 모두 보존했습니다.

학습은 평가연도보다4년 전1월1일, 보정은2년 전1월1일입니다. 최소조건은 학습·보정 각각 표본200/양성20/음성20 이상. 이는 계산상 점검 기준이며 기록 완전성이나 서비스 허용 기준이 아닙니다. 모든 시점에서 적격 인허가 전체를 사용했습니다.

과거 폐업 신고가 매우 적은 시기의 표본 완전성은 확인되지 않았습니다. 초기 구간은 탐색적 스트레스 점검으로 해석해야 하며, 성능 수치만으로 운영 범위를 확정할 수 없습니다. 현재 주소·최신 스냅샷·겹치는365일 추적·같은 인허가 반복 한계가 있습니다. 각 분기를 독립 검증으로 세거나 표본을 고유 점포 수로 합산하지 않습니다. 모델 재튜닝·공개 앱 연결·푸시 없음.

## 범위 확대 후 해석

두 오차 개선73/96분기. 기존2013~2025의52분기는 모두 개선됐지만2002~2006의20분기는 모두 미개선입니다. 이를 근거로 잘 나온 시기만 사후 선택해 전체 성능을 주장하지 않습니다. 2009년 상대개선 폭은 다른 연도보다 커 업종 구성·기준선 변화의 영향을 별도 확인해야 합니다. 개선이 작은 최근 결과와 같은 수준으로 일반화하지 않습니다. 과거기록의 완전성은 이번 계산으로 입증되지 않았습니다.
