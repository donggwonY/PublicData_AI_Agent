# D-03 월별 지하철 이용량 추가 실험 사전 계획

2026-10-28. 사용자 보유 월별 승차·하차 CSV 사용. 결과 확인 전에 아래 설정 고정.

- 질문: 기존 주변 상권 입력에 개업 전 지하철 이용량을 추가하면 확률 오차가 줄어드는가?
- 일반음식점 2010~2021 좌표 유효 표본, 365일 이내 폐업 신고 정의와 기존 세 시간 분할 유지. 기존 2023~2024 시험 재평가 금지.
- 위치: A-01 공식 출구 묶음 중 traffic_match이며 review_cluster=false인 항목. 어린이회관→어린이세상은 기존 A-01 근거 재사용. 미연결 역은 제외하고 목록 기록. 현대 출구가 당시에도 같았는지는 미확인.
- 가용 월: 개업 월에서 2개월 이전까지. 실제 원본 공개일을 확인한 것이 아닌 보수적 가정. 당시 마지막 월 승차·하차가 모두 양수인 역만 후보(최초 양수는 개통일 확정 근거가 아님). 1km 이내 가장 가까운 출구의 역·호선 1개 선택. 환승 호선 합산 안 함.
- 입력: 최근3개월 일평균 승차/하차 각각 log1p, 전년 같은3개월 대비 log 차이 각각. 3개월 모두 양수여야 계산하고 결측 지표와 학습 표본 중앙값 대체. 개통 전·휴업·누락의 0을 실제 수요0으로 해석하지 않음.
- 7후보: 상수, 기존 주변 LR/RF, 주변+역 접근성 LR/RF, 주변+접근성+이용량 LR/RF. 접근성=연결 여부+출구 거리(미연결은1km 상한). RF 기존150나무/깊이8/최소잎30/seed0, LR C1 유지.
- 전체 동일 표본 평가 및 역 연결/미연결 하위집단 기록. 세 기간 모두 상수 및 해당 알고리즘의 접근성 모델 대비 Brier/log loss 개선 여부 확인. 결과는 반복 활용 검증기간의 탐색이며 독립 시험 증거 아님.
- 검증: 월 연속성·유일성·양수 조건·위치 키·미래 월 변경 불변성·학습365일 관측 간격·기존 점수 재현·확률 범위·수렴. 원본·코드·위치·계획 해시 기록.
- 원본 보존. 운영 앱/DB 반영 없음. 좌표가 없는 역·신고 지연·현대 출구 재사용·개업일과 실제 영업일 차이·역 이용량과 상가 방문객 차이 명시.
