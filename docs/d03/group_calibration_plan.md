# 지역·업태 보정 비교 계획

2026-10-29 결과 확인 전 설정 고정. 이미 사용한 과거 검증기간의 후속 탐색이다. 2025년/기존2023~2024최종시험은 이번에 평가하지 않는다.

면적RF 설정과 양수면적/좌표 유효 표본은 유지한다. 분할은 RF학습2010~2011/보정2013/평가2015~2016, 학습2010~2013/보정2015/평가2017~2018, 학습2010~2016/보정2018/평가2020~2021. 각 단계 사이365일 결과 관측 기회를 확인한다.

후보6개: 무보정, 기존전체sigmoid(C=1e6), 정규화전체sigmoid(C=1), 구군추가(C=1), 업태추가(C=1), 구군+업태추가(C=1). 마지막3개는 logit(기초예측)+보정자료에서만 학습한one-hot 구분으로 로지스틱 보정한다. L2정규화로 집단별 계수를0쪽으로 제한하며 미관측 범주는추가효과0으로 처리한다. 모든 후보는같은RF·보정·평가표본을 공유한다. C·기간·조건 재탐색 없음.

채택 검토 기준: 집단추가후보가 세기간 모두 기존전체sigmoid와 정규화전체sigmoid보다 Brier와 log loss가 작아야 한다. 무보정 대비도 별도로 표시한다. 평균만 좋아진 것으로 채택하지 않는다. 집단별표본/사건/가중지표, 날짜분리·해시·확률범위·수렴·미관측범주 처리 검사. 모델/기간 반복선택·현재면적·행사혼입 한계는 그대로다. 최종서비스채택/DB/배포/자료요청 없음.
