# D-03 오차 분석과 단일 업태 비교 계획

2026-10-28. 기존 검증기간 재활용 탐색. 2023~2024 최종 시험 미사용.

기존 주변 랜덤포레스트를 동일 세 기간에 재현하고 업태·구군·개업연도별 확률 오차, 예측-실제 차이, 상수 대비 Brier 차이를 기록한다. Brier 자체는 사건 비율에 영향받으므로 큰 값만으로 특정 업태의 모델 실패를 단정하지 않는다. n<200 또는 사건<20 그룹은 작은 표본으로 표시한다. 0.5 기준 오분류 대신 확률 오차를 본다.

업태 선택은 검증 오차가 아닌 첫 학습기간2010~2013의 표본수로 고정한다. 최소1000건·사건50건을 충족하는 최대 업태 하나, 동률은 이름순. 이후 결과를 보고 다른 업태로 교체하지 않는다.

선택 업태 동일 검증 표본에서 전체 평균, 해당 업태 학습 평균, 전체 업태로 학습한 주변 LR/RF, 선택 업태만 학습한 주변 LR/RF를 비교한다. 기존 입력·하이퍼파라미터와 시간 간격 유지. 세 기간 모두 해당 업태 평균 및 같은 알고리즘 전체학습 모델보다 Brier/log loss가 작은 경우만 다음 독립 평가 후보로 표시. 표본수가 줄어드는 대가를 포함한 비교이지 인과 효과 아님.

학습365일 관측 간격·표본 중복·기존 RF 수치 재현·하위집단 합계·수렴·확률 범위 검사, 입력·코드 해시 기록. 서비스/DB 변경 없음. 원격 pull은 로컬 변경으로 중단되어 최신 반영 미확인.
