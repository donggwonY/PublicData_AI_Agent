# D-03 확장 비교 사전 계획

2026-10-28. 사용자가 기존 자료로 가능한 추가 비교를 요청했다. 결과 확인 전 아래 14개 후보를 고정한다. 무제한 튜닝이나 새 최종 성능 입증이 아니라 기존 자료의 후속 탐색이다.

## 같은 표본과 시간 구간

기존 주변 상권 실험과 같은 좌표 유효 일반음식점 표본. 2022년 이후 개업 기록은 특징 구축·정답 생성 전에 제외한다. 학습2010~2013/검증2015~2016, 학습2010~2015/검증2017~2018, 학습2010~2018/검증2020~2021. 각 검증 전 1년을 비워365일 결과 관측을 마친다. 기존2023~2024 시험은 재사용하지 않는다.

주변 맥락은 개업60일 전500m 관측 영업·최근365일 개업·폐업일 기록 수. 조건을 바꾸지 않는다. 과거 인구는 이전 실험에서 악화했고 군위 결측으로 표본이 달라 이번 후보에서 제외한다. 현재 주소·신고 지연·원천 누락 한계는 그대로다.

## 고정 후보

1. 전체 학습 평균 기준선.
2. 최근3개 개업연도 학습 평균.
3. 업태별 평균을 전체 평균으로 수축한 기준선(가상 표본50건, 새 업태는 전체 평균).
4. 전체기간 기존 로지스틱(업태·구군·개업 월).
5. 최근3년 기존 로지스틱.
6. 전체기간 기존 입력+주변 맥락 로지스틱.
7. 최근3년 기존 입력+주변 맥락 로지스틱.
8. 업태×구군 상호작용+기존 입력+주변 맥락 로지스틱.
9. 기존 입력 랜덤포레스트(150트리, 깊이8, 말단최소30, max_features=sqrt).
10. 기존 입력+주변 맥락 랜덤포레스트(같은 설정).
11. 기존 입력+주변 맥락 히스토그램 부스팅(150회, 학습률0.05, 말단15개, 말단최소30, L2=1, 조기종료 안 함).
12. 시간 분리 보정 비교용 로지스틱(주변 맥락 포함, 더 이른 학습만 사용).
13. 12번 예측을 별도 과거 보정연도에서 sigmoid 보정.
14. 12번 예측을 같은 보정연도에서 isotonic 보정(out_of_bounds=clip).

보정 학습: 각 전체 학습 종료년 E에 대해 모델은2010~E-2년, E-1년은365일 관측 간격, 보정은E년 개업 표본, 다음1년은관측 간격, 검증은E+2~E+3년. 보정기는 검증 정답을 보지 않는다. 12번과13/14번이 같은 기초 모델을 사용하므로 보정 자체 효과도 비교할 수 있다. 다만 다른 후보보다 기초 학습 자료가 적다.

로지스틱은C=1·max_iter2000·class_weight=None. sigmoid 보정은 기초 예측 logit을 입력으로C=1000000 로지스틱, isotonic은 단조 보정. 범주원핫·수치log1p 및 표준화는 각 학습 구간에서만 적합. 모든 난수0. 트리도 class_weight=None, 랜덤포레스트 병렬2개로 제한한다.

## 평가와 중단 기준

Brier/log loss를 우선하고 AUC/AP·평균예측/실제비율·구군·새 건물 하위집단을 기록한다. 세 기간 모두 두 확률 오차가 전체 평균보다 작은 후보만 다음 독립 평가 후보로 표시한다. 기간별 결과를 숨긴 평균순위만으로 서비스에 채택하지 않는다. 순위와 작은 차이는 통계적 우월성의 증거가 아니다. 이번 결과로 설정을 더 조정하거나 기존 시험에 맞추지 않는다.

기존 기본·주변 모델 결과 재현, 표본 비중복·365일 간격·보정 기간 분리·확률 범위·수렴을 검사한다. 검증 결과 JSON·비교표·실패 및 한계 정리를 완료 산출물로 한다. 운영 배포·DB 쓰기는 이번 실험에 포함하지 않는다.
