# 과거 구군 인구 자료 정리

2026-10-17 사용자가 내려받은 행정안전부 주민등록 인구·세대현황 CSV 4개를 통합했다. 전국 시도 단위로 잘못 내려받은 파일은 제외하고 수정본 `(1)` 두 개를 사용했다.

## 결과

- 2009-01~2024-12 총 192개월, 파일 간 월 중복·누락 없음.
- 기존 대구 8개 구군 1,536개 월별 관측값.
- 군위군 2023-07~2024-12 관측값 18개.
- 관측값 총 1,554개. 군위군 2020-01~2023-06의 원천 0값 42개는 구조적 미확보로 표시해 수치를 null로 변환했다.
- 군위군 2009~2019년은 원천 파일에 행 자체가 없다. 모든 구군의 전체 기간이 확보됐다는 의미가 아니다.
- 통합 행 1,596개, 지역코드+월 중복 0. 남녀 합계·시 전체와 구군 합계 대조 2,556회 통과.
- 대구 전체 행은 합계 검증에만 사용하고 분석 행에서 제외했다. 남녀 비율·세대당인구의 반올림값은 분석 원천 변수로 가져오지 않았다.

## 보존과 재현

원본 바이트 그대로 `data/raw/d03_population/`에 보존했다(Git 제외). 각 파일 SHA-256·인코딩·파일명·출처 URL·수령일은 population_monthly.json에 기록했다. 수령일은 실제 다운로드 시각 또는 과거 공개일의 증거가 아니다.

통합 자료: population_monthly.json. 열은 구군, 원천 지역코드, 기준월/말일, 총인구, 세대수, 남녀 인구, 자료 상태, 원천 파일, 과거 공개일이다. 과거 공개일은 미확인이라 null로 두었다.

재현: `python scripts/prepare_d03_population.py`. 이미 보존된 원본이 있으면 이를 읽으며, 없을 때만 사용자의 Downloads에서 지정 파일을 복사한다. 다운로드 원본에는 줄바꿈 정규화 없이 바이트 해시를 쓴다.

## 모델에 넣기 전에 남은 작업

1. 과거 공개일 또는 합리적 이용 가능 시차의 근거를 확인하고 연결 규칙을 고정한다. 개업 월의 인구를 자동으로 붙이지 않는다.
2. 주민등록 통계의 포함 인구 정의가 기간 중 달라지는 점을 출처 설명과 대조한다. 현재 다운로드가 당시 발표된 값 그대로라는 보장은 없다.
3. 군위군은 편입 전 경상북도 자료와 당시 코드를 별도로 확보하거나 해당 행을 미확보로 남겨 분석 범위를 밝힌다. 0으로 대체하거나 미래 값을 역으로 채우지 않는다.
4. 첫 모델의 최종 평가를 이미 확인했으므로, 추가 인구 변수 실험은 후속 탐색임을 명시하고 별도 평가 계획을 먼저 정한다.

이번 작업은 자료 통합·품질 점검까지다. 인허가 연결·추가 모델 학습·운영 DB 변경·커밋/푸시는 하지 않았다.
