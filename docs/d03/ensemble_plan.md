# 면적 모델과 고정 혼합 후속 탐색 계획

2026-10-31 결과 확인 전 고정. 새 자료 없이 가능한 개선 검토. 기존 지역 보정은 미채택이며 다른 기초 모델을 비교한다. 과거 3기간은 이미 본 자료이므로 독립 시험이 아니다. 2023~2025 최종/후속 평가를 재사용하지 않는다.

기존 group_calibration.py와 같은 입력·면적 복구·양수 면적 표본·기간·365일 간격을 유지한다. RF 기초 학습/보정/평가는 2010~11/2013/2015~16, 2010~13/2015/2017~18, 2010~16/2018/2020~21이다.

대조: 같은 RF의 무보정, sigmoid(C=1e6), 정규화 sigmoid(C=1), 과거 기초 학습 상수.
후보: 면적 로지스틱(C=1), ExtraTrees(150 trees,depth8,leaf30,sqrt,seed0), 각각 별도 과거 보정기간에서 sigmoid(C=1); RF 정규화보정과 각 후보의 50:50 확률 혼합. 후보 4개, 비율/설정 재탐색 없음. 범주 인코딩과 결측 대체는 기초 학습에만 적합한다.

검토 통과: 세기간 모두 RF 기존전체보정 및 정규화전체보정보다 Brier/log loss 감소. 별도로 상수·무보정 대비와 구군/업태 집계 및 Brier 악화 수를 기록한다. 전체 통과해도 집단 악화·현재면적 시점·독립 평가 부재는 해소되지 않는다. 서비스 채택이 아니다.

검사: 기존 RF 점수 재현, 입력 해시, 기간 간격·비중복, 동일 평가 표본·사건, 확률 유효성, 집단 합계/가중지표. DB/운영/배포/외부 요청 없음. 원격 동기화는 미커밋 변경으로 중단되어 로컬 스냅샷에서 수행한다.
