# D-03 추가 점검 팀 공유 — 2026-11-04

## 공유용 문안

D-03 추가 실험과 면적 누락 집단 점검까지 진행했습니다!
면적이 있는 동일 표본에서는 기존 면적 모델이 기본 모델보다 확률 오차가 약1.17~1.83% 작았습니다. 다만 면적이 없는 점포까지 포함한 모델과 주변 점포 이력 추가 모델은 기간마다 결과가 달라 안정적인 개선은 확인하지 못했습니다.

오차가 큰 집단을 확인하다가 원본 주소에 행사명이 명시된 기록61건을 찾았습니다. 이 중 기존 실험에 영향을 주는 들안길 행사50건을 포함·제외해 비교했지만, 학습에서 제외하면 전체 오차는 조금 줄고 면적 누락 집단의 오차는 오히려 커졌습니다. 따라서 행사 기록을 일괄 삭제하거나 모델을 바로 적용하지는 않았습니다.

다음은 서비스에서 일반 상설 음식점과 행사장 영업을 어떤 범위로 다룰지, 개별 폐업 확률 대신 검증된 생존·폐업 신고 통계를 우선 제공할지 의논하면 좋겠습니다. 결과와 한계는 docs/d03에 정리했습니다.

## 판단에 필요한 근거

- [동일 표본 비교](matched_baseline.md): 같은 기간·표본에서 면적 RF의 기본 회귀 대비 Brier 감소율1.17~1.83%. 현재 면적이 과거와 같다는 가정은 미확인.
- [면적 없는 RF](no_area_forest.md), [주변 이력 추가](no_area_context.md): 사전의 세 기간 일관 개선 기준 미통과. 전체와 누락집단을 구분해 평가.
- [원본 행사 표기](event_marker_review.md): 전체 일반음식점97,438건 중 주소상 행사명61건, 경기장/백화점 행사장8건. 법적 한시허가 확인은 아님. 넓은 키워드391건에는 상호 오탐이 있어 자동 제외 불가. 표기 없는 점포도 상설로 확정 불가.
- [민감도](event_sensitivity.md):2017~2018 평가50건 분리는 평가모집단 변경이다.2020~2021 학습50건 제외는 동일평가에서 전체 소폭개선·면적제외집단 악화, 상수 기준선 대비 우위 없음.

## 팀에서 결정할 것

1. 서비스 설명 대상이 모든 일반음식점 인허가인지, 상설 점포인지 정한다. 상설만 원하더라도 현재 표기만으로 완전히 구분할 수 없다는 한계를 명시한다.
2. 현재 예측 모델은 연구 결과로 보관하고, 공개 서비스는 기존 통계 설명을 우선할지 결정한다. 연구용 시연 여부는 공개 개별 확률 채택과 별도로 판단한다.
3. 추가 개선을 계속하려면 개업 당시 면적·허가 유형·수정 이력 중 무엇을 확보할지 결정한다. 새 자료 없이 같은 검증기간에 모델 설정을 반복해서 맞추는 작업은 현재 제안 범위에서 종료한다.

이번 정리는 현재 추가 실험 범위의 인계용이다. 사용자가 전체 D-03의 영구 종료나 서비스 정책을 확정한 것으로 기록하지 않는다. 원본/DB/공개 앱 변경 없음. 문안은 작성만 했고 외부로 보내지 않았다.
