같은 실행의 미보정 모델과 비교합니다. 앞선 실험과 학습연도가 달라 이전 수치를 직접 비교하지 않습니다.

- 지역별 축소보정은 전체 Brier·log loss를 네 기간 모두 줄였으나 개선 폭은 작습니다.
- 2023년 Brier 0.081082→0.080994, log loss 0.294062→0.293170.
- 반대로 전체 평균 예측은 8.51%→8.02%, 실제 9.14%로 평균 과소예측은 커졌습니다. 전체 오차와 평균 확률의 일치는 서로 다른 기준입니다.

## 판단

일괄 적용 보류. 지역 보정은 후속 검증 후보로 유지하되 과거 평균이 이후의 변화까지 따라잡는다고 볼 수 없습니다. 다음 검토는 보정기간의 업종·지역 신고율이 평가기간에 얼마나 변했는지와 운영기간 구성 변화를 진단하는 것입니다. 평가 결과에 맞춰 계수나 유리한 지역만 고르지 않습니다. 2025는 이번에도 미사용이며, 이미 반복 평가한 연도의 탐색 결과입니다. 서비스·DB 반영 없음.
