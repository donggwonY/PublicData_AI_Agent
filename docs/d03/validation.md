# D-03 첫 모델 검증 결과

일반음식점 2010~2018년 개업 기록으로 학습하고 2020~2021년 개업 기록으로 검증했다. 최종 평가(2023~2024년)는 예측·채점하지 않았다.

입력은 업태·구군·개업 월뿐이다. 범주 인코더와 모델 모두 학습 자료에만 적합했다. 수렴 검사와 예측 확률 범위·재호출 일치 검사 통과.

```text
               n  events  actual_pct  predicted_pct    brier  log_loss   roc_auc  average_precision
constant  5681.0   445.0    7.833128       8.697735  0.07227  0.275160  0.500000           0.078331
logistic  5681.0   445.0    7.833128       8.965788  0.07299  0.278735  0.509774           0.082040
```

로지스틱 회귀의 Brier 변화(모델−상수)는 0.000720, log loss 변화는 0.003575이다. 두 지표는 작을수록 좋다. ROC-AUC와 average precision은 클수록 좋으며, 상수 예측의 ROC-AUC는 0.5다.

## 해석 제한과 다음 단계

모델 성능은 현재 스냅샷에 남은 인허가의 과거 기간 검증 결과다. 실제 개업 당시 속성 이력, 원천 누락, 신고 지연은 미검증이다. 인허가 간 동일 건물 의존성도 있어 관측값을 독립 표본으로 가정한 유의성 주장은 하지 않는다.
검증기간은 2020~2021년으로 특수한 시기다. 작은 확률 오차 개선만으로 서비스 채택을 결정하지 않는다. 낮은 예측 확률을 안전한 창업이라는 보증으로 설명하지 않는다.
다음은 검증 결과로 후보 유지/보류 방침을 기록하고 고정된 최종 평가와 새 건물 하위집단 평가를 실행한다. 이번에는 보정 모델 추가·최종 평가·운영 적용을 하지 않았다.

재현: Python 3.12 분석 가상환경에서 `python scripts/fit_d03.py`. 패키지 버전과 입력 해시는 validation.json에 기록했다.

## 이번 검증의 판단

로지스틱 회귀는 상수 기준선보다 Brier(0.07299 vs 0.07227)와 log loss(0.27873 vs 0.27516)가 모두 나쁘고 AUC도 0.50977로 낮다. 첫 후보를 서비스 채택하지 않는다. 이는 이 입력·학습/검증기간의 실험 결과이며 모든 폐업 예측이 불가능하다는 결론은 아니다. 유의성 검정이나 모델 개선 효과를 주장하지 않는다.

추가 변수 탐색에 앞서 이 설정을 고정한 최종 기간 평가와 새 건물 하위집단 평가를 수행해 시간 변화에서의 한계를 확인하는 것을 다음 단계로 제안한다. 최종 평가 점수를 보고 이 후보를 다시 튜닝하지 않는다.
