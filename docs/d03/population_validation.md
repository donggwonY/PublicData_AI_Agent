## 제한

기존 검증 결과를 본 뒤 설계한 후속 탐색이며 독립적인 성능 입증이 아니다. 2개월·3개월 시차는 당시 공개일 확인을 대신하는 가정이다. 과거 수정 이력·인구 정의 변화·행정경계 한계가 남는다. 군위군·전체 대구·실제 미래 성능으로 일반화하지 않는다. 확률구간별 실제 사건 비율은 population_validation.json에 보존했다.

동일 표본·연결 후 누락 없음·입력 해시·수렴·확률 범위 검사를 통과했다. 원본·DB·운영 모델은 변경하지 않았다.

재현: `python scripts/fit_d03_population.py` (기존 분석 가상환경).

## 판단

동일 표본에서 기본 모델 AUC 0.51111→인구 추가 0.51629로 소폭 상승했지만, Brier 0.07298→0.07382 및 log loss 0.27870→0.28209로 악화됐다. 실제 사건 비율은 7.83%인데 평균 예측은 8.98%→10.70%로 과대예측이 커졌다. 3개월 시차도 유사했다. 소폭 AUC 차이의 통계적 유의성은 주장하지 않는다.

이번 입력·기간·시차 가정에서는 구군 총인구·세대수 추가를 채택하지 않는다. 인구 자체가 무관하다거나 모든 보조자료가 무용하다는 결론은 아니다. 공간 범위가 넓은 구군 지표, 기간별 변화, 모델 형태 등의 원인 기여는 분리하지 못했다.

첫 모델과 후속 인구 추가 실험을 모두 서비스 적용 보류로 정리한다. 기존 최종 시험에 다시 맞추지 않는다. 다음은 실험 요약·한계·후속 자료 요구사항을 팀 전달용으로 정리하고 D-03 첫 실험 범위의 완료 여부를 판단하는 단계다.
