# 행사 표기 민감도 비교 범위 — 2026-11-04

주소에서 행사명이 확인된61건은2018년50건·2019년9건·2022년2건이다. 단기영업/법적 한시허가를 확정한 표본이 아니므로 `행사명 표기 표본`으로만 부른다. 경기장·백화점8건과 넓은 키워드391건은 제외 후보에 넣지 않는다.

| 학습 | 평가 | 학습 표기 건수 | 평가 표기 건수 |
| --- | --- | ---: | ---: |
| 2010~2013 | 2015~2016 | 0 | 0 |
| 2010~2015 | 2017~2018 | 0 | 50 |
| 2010~2018 | 2020~2021 | 50 | 0 |

2019년9건·2022년2건은 위 학습/평가 구간 밖이다. 따라서61건을 분리해도 모든 기간의 면적 제외 문제를 해결하지 않는다. 첫 기간은 변화가 없어 재학습 불필요하다.

## 고정할 후속 비교

이미 계산한 면적 없는 기본 RF(150trees/depth8/leaf30/sqrt/seed0) 하나만 사용한다. 주변 이력 모델은 제외한다. 주소 표기는 모델 입력으로 넣지 않는다. 새 파라미터 탐색과2023~2025 재평가는 하지 않는다.

1. 2017~2018: 학습 표본은 동일하다. 기존 모델 예측을 복원해 전체 점수 재현 후, 평가50건 포함/제외 결과와 별도50건 결과를 병기한다. 두 평가 모집단이 달라지는 차이이므로 제외 후 점수 감소를 모델 개선이라고 부르지 않는다.
2. 2020~2021: 기존 학습 포함 모델과 학습50건 제외 모델을 동일 평가표본에 비교한다. 상수 기준선도 각 학습표본에 맞춰 계산한다. 전체 및 면적 제외 집단의 Brier/log loss를 보고하고 악화도 그대로 기록한다.
3. 첫 기간은 학습/평가에 해당 표본이 없어 기존 결과를 재사용한다. 2019/2022의11건을 임의로 다른 기간에 넣지 않는다.

실행 전 데이터/기준선/규칙 해시, 대상키 유일성·실제 연결수·날짜 간격을 확인한다. 기존 기본 RF 및 그룹별 점수 재현을 통과해야 한다. 원본은 그대로 두고 분석용 마스크만 사용한다. 현재 주소에 있는 행사명이 당시에도 기록돼 있었는지 미확인이므로 결과는 사후 민감도 분석으로만 해석한다. 서비스 채택 근거가 아니며 외부 검토가 필요하다.

이번 작업은 저장된 주소 검토의 연도 분포 대조와 계획 작성까지 완료했다. 재학습·예측 재채점은 아직 하지 않았다.
