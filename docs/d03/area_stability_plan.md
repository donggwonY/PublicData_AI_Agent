# 면적 모델 안정성 점검 계획

2026-10-28. 양수 면적 RF의 기존 검증 결과를 본 뒤 추가하는 진단. 독립 최종평가나 다중 탐색 보정 결과 아님.

기존 양수 면적 코호트와 입력/학습 설정 그대로 재현해 면적 없는RF, 면적RF, 학습사건비율 상수를 비교한다. 기존3기간 점수 대조. 각 기간의 행별 Brier/log loss 차이(면적RF-기준선)를 건물 단위로 묶어 paired cluster bootstrap2000회(seed42)로 계산한다. 건물키 누락은 별도 개별 행 블록으로 취급하고 수를 명시. 건물별 합계와 표본수를 같이 재표집하여 점포가중 평균 계산.95% percentile 구간,음수면 개선. 고정 모델의 평가 표본 불확실성만 다루며 학습 재추정 불확실성/서로 다른 인접건물 공간의존/반복 모델선택을 반영하지 못함.

학습에 나온 건물, 학습에 없던 건물, 건물키 없음으로 검증표본을 분리해 같은 세 예측의 지표를 기록한다. 기존 건물 정보를 미래 표본에 쓰는 실제 시나리오와 새 건물의 일반화 성능을 구분. 새 건물만 재학습하거나 후보/파라미터 변경하지 않음.

원래 최종2023~2024 시험·운영·DB는 건드리지 않음. 양수면적 선택 편향과 개업당시 면적 미확인은 유지. 검사:기존지표 재현·건물그룹 합계·점차이 일치·재표집 결정성/동일예측0차이·시간분리·학습가용입력 확인.
