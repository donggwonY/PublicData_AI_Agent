# 42업종 확률 보정 계획

2026-11-10 실행 전 고정. 기존 LR(C=1, seed7) 특징은 업종·구군·운영기간 구간. 인허가 단위, 단기 행사 유지, 미래 기반 플래그 제외.

- 학습/보정/평가: 2011/2013/2015, 2013/2015/2017, 2016/2018/2020, 2018/2021/2023. 각 이전 연도 365일 결과가 다음 단계 시작 전에 종료되는지 검증.
- 미보정, 전체 절편, 업종별 축소(가상표본500), 업종·구군별 추가 축소(500)를 비교. 하위집단 보정 표본이 없으면 상위 보정을 유지. 단일 클래스에도 축소 적용.
- 기준선은 보정연도 업종 신고율, 없으면 학습 업종 평균, 그것도 없으면 전체 학습평균.
- Brier·log loss·평균확률 오차, 업종·구군별 소표본(n<200 또는 사건<20)을 함께 보고. 모델·보정계수는 평가 라벨을 사용하지 않는다.
- 앞선 실험과 학습기간이 달라 숫자를 직접 비교하지 않는다. 같은 실행 안에서 미보정과 비교한다. 평가연도 반복 및 후보 업종 사후 선택으로 독립 검증은 아니다. 2025·서비스·DB 미사용.
