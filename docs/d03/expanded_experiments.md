## 판단

세 기간 모두 두 확률 오차가 상수 기준선보다 작은 후보는 없었다. 공개 개인별 확률 안내를 보류한다. 내부 실험 비교 화면은 결과 설명용으로 사용할 수 있다.

## 검증·한계

기존 상수·기본 회귀·주변 회귀의 각 기간 지표를 재현 대조했다(범주 행렬 저장 방식 차이를 고려한 허용오차). 경계값 예제·자기제외·시간 간격·보정 기간 분리·표본 비중복·수렴·확률 범위 검사를 통과했다. 구군 및 새 건물 결과는 JSON에 보존했다.
기존 검증 결과를 본 뒤 정한14후보의 탐색이다. 이미 본 기간에서 선택했으므로 작은 차이는 독립적 입증이나 통계적 유의성을 의미하지 않는다. 현재 주소·신고 지연·최신 스냅샷 누락·좌표 제외와 같은 한계는 모델 변경으로 해결되지 않는다. 새 외부 과거 데이터는 추가하지 않았다.
isotonic은 끝값0/1을 출력할 수 있고 그 경우 log loss가 커질 수 있다. 지표 계산의 표준 수치 클리핑 외 별도 검증 기반 조정은 하지 않는다. 보정 자체 효과는 보정 비교용 과거 회귀와 비교해야 하며, 전체기간 후보와 학습량이 다르다.
평가 결과를 보고 추가 파라미터 탐색이나 기존2023~2024 시험 재평가는 하지 않았다. DB 적재·운영 배포는 미수행. 실행: 분석 환경에서 python scripts/fit_d03_expanded.py.


## 팀 전달용 해석

기준선을 포함한14개 방법을 세 시기에 비교했다. 기존 자료로 가능한 대표적인 접근인 최근 자료 학습·업태별 차이·트리 모델·시간 분리 확률 보정을 점검했다. 모든 가능한 알고리즘을 소진했다는 의미는 아니다.

세 기간 단순평균 Brier는 전체 학습 평균0.079763, 주변 입력 랜덤포레스트0.079808, 기존 회귀0.080292였다. 주변 랜덤포레스트가 기존 회귀보다는 평균 오차가 작지만, 전체 평균 기준선까지 안정적으로 넘어서지는 못했다. 작은 차이의 유의성은 확인하지 않았다. 평균 확률을 모든 점포에 동일하게 주는 기준선은 개별 점포를 구분하는 모델이 아니므로 이를 곧바로 개인별 위험 안내에 적용할 수는 없다.

이번 범위에서는 모델 종류만 바꿔 해결된다고 보기 어렵다. 다음은 과거 자료의 누락·수정 이력과 날짜 정의를 점검하고, 당시 매출·유동인구 등 새 자료 후보의 기간·공간 단위·공표 시점 확보 가능성을 검토하는 방향을 팀과 논의한다. 자료 확보가 성능 개선을 보장하지는 않는다. 공개 적용과 별개로 이 비교 결과를 설명하는 팀 검토 화면은 활용할 수 있다.

현재 실험 화면은 이전의3개 후보·주변 맥락 비교를 표시하며, 이14후보 결과는 본 문서와 JSON에서 확인한다. 화면에 새 결과가 자동 추가됐다고 간주하지 않는다. 공유 DB 연결 미확인 상태가 유지되어 이번 결과도 로컬 파일로만 저장했다.
