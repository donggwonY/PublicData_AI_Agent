# 과거 인구 연결 기준과 후속 실험 계획

2026-10-17. 로컬 일반음식점 인허가와 구군 월간 인구의 연결 가능성을 검증했다. 모델 재학습은 하지 않았다.

## 공개 시점과 가정

행정안전부 현재 안내는 월말 기준, 다음 달 1일 12시 이후 공표(주말·공휴일이면 다음 평일)라고 설명한다. 출처: https://jumin.mois.go.kr/statMonth.do (2026-10-17 확인).

과거 월별 실제 공개일·수정 이력은 미확인이다. 개업 시간이 없으므로 전월 자료를 일률적으로 연결하지 않는다. 탐색용 기본 규칙은 개업 월보다 2개월 전 인구이며 3개월 전을 민감도 대안으로 둔다. 이는 여유를 둔 이용 가능 시점 가정이지 과거 데이터 공개/무수정 증명은 아니다. 예: 2010-01-01 개업 → 2009-11 인구. 과거 공개일 필드는 계속 null로 유지한다.

주민등록 전체 통계는 거주불명자가 2010년 10월부터, 재외국민이 2015년 1월부터 포함되는 정의 변화가 있다(동일 공식 페이지). 장기 인구 변화를 모두 실제 인구 이동으로 해석하지 않는다. 사용자가 받은 CSV만으로 등록구분 선택의 모든 메타를 복원할 수 없어 원천 페이지 정의와 함께 보존한다.

## 연결 결과

| 기존 구분 | 인허가 | 연결 | 미연결 |
| --- | ---: | ---: | ---: |
| 학습 2010~2018 | 22,960 | 22,800 | 160 |
| 검증 2020~2021 | 5,681 | 5,643 | 38 |
| 이미 평가한 2023~2024 | 5,837 | 5,824 | 13 |
| 간격 연도 2019·2022 | 5,874 | 5,839 | 35 |

미연결은 전부 군위군 과거 자료 미확보다. 2개월·3개월 시차에서 연결 건수는 같지만 연결되는 월·값은 다르다. 군위군 0을 인구 0으로 처리하거나 최신 값으로 역채우지 않는다. 나머지 구군은 이름과 원천 구군 범위를 확인한 뒤 구군+기준월 다대일 연결을 적용했다. 과거 경계 정확도를 완전히 검증한 것은 아니다.

원본 해시·분석 입력 해시, 구군+월 유일성, 연결 후 행 수 보존, 인구 기준일이 개업일보다 앞섬, 연도 경계와 군위군 결측 예제 검사 통과. 실제 개업일 단위 결합 프레임은 스크립트 함수에서 생성하며 개인정보성 예측 목록은 별도로 저장하지 않았다.

## 후속 모델 실험 — 실행 전 고정안

- 첫 실험 결과는 보존한다. 이미 확인한 2023~2024년은 새 블라인드 평가로 부르지 않는다.
- 새 실험의 주 비교는 기존 학습/검증 기간에서 기존 대구 8개 구군만 사용한다. 군위군을 두 모델 모두에서 제외해 동일 모집단을 비교한다(학습 22,800·검증 5,643). 이를 전체 대구 결과로 일반화하지 않는다.
- 기준 후보: 업태·구군·개업 월 로지스틱 회귀를 동일 표본으로 다시 학습.
- 추가 후보: 같은 입력에 log1p(총인구), log1p(세대수) 추가. 수치 표준화는 학습 자료로만 적합, C=1·기존 설정 고정. 인구와 세대수의 높은 상관 및 지역 규모 대리지표라는 한계를 기록한다.
- 기본 2개월, 민감도 3개월로 사전 고정. 더 좋은 점수가 나오는 시차를 반복 탐색하지 않는다.
- Brier·log loss·AUC·평균 예측/실제 비율과 지역별 오차를 비교한다. 유의성·인과 개선을 주장하지 않는다.
- 기존 검증 결과도 이미 본 상태이므로 후속 탐색 실험으로 명시한다. 독립 성능 입증에는 별도 미래 자료 또는 사전 고정한 추가 시간 검증이 필요하다. 기존 최종 기간은 이번 주 비교에서 다시 채점하지 않는다.
