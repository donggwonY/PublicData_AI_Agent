# D-03 후속: 과거 주변 일반음식점 맥락 실험 계획

2026-10-28, 결과 확인 전 고정. 사용자 요청에 따라 첫 실험 이후 후속 탐색을 수행한다.

질문: 개업 전 주변 500m 일반음식점의 관측 영업 수·최근 365일 개업 수·폐업일 기록 수를 추가하면 확률 오차가 줄어드는가?

- 원천은 이전 D-03과 같은 stores.parquet 해시를 검증한다. 일반음식점만 대상으로 하며 2022년 이후 개업 기록은 특징 구축과 평가에서 제외한다.
- 각 대상 개업일에서 60일을 뺀 날을 cutoff로 사용한다. 모든 사건은 cutoff 미만만 세며 최근 구간은 [cutoff-365일, cutoff)이다. 60일은 신고 지연을 고려한 고정 가정으로 과거 공개 시점을 보증하지 않는다.
- 좌표가 유효한 동일 대상 표본으로 세 후보를 비교한다: 학습 사건 비율 상수, 기존 업태·구군·개업 월 회귀, 기존 입력+주변 맥락 회귀. 반경·시차·변수·C=1을 결과를 보고 조정하지 않는다. 수치형은 log1p 후 학습 표본으로만 표준화한다.
- 학습2010~2013/검증2015~2016, 학습2010~2015/검증2017~2018, 학습2010~2018/검증2020~2021. 정답365일 관측 간격 검사. 기존2023~2024 시험은 재채점하지 않는다. 이전 결과를 본 후 설계한 탐색이지 새 독립 시험이 아니다.
- Brier·log loss·AUC·평균 예측과 실제 비율, 구군 및 학습에 없던 건물 하위집단을 기록한다. 모든 창에서 두 확률 오차가 기존 회귀와 상수보다 작을 때만 다음 독립 평가 후보로 추천한다. 그렇지 않으면 공개 확률 안내는 보류하며 내부 실험용 비교는 가능하다.
- 특징 검증: 작은 예제의 경계값/자기제외, 미래 개업과 cutoff 이후 폐업일 변경에 대한 불변성, 실제 표본의 전체 거리 직접계산과 대조. 학습·검증 비중복 및 확률·수렴 검사를 수행한다.

현재 좌표·최신 스냅샷 생존 편향·원천 누락·신고 수정 이력 한계가 남는다. 인허가 건수는 고유 점포 수와 다를 수 있다. 폐업일 미기록은 폐업이 관측되지 않은 상태이며 과거 영업을 확정하지 않는다. 주변 일반음식점 이외 경쟁 업종은 포함하지 않는다. 좌표 누락 대상과 이웃은 제외하며 누락 규모를 기록한다. DB 또는 공개 서비스 변경은 이 실험의 완료 조건이 아니다. 공유 DB 설정이 맞지 않으면 로컬 산출물을 보존하고 적재 미수행으로 기록한다.
