# 동일 표본 비교

현재 면적의 과거 시점 유효성은 미확인이다. 누락 집단에 일반화하지 않으며 2023~2025 재평가 없음. 기본 회귀와 면적 랜덤포레스트의 차이는 알고리즘·입력 모두의 차이이므로 면적 효과만으로 해석하지 않는다. 면적 추가 효과는 같은 알고리즘의 context/area 쌍으로 판단한다.


## 비교 결과

면적 랜덤포레스트는 세 기간 모두 동일 표본 기본 회귀·상수·면적 없는 랜덤포레스트보다 Brier와 log loss가 낮았다. 기본 회귀 대비 Brier 감소율은 기간 순서대로 1.17%, 1.33%, 1.83%다. 이는 저장된 면적 모델 점수에 기본 회귀를 추가 대조한 결과이며 새 면적 모델의 개선은 아니다. 현재 면적의 시점 문제와 제외 집단의 과소예측은 해결되지 않았다.
