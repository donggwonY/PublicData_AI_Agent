# D-03 매장 면적 품질·시점 점검

## 확인 결과

2010~2021 일반음식점 31,674건(좌표 없는 행 포함). 양수 면적 30,885건(97.51%), 누락 565건, 0이하 224건. 양수 중앙값 53.43㎡. 숫자 변환 불가 비어있지 않은 원문 55건. 이 중 쉼표 제거로 숫자 변환 가능한 값 55건(진단만 수행, 기존 데이터 수정 없음).
가공 area_m2는 원본 소재지면적과 31,657건 일치; 원본 미연결 1건은 비교 불가; 연결 후 값 차이 16건. 시설총규모와 둘 다 값이 있는 경우 불일치 38건이므로 의미 확인 없이 서로 대체하지 않는다.

레코드 최종수정일이 허가일 이후인 행 31,212건. 이 날짜는 레코드 전체 수정일이며 면적 자체가 바뀌었다는 증거가 아니다. 반대로 허가일과 수정일이 같아도 당시 공개/측정 시점을 증명하지 못한다.

## 판단

현재 파일에 면적 변경 이력·면적 측정일/유효시작일은 없어 개업 당시 면적을 확정할 수 없다. 수치 보유율은 높으나 과거 예측 시점에 알 수 있었는지는 미확인이다. 현재값을 개업 당시값으로 가정해 학습·평가하지 않았다. 기존 모델/운영/DB 변경 없음.

## 후속 자료 조건

허가 당시 면적 또는 관리번호별 면적 변경 이력과 적용일이 필요하다. 이미 작성한 한시영업 자료 문의에 이 항목을 함께 요청할 수 있다. 확보 후0/누락을 별도 표시하고 학습기간에서만 대체/변환 규칙을 정하며, 과도한 값은 원본 검토 후 처리한다. 최대값만으로 오류나 정상 여부를 단정하지 않는다. 시설총규모를 자동 보충하거나 허가일 이후 수정된 행을 모두 삭제하지 않는다.

원본 키 유일성 검사 통과. 연결된 행의 값 차이도 별도 기록했으며 원본 버전 차이/가공 원인을 확정하지 않았다. 미연결 행은 제외/보정하지 않고 별도 집계. 좌표 유효 기존 검증기간별 품질은 [JSON](area_availability.json). 재현: `python scripts/audit_d03_area.py`.
