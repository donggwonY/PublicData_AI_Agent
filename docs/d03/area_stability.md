## 검증과 해석 제한

이전 RF/상수 지표 재현, 면적누락 입력 제외, 동일 표본과365일 관측 간격, 하위집단 합계, 건물 합계/점차이 일치, 재표집 결정성/동일예측 차이0 검사 통과. 건물키 없는 행은 개별 블록으로 처리하며 수는 JSON에 기록.

이 구간은 모델을 다시 학습하는 불확실성이나 모델 선택 과정을 반영하지 않는다. 인접한 다른 건물 간 상관도 남는다. 따라서 구간이0을 제외하더라도 새 자료의 일반화나 통계적 확증으로 과장하지 않는다. 원천의 개업당시 면적과 양수표본 선택 편향·축제영업 혼입은 여전히 미확인이다. 최종2023~2024 재평가,원본/운영/DB 변경 없음.

## 이번 판단

세 기간 모두 상수/면적없는RF 대비 Brier와 log loss 차이의 건물 재표집95% 구간 상한이0보다 작았다. 새 건물 표본3995/3791/2919건에서도 두 오차 모두 두 기준선보다 작았다. 새 건물 AUC는0.605/0.619/0.631로 제한적 구분력이다. 건물키 누락은 세 기간 모두0건이다.

기존 관측 표본에서 개선 방향이 일관된 후보라는 근거는 보강됐다. 하지만 이미 선택한 모델/기간의 사후 진단이며 과거면적 확인을 대신하지 않는다. 상권 실패 원인 설명이나 새 사용자의 개별 위험확률 보증으로 사용하지 않는다. 이 단계에서는 모델 설정을 고정해 보존하고, 다음 검증의 목적/기간/과거자료 가용성을 따로 정한다.
