# D-03 생존 기준선과 결과 예측 실험

**추가 실험·하위집단 진단 범위 완료 / 개인별 예측 서비스 적용은 보류 권고·팀 결정 대기.** 최신 결론과 남은 한계는 [완료 보고](closeout.md)를 기준으로 본다. 각 단계 보고서의 다음 단계 문구는 작성 당시 기록이다.

기준일 2026-10-13, 인허가 225,858건. 원천 업종명은 16개이고 의원·병원을 묶은 분석 그룹은 팀 합의대로 15개다. 원본 구분은 유지한다. 생존 요약 685행을 재현했으며 예측 실험은 일반음식점에 한정했다.

첫 모델의 최종 시험 평균 예측은 9.09%, 실제 365일 이내 폐업·취소·말소 신고 비율은 18.31%로 과소예측했다. 별도 동일 표본 비교에서 과거 구군 인구·세대수를 추가해도 확률 오차가 커졌다. 현재 후보는 서비스에 적용하지 않는다. 모든 추가 자료가 무용하다는 결론은 아니다.

## 2026-10-28 후속 실험

첫 실험 완료 기록은 유지하고, 멘토 피드백과 사용자의 추가 실험 요청에 따라 [과거 주변 상권 실험 계획](historical_context_plan.md)을 고정했다. [후속 결과](historical_context.md)에서 세 검증 기간의 동일 표본 비교를 확인한다. 기존 최종 시험을 재채점하지 않는다.

후속 결과: 과거 주변 맥락 추가는 2015~2016년만 확률 오차가 줄고 2017~2018년·2020~2021년은 악화했다. 세 기간에 걸친 개선 기준을 충족하지 못해 현재 후보의 공개 확률 안내 보류를 유지한다. 내부 비교 화면 구현·배포는 별도 후속 범위다.

[팀 검토용 실험 화면](experiment_viewer.md) 로컬 구현 완료: 기간별 예측·실제 비율과 오차 비교. 공개 배포·개인별 예측은 미수행.

## 14개 후보 추가 비교 (2026-10-28)

[확장 실험 결과](expanded_experiments.md): 최근 학습·업태별 차이·랜덤포레스트·부스팅·시간 분리 확률 보정을 포함한14개 후보를 세 기간에서 비교했다. 세 기간 모두 상수 기준선보다 두 확률 오차가 작은 후보는 없었다. 주변 랜덤포레스트가 모델 중 평균 Brier가 가장 작았으나 전체 평균 기준선보다 약간 컸다. 기존 최종 시험 재평가·DB 적재·배포는 미수행.

[추가 과거 자료 확보 조사](external_data_acquisition.md): 대구 빅데이터활용센터2026.09 목록·무료 분석 인프라·결과 반출 절차 확인. 유동/생활인구·카드 소비 후보와 미발송 문의 초안 정리. 원자료 확보·신청 완료 아님.

### 월별 지하철 후속 실험 (2026-10-28)

사용자 보유 월별 CSV를 활용한 [승하차 추가 실험](transit_experiment.md)을 완료했다. [사전 계획](transit_experiment_plan.md), [전체 결과](transit_experiment.json). 역 접근성과 이용량을 분리한 7후보·3기간 비교에서 이용량 추가 모델은 두 알고리즘 모두 세 기간 확률 오차가 증가했다. 기존 최종 시험·운영 앱·DB 변경 없음.

### 오차 진단과 한식 전용 모델 (2026-10-28)

[오차 분석](error_analysis.md)에서 기존 주변RF의 업태·구군·연도별 확률 오차를 점검하고 첫 학습기간 최대 표본 업태인 한식 전용 모델을 비교했다. 일부 기간 개선은 있으나 세 기간 공통 채택 기준 미통과. 2017~2018 호프/통닭의 과소예측은 원천/시기 차이를 검토할 단서로 기록했다. [계획](error_analysis_plan.md), [전체 결과](error_analysis.json).
