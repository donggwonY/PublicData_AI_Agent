# D-03 생존 기준선과 결과 예측 실험

**추가 실험·하위집단 진단 범위 완료 / 개인별 예측 서비스 적용은 보류 권고·팀 결정 대기.** 최신 결론과 남은 한계는 [완료 보고](closeout.md)를 기준으로 본다. 각 단계 보고서의 다음 단계 문구는 작성 당시 기록이다.

기준일 2026-10-13, 인허가 225,858건. 원천 업종명은 16개이고 의원·병원을 묶은 분석 그룹은 팀 합의대로 15개다. 원본 구분은 유지한다. 생존 요약 685행을 재현했으며 예측 실험은 일반음식점에 한정했다.

첫 모델의 최종 시험 평균 예측은 9.09%, 실제 365일 이내 폐업·취소·말소 신고 비율은 18.31%로 과소예측했다. 별도 동일 표본 비교에서 과거 구군 인구·세대수를 추가해도 확률 오차가 커졌다. 현재 후보는 서비스에 적용하지 않는다. 모든 추가 자료가 무용하다는 결론은 아니다.

## 2026-10-28 후속 실험

첫 실험 완료 기록은 유지하고, 멘토 피드백과 사용자의 추가 실험 요청에 따라 [과거 주변 상권 실험 계획](historical_context_plan.md)을 고정했다. [후속 결과](historical_context.md)에서 세 검증 기간의 동일 표본 비교를 확인한다. 기존 최종 시험을 재채점하지 않는다.

## 전체 대상 실험 실행 완료 — 2026-11-03

사용자가 Windows 설정을 변경한 뒤 기존 분석 환경에서 실행을 완료했다. 이전 실행 대기 안내를 대체하며 팀원 대행 실행은 더 이상 필요하지 않다. [전체 대상 결과](full_coverage.md), [수치](full_coverage.json).

면적·좌표 누락을 포함한 일반음식점에 업태·구군·개업 월만 사용한 로지스틱 모델은 2015~2016, 2017~2018, 2020~2021 세 기간 모두 전체 Brier와 log loss가 같은 표본의 학습 평균 기준선보다 높았다. 면적 제외 집단의 실제 신고 비율은 각각 86.61%, 89.55%, 65.17%였으나 예측은 7.62%, 7.00%, 8.85%로 과소예측했다. 누락 원인이나 누락 발생 시점이 확인된 것은 아니며 누락 여부를 예측 입력에 넣지 않았다.

입력 해시·날짜 간격·그룹 합계와 기존 2020~2021 점수 재현 검사를 통과했다. 이 결과는 전체대상 기본 모델의 한계이며 다른 면적 모델과 직접 성능 순위를 비교하지 않는다. 2023~2025 재평가, DB 변경, 서비스 적용은 하지 않았다. 현재 입력만으로 제외 집단까지 안정적으로 예측한다고 설명할 근거가 없어 서비스 적용 보류 결론을 유지한다.


### 동일 표본 기본 모델 대조 — 2026-11-03

[동일 표본 비교](matched_baseline.md) 완료. 기존 면적 RF는 세 기간 모두 기본 회귀·상수·면적 없는 RF보다 두 오차가 낮았다. 기존 결과를 재사용하고 기본 회귀만 추가 계산했다. 면적 보유 집단에서의 유용성과 전체 점포 적용 가능성을 구분하며, 과거 면적 시점·누락 집단 한계는 유지한다.


### 면적 없는 RF 추가 비교 — 2026-11-03
