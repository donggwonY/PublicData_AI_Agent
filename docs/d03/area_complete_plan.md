# 양수 면적 표본만의 추가 비교 계획

이전 면적 실험에서 누락 여부가 개선을 설명함을 확인한 뒤 사용자 동의로 진행하는 후속 탐색. 이전 실험에 쓰인 면적 복구 규칙과 세 기간 유지. 양수·유한 면적이 있는 동일 표본으로 학습/검증을 모두 제한하며, 5후보(상수·주변LR/RF·주변+log면적LR/RF)를 새로 학습한다. 면적 누락 지표는 입력에서 완전히 제거한다. 면적 외 입력/하이퍼파라미터는 유지한다.

평가 기준: 세 기간 모두 같은 알고리즘의 면적 없는 모델 및 상수보다 Brier/log loss가 낮은지. 면적 있는 표본만으로 대상이 바뀌므로 이전 전체표본 오차와 직접 비교하지 않는다. 제외 표본/사건 수와 새 표본을 기록한다. 개업당시 면적/공개일 미확인, 결측 표본 선택 편향, 반복 활용 검증이라는 한계는 남는다. 기존2023~2024 재평가·운영/DB 변경 없음.
