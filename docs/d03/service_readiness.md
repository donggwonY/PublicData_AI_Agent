# D-03 서비스 활용 검토안

2026-10-31. 팀 전달 전 로컬 정리 초안. 신규 모델 학습·운영 반영·배포·외부 전송은 하지 않았다. 이번 점검은 저장 결과 대조이며 모델 재현 실행은 아니다.

## 가장 유망한 결과와 선택 한계

평가 표본은 면적·좌표가 있는 일반음식점 2025년 1~9월 1,608건, 365일 내 신고 168건(10.45%). 초기 2023~2024 시험의 약 9%/18%와 평가 대상이 다르므로 그 차이를 개선량으로 계산하지 않는다.

| 비교 | 모델 | 평균 예측% | Brier | AUC |
| --- | --- | ---: | ---: | ---: |
| 면적 효과 | forest_context | 8.03 | 0.090090 | 0.6220 |
| 면적 효과 | forest_area | 8.15 | 0.084579 | 0.7060 |
| 보정 효과 | calibration_base_rf | 7.51 | 0.090100 | 0.7116 |
| 보정 효과 | sigmoid_rf | 9.99 | 0.084253 | 0.7116 |

면적 비교는 2010~2023 학습, 보정 비교는 2010~2021 기초 학습과 2023 보정이다. 보정 효과는 같은 기초 모델끼리만 비교한다. 위 네 모델 중 보정 모델의 Brier 점추정이 가장 낮지만 이를 전체 실험의 확정 우승 모델로 선정하지 않는다. 보정 전후 Brier 차이의 95% 건물 재표집 구간 [-0.019042, +0.002194]는 0을 포함한다. 평균 예측이 실제 비율과 가까워도 개인별 정확성이 입증된 것은 아니다.

근거: [면적 평가](area_2025.json), [확률 보정](area_calibration.json), [기간별 추가 보정 미채택](group_calibration.md).

## 남아 있는 오차

- 동구 237건: 보정 후 14.05%, 실제 26.16%. 특정 장소·한시영업 혼입 가능성은 조사했지만 전체 원인을 확정하지 않았다.
- 한식 698건: 보정 후 9.60%, 실제 7.59%.
- 보정 후 20% 이상 구간 191건: 평균 25.78%, 실제 35.60%.
- 업태 19개 중 11개, 구군 9개 중 6개, 면적 5개 중 3개에서 Brier 악화. 이 개수를 전체 정확도로 바꾸지 않는다.

현재 면적·주소가 개업 당시와 동일한지 미확인이고, 2025 표본을 여러 번 진단했으므로 신규 독립 시험이 아니다. 잘 맞는 집단만 사후 선택해 공개 대상으로 삼지 않는다. [하위집단](area_subgroups.md), [보정 구간](area_calibration.md).

## 임대료 검토 종료 지점

2022년 1층 표본 행수는 분기별 395/393/390/392. 달성군은 각 2행, 남구 19/17/17/17, 중구 149/149/146/147이다. 기존 전체 행수 합계와 일치 여부를 검사했다. 행은 고유 건물 수와 다를 수 있으며 1층 필터만으로 대표성·가중치·과거 시점 문제가 해소되지 않는다.

추가 예측 실험은 현재 자료로 보류한다. 도움이 없다는 성능 검증 결과가 아니라 입력 타당성 미확보 판단이다. 기존 상권 경계, 정확한 면적·가중치, 공표 시점·당시 공개본 증거를 확보하거나 대체 변수의 정의를 사전에 정할 때 재개한다. [1층 점검](rental_first_floor.json), [공식 설명 및 제한](public_data_followup.md).

## 서비스 표시 초안

현재 권고는 검증된 과거 집계 설명과 연구용 모델 비교다. 아래는 제품 반영 전 문구·동작 제안이며 구현·승인이 아니다.

| 위치 | 표시 초안 | 적용 조건 |
| --- | --- | --- |
| 과거 통계 | “선택한 조건에서 개업 후 365일 이내 폐업·취소·말소가 신고된 비율입니다. 실제 사업 실패율과 다를 수 있습니다.” | 기간·기준일·대상 수·신고 수·365일 관측 가능 여부 함께 표시 |
| 연구용 비교 | “2025년 1~9월 평가 표본 1,608건에서 보정 모델 평균 예측은 9.99%, 실제 신고 비율은 10.45%였습니다. 과거 자료를 이용한 탐색 결과이며 개별 가게의 확률 정확성을 보장하지 않습니다.” | 연구용 명시, 같은 표본 비교, 학습·보정 기간 및 구간별 오차 제공 |
| 작은 집단 | “표본 또는 신고 건수가 적어 해석에 주의가 필요합니다.” | 기존 진단 기준 n<100 또는 신고/비신고 각각 10건 미만 표시. 서비스 허용 기준으로 해석하지 않음 |
| 입력 불일치 | “현재 자료로는 이 결과를 제공할 수 없습니다.” | 기준일·입력 버전·지표 정의 불일치, 필수 자료 누락 시 임의 대체 금지 |

개별 가게의 공개 폐업 확률, 창업 성공/실패 판정, 안전한 지역 순위, 실제 공실률로의 표현은 현재 근거로 제안하지 않는다. 예측은 일반음식점 대상이며 15업종 전체로 확장하지 않는다.

기존 연구용 화면은 [실행 안내](experiment_viewer.md)에 구현·검사 범위가 기록돼 있다. 이번에는 화면을 변경하거나 재실행하지 않았다. 해당 화면의 기존 로컬 검사와 공개 배포 검증은 구분한다.

## 팀에 남길 결정

1. 기존 과거 통계와 연구용 비교를 어느 화면·사용자 범위에 공개할지.
2. 개인별 예측을 추가 목표로 유지할 경우 아직 사용하지 않은 미래 자료 평가와 당시 입력 확보의 담당·범위.

로컬 자료로 가능한 이번 준비는 완료했다. 원본 이력·공식 가중치 확보 및 제품 공개 결정은 완료로 표시하지 않는다. 사용자의 공유 요청 전 외부 전송하지 않는다.


## 추가 비교 반영

[4개 고정 후보 비교](ensemble_results.md) 완료. 로지스틱 혼합은 2/3 과거 기간에서 개선했지만 전기간 기준 미통과. 지역별 악화도 남아 서비스 권고를 변경하지 않는다. 2025 결과는 다시 평가하지 않았다.


추가 입력 탐색: [같은 건물의 과거 이력](building_history.md). 2후보 모두 2/3기간에서 대응 대조보다 두 오차 감소, 첫 기간 악화로 전기간 기준 미통과. 2025 재평가·운영 변경 없음.

지역별 추가 진단: [건물 이력 효과 분해](building_history_groups.md). 2017~2018은 중구에 개선 집중, 2020~2021은 7/9 구군 개선. 집계 대조 완료, 재학습·채택 없음.

건물 이력 안정성: [건물 단위 2000회 재표집](building_uncertainty.md). 2020~2021 두 후보의 두 오차 구간은 개선 방향, 다른 기간은 제한적. 고정 모델 조건부 진단이며 전기간 채택 기준 미통과 유지.
