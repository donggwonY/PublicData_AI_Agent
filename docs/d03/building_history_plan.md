# 같은 건물의 과거 이력 추가 계획

2026-10-31 결과 전 고정. 기존 주변 500m 집계와 별도로 같은 building_key의 일반음식점 관측 영업 수·최근365일 개업 수·폐업일 기록 수를 추가한다. 각 대상 개업 60일 전 미만만 사용하며 동일 건물은 같은 점포/층을 뜻하지 않는다. 현재 건물키의 과거 동일성·과거 공개일은 미확인이다.

기존 ensemble 비교의 양수면적·좌표 유효 표본 및 3기간 분할을 그대로 유지한다. 원본 이웃은 기존과 동일하게 일반음식점/유효좌표/2022년 이전이다. 건물키 누락은 0집계+누락표시, 수치는 log1p. 결과나 현재 상태를 특징으로 쓰지 않는다. 미래 폐업일은 cutoff 이전 집계에 영향 없어야 한다.

후보2개: 기존 RF에 건물이력4입력(3집계+키누락)을 추가한 무보정, 같은 모델의 과거 별도기간 sigmoid(C=1) 보정. 기존 무보정RF 및 정규화보정RF와 각각 비교한다. 설정·60일 시차·변수 재탐색 없음. 3기간 모두 대응 대조보다 Brier/log loss 감소해야 다음 검증 후보로 남긴다. 상수 및 구군/업태 결과도 보존. 2023~2025 재평가 없음.

입력해시·기존RF재현·동일표본/사건·365일 간격·확률·집단가중합계를 검사한다. 합성 사례에서 cutoff 경계·미래정보 불변성을 확인하고 실제 일부 행을 독립 직접집계로 대조한다. 이번은 반복 과거기간 탐색이며 서비스 효과 입증이 아니다. 운영/DB 변경 없음.
