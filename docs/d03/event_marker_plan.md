# 행사 표기 후보 분류 계획 — 2026-11-04

대상은 가공본의 전체 일반음식점이며 원본을 관리키로 연결한다. 분류에는 원본 지번주소·도로명주소·상호만 사용하고 폐업일·폐업여부·영업기간을 읽지 않는다.
주소에 `행사장` 또는 `축제장`이 있으면 explicit_address, 나머지 중 주소나 상호에 `축제|페스티벌|행사장|한시영업|임시영업|팝업`이 있으면 review_keyword로 표시한다. 나머지는 no_marker, 원본 미연결은 unmatched다. 문자열 정규화는 공백 제거만 한다. 상호의 축제·팝업 등은 상설 상호일 수 있어 자동 확정하지 않는다.
분류 규칙은 모든 개업 연도에 동일하게 적용하고 연도별 건수만 보고한다. 2023년 이후에도 정답·예측을 계산하지 않는다. 표기없음은 상설점포 확정이 아니며 명시 표기도 법적 한시허가 또는 개업 당시 정보 가용성의 증명이 아니다. 원본 삭제·재학습·DB 변경 없음.
