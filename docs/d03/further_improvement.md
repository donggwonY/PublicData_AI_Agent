# 추가 오차 개선 검토 — 2026-10-31

## 최신 실행 상태

기존 service/.venv의 sklearn은 정상 작동하여 동일 계획 비교를 완료했다. 아래 최초 중단은 과거 경과다. [완료 결과](ensemble_results.md): 신규 4후보 중 고정 통과 기준 만족 없음. 로지스틱 혼합은 2/3기간 개선했으나 일관된 개선이나 2025 오차 해결을 입증하지 못했다.

## 최초 실행 상태

사용자 요청에 따라 새 자료 없는 개선 후보를 검토했다. 기존 지역/업태 보정, 최근 자료 학습, isotonic 등은 이미 비교했으므로 반복하지 않는다. 이번 고정 후보는 면적 로지스틱과 ExtraTrees의 시간분리 보정 및 각각과 RF의 50:50 혼합이다. [계획](ensemble_plan.md), 실행 코드 scripts/fit_d03_ensemble.py.

실행은 sklearn import 중 Windows 앱 제어 정책의 DLL 차단으로 중단됐다. 모델 학습 전 실패했으므로 신규 점수·개선·검증 통과를 주장하지 않는다. 코드 구문 검사만 통과했으며 실행 검증은 미완료다. 보안 설정 변경·차단 우회·라이브러리 재설치 없음. 조직/사용자가 허용한 분석 환경에서 동일 계획을 실행해야 한다. scripts/pull_main.py 또한 미커밋 변경으로 중단되어 최신 원격 동기화 미확인이다.

## 시도할 가치와 한계

1. 다른 기초 모델과 고정 혼합: 같은 RF의 지역 보정과 달리 학습 방식의 차이를 비교한다. 모델 간 오류가 다르면 혼합이 도움이 될 수 있으나 실제 개선 여부는 미확인이다. 후보·혼합비율은 결과를 보고 다시 고르지 않는다.
2. 한시영업 사건 분리: 동구 오류 집중 원인 후보지만 결과를 본 뒤 행사/단기 신고를 임의 삭제하면 대상이 바뀐다. 개업 당시 확인 가능한 한시영업 표시를 확보한 뒤 별도 대상 정의와 시간분리 검증이 필요하다. 현재 독립 식별 자료가 부족해 실행하지 않는다.
3. 당시 면적·주소 복원: 유망한 면적 모델의 시간상 입력 불확실성을 줄이는 방법이다. 오차 감소 보장이 아니라 타당성 개선이며 원본 이력이 필요하다. 외부 요청 보류 유지.
4. 미래 기간 검증: 이미 살펴본 2025 집단 오차에 맞춰 튜닝하지 않는다. 현재 스냅샷으로 아직 365일 관측하지 못한 최근 개업자를 임의 평가하지 않는다.

이번 후보 비교가 통과해도 집단별 악화, 작은 표본, 반복 검증기간 재사용이 남는다. 서비스 선택은 별도다. '모든 가능한 방법을 소진했다'거나 '더 개선 불가능하다'고 결론내리지 않는다. DB·운영·외부 전송 없음.
