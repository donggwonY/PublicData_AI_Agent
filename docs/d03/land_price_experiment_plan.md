# 공시지가 추가 탐색 사전 조건

2026-11-07 확대 수집 및 모델 실행 전 고정. 기존 구군별100필지 표본 900곳을 대상으로 과거 공시지가 수집. 인허가 기준일 영업점의 다음365일 폐업 신고 예측. 2013→2015, 2015→2017, 2018→2020, 2021→2023 네 기간.

각 기준일보다 공시일이 빠르고 기준연도가 이전인 행 중 가장 최근 공시일을 선택. 같은 공시일 가격 충돌은 제외. 양수 가격만 사용. 같은 연결 표본에서 운영기간 5구간 LR와 운영기간+log(공시지가) LR 비교, C1/max_iter2000/seed7. 숫자 표준화는 학습자료만. 학습평균 기준선도 보고. 기간별 Brier/log loss/AUC와 표본수를 모두 공개. 2025는 이번 후보 비교에 사용하지 않음.

현재 필지의 과거 이력으로 분할·합병과 사후 수정, 과거 주소 동일성을 입증하지 못함. 과거 영업점도 최신 인허가 스냅샷에서 재구성. 필지 가격은 점포 임대료가 아님. 구군균등 표집과 연결 제외로 전체 대표성 없음. 기존에 본 연도 재사용 탐색이며 신규 독립 최종평가 아님. 서비스/DB 자동 반영 없음.
