# 운영기간을 포함한 동일 입력 기준선 비교

모델의 입력인 업종·지역·운영기간을 모두 사용한 단순 신고율 표와 비교했습니다. 이전 보정연도만 사용하고 지역과 운영기간 단계에 가상표본500으로 축소합니다. 축소하지 않은 표도 함께 보고합니다. 설정 변경·재학습은 하지 않았습니다.

|기간|분기|모델이 지역평균보다 두 오차 개선|모델이 운영기간 축소평균보다 개선|모델이 운영기간 단순평균보다 개선|
|---|---:|---:|---:|---:|
|전체|96|73|71|92|
|2013년 이후|52|52|52|52|
|최근3년|12|12|12|12|

업종별 상세 점수·미관측 운영기간 조합 수는 JSON에 보존했습니다. 동일한 입력정보를 쓰더라도 함수형태와 축소강도가 달라 특정 기준선이 반드시 강하다고 가정하지 않습니다. 분기별로 유리한 모델을 골라 최종 성능으로 보고하지 않습니다. 기존 실험의 사후 검증이며 서비스 모델은 변경하지 않았습니다.

## 해석

운영기간까지 같은 입력을 제공한 기준선에도 최근52분기에서 두 오차 개선이 유지되었습니다. 따라서 지역·운영기간 정보를 모델만 사용한 비교에서만 얻은 개선은 아닙니다. 다만 주 기준선의 축소강도500에 조건부인 비교이며 모든 가능한 단순 기준선보다 낫다는 의미는 아닙니다. 최신2025-10 시점 Brier 상대감소는 0.54%로 작습니다. 충분표본 업종24개 중 두 오차 개선은15개로 전체 평균과 업종별 결과를 구분해야 합니다.
