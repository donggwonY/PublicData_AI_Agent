# 호프/통닭 폐업 신고 집중 원인 점검

2026-10-28. 기존 모델·학습표본·예측값은 변경하지 않았다.

## 관찰

- 기존 검증 동일 표본 504건, 1년 이내 신고 107건(21.23%).
- 2017-07-23/26, 2018-07-23의 신고 67건. 그중 허가 월7월·공원순환로 주소 후보 65건.
- 원본 관리번호+자치단체코드 연결 점검: {'ld_mismatches': 0, 'cd_mismatches': 0, 'raw_matched': 504, 'raw_unmatched': 0, 'category_mismatches': 0}. 원본과 가공본의 기록 일치 여부이며 실제 영업 종료의 진위를 보증하지 않는다.

[공식 축제 연혁](https://chimacfestival.co.kr/page/info_history.php)과 [대구시 2017 안내](https://thegoodnight.daegu.go.kr/kr/community/community_01.asp?bcate=&board_id=1&gotoPage=98&idx=599&menu=&mode=cont&snm=&srch_Flag=&srch_Word=&subchk=)에서 2017년7월19~23일, 2018년7월18~22일 두류공원 축제 일정 확인. 주소·짧은 허가 기간·폐업 신고일 패턴으로 축제 한시 영업 혼입 가능성을 추론한다. 개별 부스 참가/한시 허가 확정 근거는 아직 없다.

## 사후 민감도 진단

위 후보를 가정상 제외하면 439건 중 42건(9.57%)이다. **폐업 결과를 보고 만든 후보 조건이라서 모델 성능 개선이나 새 검증 결과로 해석할 수 없다.** 기존21.23%를 오류라며 덮어쓰거나 이 조건으로 학습 데이터를 삭제하지 않았다.

## 다음 조치

상설 음식점의 실패 위험을 목표로 할 경우 한시/행사 인허가를 구분할 필요가 있다. 허가 당시 확인 가능한 한시영업 표시·허가기간·행사 참가 명부를 먼저 확보/확인하고, 폐업일 없이 적용 가능한 기준을 모든 학습·검증기간에 일관되게 정의한 뒤 새 실험을 계획한다. 단순 단기폐업 전체 삭제는 정상 실패 사례까지 제외하므로 하지 않는다. 축제 효과와 일반 영업 실패를 같은 사건으로 취급했을 가능성에 대한 단서이며, 모든 예측 오차가 해결된 것은 아니다.
