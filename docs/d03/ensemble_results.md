## 실행 환경과 후속 해석

기존 service/.venv 환경에서 실행 완료. Python 3.12.14, sklearn 1.9.1, numpy 2.3.5, pandas 3.0.1. Parquet 읽기 의존성은 기존 d03-viewer-20261028 경로를 마지막 검색 경로로 사용했다. 차단된 임시 sklearn 복사·정책 변경 없음. 기존 RF 3대조 점수와 입력 해시·표본·집단 합계 검사를 통과했다.

| 평가기간 | 로지스틱 혼합의 Brier 변화(RF 정규화보정 대비) | 구군 Brier 악화 | 업태 Brier 악화 |
| --- | ---: | ---: | ---: |
| 2015-2016 | +0.00002001 | 5/9 | 11/23 |

Brier 변화가 음수면 개선이다. 로지스틱 혼합은 두 기간에서 두 RF 보정 대조보다 Brier와 log loss가 작지만 첫 기간 정규화보정 대비 악화한다. 고정 기준을 통과한 후보는 없으며 일부 기간 개선은 작은 점추정 차이다. 유의성 입증·동구2025 오차 해결로 해석하지 않는다. 2025 재채점이나 결과 기반 혼합비율 변경은 하지 않았다. 현재 공개 개인별 확률 보류 권고 유지.
