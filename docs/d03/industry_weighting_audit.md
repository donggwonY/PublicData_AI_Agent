# 업종 비중과 평가 구성의 영향

비교 대상은 업종·지역·운영기간 축소평균500입니다. 가중 방식의 효과와 업종 구성 차이를 혼동하지 않도록 동일한 업종·표본에서 점포수 가중과 업종 동일가중을 비교했습니다.

|기간|대상 선정|업종 수|평가분기|점포수 가중 개선|업종 동일가중 개선|
|---|---|---:|---:|---:|---:|
|전체|해당 분기 충분표본 업종|9~25|96|70|54|
|전체|기간 공통 충분표본 업종|7~7|96|80|83|
|2013년 이후|해당 분기 충분표본 업종|18~25|52|52|43|
|2013년 이후|기간 공통 충분표본 업종|15~15|52|52|48|
|최근3년|해당 분기 충분표본 업종|21~24|12|12|10|
|최근3년|기간 공통 충분표본 업종|19~19|12|12|11|

개선은 모델의 Brier·log loss 모두 기준선보다 작은 경우입니다. 충분표본 기준은 n≥200·신고≥20이며 평가 자료에 기반한 사후 분석 범위입니다. 공통 업종은 해당 기간 전체에서 이 조건을 충족한 교집합으로, 서비스 허용 목록으로 사용하지 않습니다.

전체 업종별 건수 가중 점수에서 개선됐더라도 모든 업종에 균등한 개선이 있다는 뜻은 아닙니다. 반대로 동일가중 결과가 일부 나빠졌다는 사실만으로 전체 모델이 무효라고 해석하지 않습니다. 평가 대상과 가중 방식에 따라 서로 다른 질문에 답하는 지표입니다. 모델 변경·재학습·서비스 반영 없음.
