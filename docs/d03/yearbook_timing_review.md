# 사업체 통계 시점 확인 결과

2026-11-09 공식 일러두기·사업체조사 머리말 8페이지 확인.

- 수성구 `2019st/0502.html` 보고서 머리말: 2020년6월.
- 수성구 `2021st/0502.html` 보고서 머리말: 2022년8월, 2020년 기준 조사라고 명시.
- 두 지역2019/2021판 일러두기는 각각 원칙적 최종수록연도2018/2020 말이라고 설명. 개별표 주석 우선.

폴더의 연도는 실제 공개일이 아니다. 수성구2019판 자료를2019년 예측에,2021판 자료를2021년 예측에 즉시 사용하면 미래자료 혼입 가능성이 있다. 보고서 머리말 시점을 다른 연보 표의 정확한 온라인 공개일로 단정하지 않는다.

- 현재 설명·과거 통계 소개: 출처와 실제 기준연도 표시 후 사용 후보. 모델효과 검증과 별개.
