## 효과 크기와 지역별 제한
상대 감소가 양수면 개선, 음수면 악화다. 설정·변수·시차는 평가 후 변경하지 않았다.

판정: 후속 검증 후보로 보존하되 채택하지 않는다. 두후보 모두 2/3기간에서 대응 대조보다 Brier/log loss가 작았지만 첫 기간은 악화. 개선 크기는 작으며 신규 독립 검증이나 2025 동구 오차 감소를 입증하지 않는다. 현재 건물키를 사용하므로 같은 점포/층의 이력이나 당시 주소를 보증하지 않는다.

건물키 누락은 특징 생성 대상 30,580행 중 0행. 합성 날짜 경계·미래 폐업일 불변성, 실제 3행 독립 집계, 이전 RF 점수 재현, 입력 해시·시간 분리·집단 합계 검사를 통과했다. 새 미래자료 평가 전 사용 범위를 확대하지 않는다.
