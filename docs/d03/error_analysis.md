## 검증과 한계

기존 RF 점수 재현, 시간 간격/표본 분리, 하위집단 표본·사건·가중 Brier 합계, 수렴·확률 범위 통과. 인허가 상태/현재 주소의 과거 정확성·신고 지연 미검증. 업태별 오차는 원인 규명이 아니며 작은 차이의 통계적 유의성을 주장하지 않는다. 전용 모델의 입력/설정 변경이나 검증 결과에 따른 업태 교체를 수행하지 않았다.

다음 독립 평가 기간은 이번에 선정하지 않았다. 원본 면적 등의 개업 당시 가용성도 별도 확인이 필요하다. 운영 서비스·DB·푸시 변경 없음. [계획](error_analysis_plan.md), [전체 결과](error_analysis.json). 재현: 기존 분석 환경에서 `python scripts/analyze_d03_errors.py`.

## 이번 판단

2017~2018 호프/통닭504건은 실제21.23%, 기존 주변RF 예측6.07%로 큰 과소예측이 관찰됐다. 이 결과만으로 원인을 특정할 수 없으며 업태 분류/신고 기록/시기별 사건 비율을 먼저 검토할 후속 단서다. 한식 전용 모델은 일부 기간만 개선했고 세 기간 일관된 개선 기준은 통과하지 못했다. 전용 모델로 바꾸는 것만으로 해결됐다고 판단하지 않는다.
