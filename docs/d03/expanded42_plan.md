# 42업종 확대 실험 계획

2026-11-10 실행 전 고정. 2026-11-06 스냅샷, 인허가 단위로 기준일 영업 기록의 다음 365일 폐업 신고를 평가한다. 의원·병원은 통합한다.

- 학습→평가: 2013→2015, 2015→2017, 2018→2020, 2021→2023. 2025는 이번에 평가하지 않는다.
- 기준선: 업종별 학습 신고율. 미관측 업종만 전체 학습 신고율 대체.
- 후보: 기존 통합 LR(C=1), RF(150트리, 깊이8, 최소잎30, sqrt, seed7). 탐색·튜닝 없음.
- 특징: 업종, 구군, 기준일 운영기간 5구간. Brier·log loss·AUC와 업종별 소표본 여부를 보고한다.
- 최신 데이터의 단기행사·겸업 플래그는 미래 폐업을 반영할 수 있어 예측 특징과 제외 기준으로 사용하지 않는다. 서비스 통계와 단위·제외 대상이 다르다.
- 기존 연구 결과를 덮어쓰지 않는다. 반복 평가연도이므로 탐색 결과이며 독립 최종 평가·서비스 채택이 아니다. 현재 주소의 과거 유효성과 기록 수정 시점도 미확인이다.
