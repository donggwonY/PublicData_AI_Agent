# D-03 운영기간 후속 모델 비교

기준일 기록상 영업점의 다음365일 폐업·취소·말소 신고 예측. 운영기간은 인허가일부터 기준일까지 일수. 과거 상태는 최신 기록으로 재구성하며 휴업·재개업·명의변경을 확인한 실제 연속 운영기간이 아니다.

사전 고정: 2013→2015,2015→2017,2018→2020 각1월1일. C=1 로지스틱, 운영기간365일 기준 <1/1-3/3-5/5-10/10+ 구간. 단순평균·운영기간만·업태구군·업태구군운영기간 4후보. 후속 사전고정 RF150트리·깊이8·잎30·sqrt·seed7, 건물단위1000회 고정예측 재표집 추가. 현재 면적 제외. 결과 후 튜닝 없음.
