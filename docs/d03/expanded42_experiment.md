## 해석

전체 Brier는 두 모델 모두 네 기간에서 기준선보다 낮지만 개선 폭은 작습니다. 2023년 통합 LR은 평균 7.98%, 실제 9.14%로 과소예측이 남습니다. 소표본이 아닌 네 기간 모두에서 한 모델 이상이 두 오차 지표를 개선한 업종은 미용업·이용업·일반음식점·제과점·즉석판매제조가공업·체육도장업·축산판매업·휴게음식점입니다. 이는 후속 검토 후보이지 채택 결과가 아닙니다. 업종별 관찰기간과 기준선 대체 여부는 위 표로 구분합니다.
