# 2026-11-16 후속 검증: 주변 건물 집계·세부 업태·비선형 모델

## 결론

현재 자료에서 확인 가능한 반복 기록의 영향을 특성 생성 단계까지 줄였으나, 주변 업종 구성의 안정적인 추가 예측 효과는 확인되지 않았다. 세부 업태 추가는 작은 개선을 보였지만 과거 정보 여부가 확인되지 않았다. 트리 모델도 주변 구성을 추가한 효과가 평가연도·거리마다 달랐다. 기존 결론을 뒤집는 근거로 사용하지 않는다.

## 수행 범위

동일 평가집단에서300m·500m × 2022·2023·2024년을 비교했다. 건물 표현·세부 업태를 포함한8개 선형 조건48회,4개 트리 조건24회 적합을 수행했다. 설정 탐색 없이 동일 설정을 사용했다. 건물 단위 재추출 및 학습에 없는 건물 부분집단 검사도 수행했다. 독립 시험자료가 아닌 반복 열람한 평가자료의 탐색 실험이다.

## 건물 기준 재계산

같은 건물·같은 업종의 반복 인허가는 한 번만 반영했다. 하나의 건물에 서로 다른 업종이 있으면 건물의 기여1을 업종 수로 나눠 반영했다. 따라서 비중은 점포 점유율과 다르다. 같은 건물을 포함한 경우와 대상 건물 전체를 제외한 주변만의 경우를 함께 평가했다. 학습·평가 표본과 건물 가중은 기존 방식과 동일하다.

|비교|두 오차 모두 개선/6|Brier 상대 감소 범위(%)|
|---|---:|---:|
|기존 인허가 구성 → 건물 구성|2/6|-0.1524 ~ 0.0624|
|건물 수 → 건물 수+구성|3/6|0.0086 ~ 0.3069|
|대상 건물 제외: 건물 수 → 구성 추가|4/6|-0.0061 ~ 0.1454|
|기존 모델 → 세부 업태 추가|6/6|0.0560 ~ 0.1853|

양수는 오차 감소, 음수는 증가다. 정확도 증가율이 아니다. 세부 업태(category)는 현재 스냅샷의 값이며 개업 당시 상태·변경 이력을 확인하지 못했다. 개선이 있어도 과거에 실제 사용할 수 있었던 변수로 간주하지 않는다.

## 비선형 모델

HistGradientBoostingClassifier를 고정 설정(200회, 학습률0.05, 최대15잎, 최소100행/잎, L2=10, 조기종료 없음)으로 비교했다. 주변 건수만 포함한 트리와 구성을 추가한 트리를 비교하므로 모델 종류 변경 효과와 주변 구성 효과를 분리한다.

|동일 트리 모델 내 비교|두 오차 모두 개선/6|새 건물에서 두 오차 개선/6|
|---|---:|---:|
|인허가 구성 추가|4/6|3/6|
|건물 구성 추가|3/6|2/6|

건물 단위1,000회 짝지은 재추출에서 두 오차 차이의95% 구간이 모두 개선 쪽에 있었던 비교는12개 중1개였다. 다중비교를 보정하지 않은 탐색 구간으로, 해당 경우를 확정적 성공으로 선택하지 않는다. 인접 건물의 공간적 상관은 별도로 해결하지 못한다.

## 한계 및 반영 상태

현재 좌표·건물키로 과거를 복원했다. 건물은 독립 점포와 같지 않으며, 업종별 균등 배분은 분석용 표현이지 실제 점포수를 복원한 결과가 아니다. 평가연도를 반복 확인했으므로 좋은 결과만 골라 새 검증으로 보고할 수 없다. 개인별 폐업 확률·창업 추천·공개 서비스 변경 및 DB 반영은 하지 않았다.
