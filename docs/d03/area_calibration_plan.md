# 면적RF 과거연도 확률보정 후속 계획

2026-10-28.2025평가에서 과소예측을 본 뒤 정한 탐색이며2025를 미사용 시험으로 다시 부르지 않는다.2025결과에 맞춘 계수/방법 선택 금지.

RF학습2010~2021,2022관측간격,보정2023,2024관측간격,비교2025년1~9월. 기존양수면적·주변맥락·범주입력/파서/RF설정 고정. sigmoid 보정 하나만: 기존RF 예측의 logit(1e-6 clipping)에 LogisticRegression C=1e6,max_iter2000,seed0을2023라벨만으로 적합. 보정자료로 RF를 재학습하지 않는다.2010~2023전체학습RF와전체학습평균도 기존지표재현용 비교기준으로 유지.

중요 비교는 같은 기초RF의 보정전/후이며 전체학습RF와는 학습자료량 차이가 있다.2023이전/2023/2025각365일간격과표본분리 확인.2025에 대한 Brier/logloss,AUC,예측평균/실제비율,고정확률구간별관측비율,건물단위보정전후차이구간 기록. 후보선택/보정계수 재조정 없음. 과거면적미확인·반복검증·한시영업혼입·양수선택 한계유지. 운영/DB/배포 변경없음.
