2026-11-03. 팀 일괄 공유 준비용이며 이 문서는 아직 외부로 전송하지 않았다. 사용자는 A-01 검토 답장과 동권에게 예측 방향 답장을 보냈다고 알렸다. 아래는 기존 저장 결과 요약이며 오늘 새 모델 학습·DB 조회를 한 결과가 아니다.

## 제안과 팀에서 결정할 것

현재 제안은 과거 집계 설명과 연구용 모델 비교 활용이다. 개별 점포의 공개 확률 채택은 보류 권고이며 팀의 제품 결정이 완료된 것은 아니다.

1. 연구용 비교 화면을 공개할지와 공개 범위.
2. 동권의 새 예측 주제가 정해지면 목표·담당을 나눠 중복 실험을 피하기.
3. 기존 폐업 신고 예측을 재개할 경우 독립 평가 기간·당시 입력자료·평가 기준부터 정하기. 추가 자료요청은 현재 보류 유지.

## 화면 공유 순서

1. [서비스 활용 검토안](service_readiness.md): 최신 성과와 지역별 오차, 표시 문구.
2. 질문이 있으면 [건물 이력 안정성](building_uncertainty.md): 일부 기간 개선의 범위.
3. [D-04 완료 범위](../d04/closeout.md): 데이터 품질과 미해결 항목.
4. [A-01 검토 결과](../d04/a01_cross_review.md): 동대구역 300m42건/동일행 제거41건, 500m72건/70건 및 출구별 배정 일치.

## 짧은 공유 문안 — 미전송

일반음식점 폐업 신고 예측은 면적·확률 보정·모델 혼합·같은 건물의 과거 개폐업 이력까지 추가로 비교했습니다. 일부 기간에서는 오차가 줄었지만 지역·시기별 차이가 남아 개별 점포의 공개 예측은 아직 보류하는 쪽으로 정리했습니다. 건물 이력은 후속 검증 후보로 남겼고, 임대료는 자료 연결과 표본의 한계로 적용을 보류했습니다.

D-04 데이터 품질·공유DB 집계 검증과 A-01 출구·상가 결합 교차 검토도 현재 범위에서 마쳤습니다. 연구용 결과를 서비스에서 어디까지 보여줄지와 새 예측 주제의 담당 범위를 맞추면 될 것 같습니다.

# D-03 팀 공유 초안

> 아래 메시지는 초기 실험 당시 초안이다. 최신 면적·보정 결과와 임대료 검토는 [서비스 활용 검토안](service_readiness.md)을 기준으로 갱신해야 한다. 사용자가 일괄 공유를 요청하기 전에는 전송하지 않는다.

아래는 전송하지 않은 공유 초안이다. 저장소 원격 반영 여부는 공유 전에 확인한다.

> D-03에서 일반음식점의 개업 후 1년 이내 폐업 신고를 예측해 봤습니다. 최종 평가에서는 평균 예측이 약 9%인데 실제 신고 비율은 약 18%여서, 지금 모델을 서비스에 쓰기는 어렵다고 판단했습니다. 과거 인구·세대수도 추가해 봤지만 확률 오차가 더 커졌습니다. 이번 실험과 한계는 정리했고, 인구 자료는 후속 검토용으로 보관했습니다. 다음 회의에서는 기존 통계 설명에 집중할지, 과거 상권 자료를 추가 확보해 예측 실험을 이어갈지 논의하면 좋겠습니다.

## 화면 공유 순서

1. `docs/d03/closeout.md`의 결과 표: 무엇을 시도했고 왜 적용을 보류했는지 설명한다.
2. `docs/d03/final_evaluation.md`: 질문이 나오면 9.09%와 18.31%의 차이를 확인한다.
3. `docs/d03/population_validation.md`: 인구 추가가 같은 8개 구군 표본에서도 확률 오차를 줄이지 못했음을 보여준다.

## 회의에서 정할 것

- 서비스 우선순위: 현재 검증된 기술통계 설명 기능 중심으로 갈지, 예측 개선을 추가 과제로 잡을지.
- 추가 과제라면 자료 후보 하나와 담당자·확보 범위·비용을 먼저 정하기. 자료를 늘리면 좋아진다는 보장은 없음.
- 원본 인구 CSV 팀 공유 장소 및 교차 검토 담당자. 이번 실험은 로컬에서 진행했고 Supabase에 인구 자료를 추가하지 않음.

설명 시 구분: 원천 업종은 16개, 의원·병원을 묶으면 분석 그룹 15개. 이번 예측 실험은 그중 일반음식점만 대상이다. '폐업 신고 예측'을 '창업 성공 확률'이나 '실제 공실률'로 표현하지 않는다.
