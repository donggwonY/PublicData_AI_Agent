사용자가 Windows 설정을 변경한 뒤 기존 분석 환경에서 실행을 완료했다. 이전 실행 대기 안내를 대체하며 팀원 대행 실행은 더 이상 필요하지 않다. [전체 대상 결과](full_coverage.md), [수치](full_coverage.json).

입력 해시·날짜 간격·그룹 합계와 기존 2020~2021 점수 재현 검사를 통과했다. 이 결과는 전체대상 기본 모델의 한계이며 다른 면적 모델과 직접 성능 순위를 비교하지 않는다. 2023~2025 재평가, DB 변경, 서비스 적용은 하지 않았다. 현재 입력만으로 제외 집단까지 안정적으로 예측한다고 설명할 근거가 없어 서비스 적용 보류 결론을 유지한다.

[결과](no_area_forest.md): 전체대상 업태·구군·개업 월 RF는 회귀보다 세 기간 모두 두 오차가 작았지만 상수 기준선 대비 개선은 첫 기간뿐이다. 면적 제외 집단 실제 신고 비율 65~90%에 예측 8~9%로 과소예측 문제가 남았다. 전체 및 면적 제외 집단의 사전 개선 기준 모두 미통과. 모델 종류 변경만으로 이 문제를 해결하지 못했다. 주변 이력 추가는 이번 실험에 포함하지 않았으며 다른 입력의 효과까지 부정하는 결과는 아니다. 해시·기준선/그룹 재현·시간 간격·합계 검사 통과. 공개 적용 보류, DB/배포 변경 없음.


### 면적 없는 주변 이력 추가 — 2026-11-03

[결과](no_area_context.md): 개업60일 전 반경500m 일반음식점 영업·개업·폐업 이력을 추가한 RF는 기존 RF 대비 전체 오차가 2015~2016/2020~2021에는 감소했으나 2017~2018에는 증가했다. 상수 기준선 대비 두 오차 개선은 첫 기간뿐이다. 면적 제외 집단은 첫 기간 두 오차 개선, 두 번째 기간 악화, 마지막 기간 Brier 소폭 악화/log loss 소폭 개선으로 일관되지 않았다. 실제 신고 65~90% 대비 예측 7~9%로 문제는 남았다. 전체·면적 제외 사전 개선 기준 모두 미통과.

좌표 없는 행도 학습표본 중앙값 대체로 유지했다. 누락 여부는 입력하지 않았다. 기준선 및 그룹 점수 재현·시간 간격·경계·대체값·합계·해시 검증 통과. 현재 주소를 이용한 과거 재구성과 실제 정보 공개 시점의 한계가 있다. 주변 이력의 일관된 개선 효과를 입증하지 못했으며 원천 누락 시점 확인 전 공개 적용 보류를 유지한다. 추가 설정 탐색/2023~2025 재평가/DB 변경 없음.
