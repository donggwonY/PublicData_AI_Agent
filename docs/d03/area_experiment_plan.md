# 면적 추가 탐색 사전 계획

현재/최근 스냅샷 면적이 개업 당시 같다는 미검증 가정의 탐색. 실제 개업 전 성능 입증으로 해석 금지. 사용자 동의로 진행.

기존 좌표 유효 일반음식점2010~2021 및 세 시간 분할 유지. 최종2023~2024 재평가 없음. 기존 area_m2를 사용하고, 결측인 경우만 관리번호+기관코드로 연결한 원본의 올바른 천 단위 쉼표 숫자를 복구한다. 기존16건 값 차이는 덮어쓰지 않음. 0/음수/비유한값은 결측, log1p 면적 및 명시적 결측지표 사용, 중앙값 대체/표준화는 학습자료만 사용. 표본 삭제·임의 상한 없음.

5후보: 상수, 기존 주변LR/RF, 같은 입력+면적LR/RF. 기존 하이퍼파라미터 고정. 세 기간 모두 같은 알고리즘 기존모델 및 상수보다 Brier/log loss 개선 여부 평가. 업태/구군별 보조 결과 기록. 반복 활용 검증이므로 후보 선정의 독립 증거 아님. 학습/검증 간365일 관측 간격·기존점수 재현·원본키·복구값·결측대체 학습범위·수렴·확률 범위 검사. DB/원본/운영 가공본 수정 없음.

## 최초 결과 후 해석용 추가 비교

면적 결측/0 표본에서 사건 비율이 높음을 확인한 후 누락 여부만 추가한 LR/RF 두 후보를 추가한다. 최초5후보 사전계획과 구분하며 성능을 고르기 위한 독립 검증이 아니다. 완전면적/결측 그룹별 점수를 함께 기록해 실제 크기와 기록 누락의 효과를 분리한다.
