# 면적 없는 전체대상 RF 비교 계획

업태·구군·개업 월만 사용한다. 면적·좌표·누락 여부·현재 상태·폐업일은 입력에서 제외한다. 주변 이력 입력 확장은 이번 범위 밖이다.
전체대상 기존 세 기간(2015~2016, 2017~2018, 2020~2021)과 학습 기간을 그대로 유지한다. 기존 RF 설정 150 trees, depth 8, leaf 30, sqrt, seed 0을 고정하며 추가 탐색하지 않는다.
기존 상수/회귀 전체 점수와 그룹별 점수를 재현하고, 전체 및 면적 제외 집단에서 세 기간 모두 RF의 Brier/log loss가 두 대조보다 낮은지 각각 보고한다. 통과하더라도 반복 사용한 과거 표본이며 독립 검증이 아니다. 2023~2025 재평가·서비스 적용 없음.
