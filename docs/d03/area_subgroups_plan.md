# 보정 모델 하위집단 진단 계획

2026-10-29. 이미 본 2025년 평가 표본의 사후 진단이며 독립 검증이 아니다. 모델·보정 계수·학습 기간을 변경하지 않는다.

기존 보정 실험의 입력 해시와 전체 점수를 재현한 뒤 보정 전후를 같은 표본으로 비교한다. 업태(category), 구군(gu), 면적(0~30, 30~60, 60~100, 100~200, 200㎡ 이상)을 결과 조회 전에 고정한다. 모든 집단을 남기며 n<100 또는 신고/비신고 각각10건 미만은 소표본으로 표시한다. 이는 검증 통과 기준이 아니라 설명 시 주의 표시다.

각 집단의 표본·사건 수, 평균 예측·실제 비율, 차이(%p), Brier와 log loss를 기록한다. 건물 단위 2000회 재표집으로 보정 후 평균 예측-실제 차이의 95% 구간을 제시한다. 고정 모델의 기술적 불확실성만 반영하며 다중 비교·모델 선택·재학습 불확실성은 포함하지 않는다. 구간에 0이 포함돼도 정확성이 입증된 것이 아니다.

검증: 기존 4모델 전체 점수 및 보정 계수 재현, 각 분류의 표본/신고 합계와 가중 지표 일치, 고정 구간 경계, 입력·기존 산출물 불변 확인. 개인별 식별정보는 저장하지 않는다. 결과에 맞춘 업종 제외·재학습·서비스 배포 없음.
