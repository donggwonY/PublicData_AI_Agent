# 건물 이력 모델의 미관측 건물 진단

2026-11-03 결과 확인 전 고정. 기존 3기간·모델·입력·보정 설정을 그대로 재현한다. 표본을 (1) 기초 학습에 등장한 건물 (2) 기초학습에는 없고 보정기간에만 등장한 건물 (3) 학습·보정 모두에 없는 건물로 분할한다. 평가 결과나 성능으로 그룹을 고르지 않는다. 주 관심은 (3)이며, 기존 건물키는 실제 건물의 독립 식별을 완벽히 보증하지 않는다.

기존 무보정RF/정규화보정RF와 건물이력 무보정/보정 모델을 동일 그룹에서 비교한다. Brier·log loss·표본·사건·평균예측·실제비율 및 구분별 집계 합을 저장한다. 학습에 없다는 것은 과거 이력이 전혀 없다는 뜻이 아니다. 예측 시점 전까지의 이력 입력은 계속 허용한다. 미래 입력 누출 검증을 대체하지 않는다.

기존 전체점수 재현, 그룹 비중복·완전분할, 표본·사건·가중점수 합 검사. 소표본은 기존 기준 n<100 또는 사건/비사건 각각10 미만. 과거 기간을 재사용한 조건부 진단이며 새로운 독립 시험/2025 검증 아님. 새 모델 탐색·운영·DB 변경 없음.
