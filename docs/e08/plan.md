# E-08 F1 브랜드 대구 가맹점 감소 예측 — 사전 계획 (2026-11-19 고정)

담당 염동권(에이전트 수행) · [0단계 자료 확인](README.md) · [작업판](../WORKBOARD.md) E-08

이 문서는 **모델 결과를 보기 전에** 고정한 계획이다. 이후 변경은 아래 "변경 기록"에 날짜·이유와 함께 덧붙이고 본문은 고치지 않는다.

## 1. 질문과 정답

- 창업자 질문: "가맹 계약을 고민 중인 이 브랜드, 앞으로 1년 동안 대구 가맹점이 줄어들까?"
- 단위: 브랜드(`brandMnno`) × 기준년도 N(N = 2017~2025). 기준년도 N 자료는 N−1년 말 기준이다.
- 대상: 기준년도 N 지역 자료에서 대구 가맹점(`frcsCnt`, 직영점 제외) 3곳 이상인 브랜드.
- 정답 y = 1: 기준년도 N+1 대구 가맹점 수 < 기준년도 N 대구 가맹점 수.
  - N+1 브랜드 목록에 있으나 대구 행이 없으면 대구 0곳으로 보고 y = 1.
  - N+1 브랜드 목록에서 빠진 브랜드(정보공개서 미등록·취소 등)는 가맹점 수를 알 수 없으므로 **주 분석에서 제외**하고 연도별 수를 따로 보고한다.
  - 민감도 분석(보고만): 목록에서 빠진 브랜드를 y = 1로 넣은 정의.
- 브랜드 키는 `brandMnno`다. 연도 간 번호는 유지되고(연속 연도 공통 번호 4,724~9,810개), 이름이 바뀐 경우도 같은 번호로 이어진다(공통 번호의 5~11%). 번호가 바뀌고 이름만 남는 경우는 연 11~39건이라 따로 합치지 않는다.

확인 수치(2026-11-19, 정답 분포만 확인, 모델 결과 아님):

| 기준년도 N | 대상 | 감소(y=1) | 유지·증가 | N+1 목록에서 빠짐 | 목록에 있으나 대구 행 없음 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2017 | 603 | 203 | 360 | 40 | 0 |
| 2018 | 647 | 253 | 351 | 42 | 1 |
| 2019 | 673 | 266 | 365 | 42 | 0 |
| 2020 | 711 | 255 | 414 | 41 | 1 |
| 2021 | 760 | 294 | 439 | 27 | 0 |
| 2022 | 835 | 279 | 457 | 70 | 29 |
| 2023 | 814 | 300 | 420 | 52 | 42 |
| 2024 | 834 | 329 | 467 | 37 | 1 |
| 2025 | 897 | 346 | 402 | 149 | 0 |

- 대구 행 없음은 감소에 포함된다(위 표의 감소 열은 대구 행이 있는 브랜드만 센 값이라, 실제 y=1은 두 열의 합).
- 0단계 README 표(예: 2017 563곳)는 두 해 모두 대구 행이 있는 브랜드만 센 값이라 이 표와 다르다. 이후 수치는 이 문서 정의를 쓴다.
- **2026 기준년도 주의**: 목록이 9,990개로 2025(11,150개)보다 적고, 목록에서 빠진 대상이 149곳(다른 해 27~70곳)이다. 2026 공개가 아직 덜 끝났을 수 있다. 시험 구간 결과에 이 점을 함께 적고, 민감도 분석을 반드시 같이 보고한다.

## 2. 입력 자료와 시점

| 자료 | 쓰는 값 | 시점 규칙 |
| --- | --- | --- |
| 브랜드 목록 `brand_list` N | 업종 대·중분류, 가맹사업 개시일, 가맹본부 번호 | 기준년도 N 목록만 |
| 지역 자료 `brand_region` N, N−1 | 대구·전국 가맹점·직영점 수, 진출 시·도 수 | N과 그 이전 |
| 가맹점 현황 `brand_stats` yr = N | 전국 가맹점 수, 신규 개점·계약 종료·해지·명의 변경, 평균 매출, 면적당 평균 매출 | yr = N이 지역 자료 기준년도 N과 같은 시점이다(전국 가맹점 수 일치 96.5~99.5%, yr = N−1과는 12~13%). 브랜드명+법인명으로 연결하고, 같은 이름이 둘 이상이면 연결하지 않고 결측으로 둔다 |

- 쓰지 않는 자료: 외식 통합정보(브랜드 번호가 가명이라 연결 불가), 인허가(이름 매칭 보완 전. 확장 단계에서 별도 계획).
- 정답을 만드는 N+1 자료는 입력에 쓰지 않는다. 업종 평균처럼 여러 브랜드를 모은 값도 기준년도 N까지의 자료로만 계산한다.

## 3. 입력 변수 (모두 기준년도 N 시점)

- 대구: 가맹점 수(로그), 직영점 수, 직전 해 대비 증감 수·비율(N−1 대구 행이 없으면 0으로 보고 "직전 해 대구 없음" 표시), 전국 대비 대구 비중
- 전국(지역 자료): 가맹점 수(로그), 직전 해 대비 증감 비율, 진출 시·도 수
- 전국(가맹점 현황): 신규 개점·계약 종료·계약 해지·명의 변경 각각 ÷ 가맹점 수, 평균 매출(로그), 면적당 평균 매출(로그), 평균 매출 직전 해 대비 변화율, 연결 실패 표시
- 브랜드: 브랜드 나이(N − 개시 연도), 업종 대분류·중분류(학습 구간 30건 미만 중분류는 "기타"), 같은 가맹본부의 브랜드 수
- 업종 흐름: 같은 업종 중분류의 직전 쌍(N−1 → N) 대구 감소율(대상 10곳 미만이면 대분류 값)
- 값 0인 매출(미기재)은 결측으로 본다.

## 4. 시간 분할

| 구분 | 기준년도 N | 정답 연도 |
| --- | --- | --- |
| 학습 | 2017~2022 | 2018~2023 |
| 검증 | 2023, 2024 | 2024, 2025 |
| 시험(1회) | 2025 | 2026 |

- 하이퍼파라미터 조정은 학습 구간 안 시간 분할(2017~2020 학습 / 2021~2022 확인)로만 한다. 검증 구간은 모델 비교에만 쓴다.
- 최종 모델은 학습+검증(2017~2024)으로 다시 학습하고 시험 구간을 한 번만 본다. 같은 규칙으로 기준선도 2017~2024에서 다시 계산한다.

## 5. 기준선과 모델

- B0: 학습 구간 전체 감소율(상수)
- B1 추세 유지: 직전 해 대구 증감 방향(감소 / 같음 / 증가 / 직전 해 대구 없음)별 학습 구간 감소율
- B2 업종 평균: 업종 중분류별 학습 구간 감소율(30건 미만은 대분류)
- M1 로지스틱 회귀(L2, 수치 변수 표준화, 결측 표시 변수)
- M2 LightGBM
- 실행 환경: 기존 실험 환경 `C:\claude_workspace\e06_env`(lightgbm 4.7.0, scikit-learn 1.9.1). 서비스 환경에는 설치하지 않는다.

## 6. 평가와 채택 기준

- 지표: Brier 점수(주 지표), AUC, 로그 손실, 보정 곡선(10구간). 신뢰구간은 브랜드 단위 부트스트랩 1,000회.
- 검증 구간에서 B1·B2 중 더 나은 기준선(Brier 기준)과 M1·M2를 비교해 하나를 고른다.
- 채택(시험 구간): 고른 모델이 더 나은 기준선보다 **Brier가 낮고(차이 95% 신뢰구간 상한 < 0)** 그리고 **AUC가 0.02 이상 높을 것**.
- 미달이면 "업종·추세 평균으로 충분하다"를 결론으로 보고하고 모델을 서비스 후보로 올리지 않는다.
- 오류 분석: 업종 대분류, 대구 가맹점 수 구간(3~4 / 5~9 / 10~29 / 30+), 브랜드 나이, 가맹점 현황 연결 여부별 지표. 크게 틀린 사례 20건은 연도별 수치를 나열해 원인 유형을 적는다(참고용).
- 민감도: §1의 "목록에서 빠짐 = 감소" 정의로 같은 비교를 다시 해 결론이 바뀌는지 적는다.
- 별도 누수 테스트 단계는 두지 않는다. 대신 변수 계산 함수가 기준년도 N 이하 파일만 읽도록 코드에서 제한한다.
