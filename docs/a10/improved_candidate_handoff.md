# A-10 개선 모델 연동 후보

기존 4개 업종 608행과 같은 조회 형식으로 [개선 후보 CSV](industry_comparison_app_candidate.csv)를 생성했다. 기준월은 2026-09다. 카페·미용실은 기존 추정치, 백반/한정식은 주변 규모 추가 추정치, 학원은 주변 업종 구성 추가 추정치다.

## 추정치의 의미와 버전

이번 연동 후보 파일은 `docs/a10/industry_comparison_app_candidate.csv`다. 기존 `industry_comparison_app.csv`와 파일명이 다르므로 연결할 버전을 명시한다. [검증 수치와 입력 근거 JSON](improvement_validation.json)에 모델 비교·주변 정보·구군 2곳 제외·2026-06 추가 평가와 원본 수집 근거를 함께 저장했다.

후보 CSV의 추정치는 해당 지역의 구군 전체를 학습에서 제외하고 계산했다. 실제 점포 수와 지역 여건 기반 참고값의 차이를 비교하는 기존 용도에 맞춘다. [후보 비교표](improved_candidate_comparison.csv)의 `estimated_shops`는 기존값, `candidate_estimate`는 개선 후보, `full_fit_estimate`는 같은 지역의 실제 점포 수까지 학습한 전체 적합값이다. 전체 적합값은 학습에 사용한 자료에 대한 결과여서 개선 성능의 증거로 해석할 수 없다.

백반/한정식·학원의 구군 한 곳 제외 및 두 곳 제외 실험에서 기존 두 시점 모두 평균 오차가 줄어 두 개선 방식을 후보로 골랐다. 후보 CSV는 기존 연동 자료와 구분해 검토할 버전이다.

이후 확보한 2026-06 추가 시점에서도 고정한 후보의 평균 오차가 백반/한정식 13.16→12.86곳, 학원 7.32→6.95곳으로 줄었다. [추가 시점 검증](improvement_plan.md#추가-시점-2026년-6월-검증)은 기존 두 시점보다 앞선 분기의 공간 평가다. 2026-09 이후 자료의 검증은 남아 있다.

## 최신 시점의 지역별 변화

| 업종 | 평균 절대오차 기존 → 후보 | 오차 감소 지역 | 오차 증가 지역 |
| --- | ---: | ---: | ---: |
| 백반/한정식 | 13.20 → 12.36곳 | 79 | 73 |
| 입시·교과학원 | 7.91 → 6.64곳 | 89 | 63 |

| 사례 | 실제 | 기존 추정 | 개선 후보 | 전체 적합값 |
| --- | ---: | ---: | ---: | ---: |
| 월성1동 · 학원 | 136 | 244.43 | 147.97 | 140.82 |
| 다사읍 · 학원 | 96 | 81.67 | 138.48 | 103.64 |
| 유가읍 · 학원 | 51 | 53.47 | 99.32 | 64.88 |
| 논공읍 · 백반/한정식 | 76 | 195.50 | 165.01 | 117.75 |

평균이 개선돼도 모든 지역이 좋아지는 것은 아니다. 특히 학원은 월성1동에서 오차가 줄었지만 다사읍·유가읍에서 커졌다. 608행의 후보는 개별 지역의 적정 점포 수나 창업 성과를 판정하는 값으로 쓰지 않는다.

## 재현과 다음 확인

기존 입력 자료로 `python scripts/evaluate_a10_nearby_context.py` 실행 후 `python scripts/export_a10_improved_candidate.py`를 실행한다. 후보와 원래 자료의 608개 조회 키·실제 점포 수가 일치하고, 카페·미용실 추정치가 일치하는지 검사한다. 단위는 점포 수이며 정밀도를 유지한 채 저장하고 화면에서는 반올림한다. 조회·결측 표시 규칙은 [기존 연동 문서](app_handoff.md)를 따른다.

[비교 카드 시안](cafe_comparison_preview.html)의 세 후보지·네 업종은 개선 후보 CSV의 반올림 값으로 갱신했다. 월성1동 학원은 실제 136곳, 추정 약 148곳이다. 다음은 앱 담당자에게 후보 버전과 검증 결과를 함께 전달하는 것이다. 운영 반영 시 사용할 파일을 명시해야 한다.
