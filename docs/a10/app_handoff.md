# A-10 업종별 점포 수 비교 연동

창업 후보지의 실제 점포 수를 주민 인구와 다른 업종의 점포 구성을 바탕으로 추정한 같은 달의 참고값과 비교한다.

## 데이터와 조회

[연동 CSV](industry_comparison_app.csv)는 UTF-8이며 2026년 9월 대구 읍·면·동 152곳과 4개 업종의 조합 608행이다. 두 평가 시점 모두 네 비교 방법보다 평균 오차가 작았던 업종 중 시안에 들어간 4개 업종을 담았다. CSV에는 구·군을 통째로 제외해 계산한 추정치를 넣었다.

| 필드 | 정의 |
| --- | --- |
| `admin_code` | 10자리 읍·면·동 코드. 문자열로 읽는다. |
| `industry_code` | 소진공 소분류 코드. `I21201` 카페, `S20701` 미용실, `I20101` 백반/한정식, `P10501` 입시·교과학원 |
| `base_month` | 실제와 추정치의 공통 기준월 |
| `actual_shops` | 상가업소 자료에서 집계한 실제 점포 수 |
| `estimated_shops` | 포아송 회귀 추정치. CSV에는 원래 정밀도로 저장한다. |

`base_month`, `admin_code`, `industry_code` 조합으로 조회한다. 후보지끼리는 같은 기준월과 업종을 사용한다. 상가업소 코드와 서비스의 업종 별칭·인허가 분류는 매핑을 확인하고 연결한다.

## 화면 표시와 확인 사례

[비교 카드 시안](cafe_comparison_preview.html)에서 네 업종을 전환해 볼 수 있다.

- 기준월과 함께 **실제 점포 수**와 **동네 여건으로 추정한 점포 수**를 표시한다. 추정치는 정수로 반올림하고 ‘약’을 붙인다. 주민 수·연령 분포·다른 업종의 점포 구성으로 계산한 비교용 수치라고 설명한다.
- 차이가 큰 경우에도 두 수치를 그대로 표기한다. 실제 점포 수와 참고값 차이에 과밀·부족 판정이나 추천 순위는 부여하지 않는다.
- 행이 있고 실제 점포 수가 0이면 **0곳**으로 표시한다. 조회 키에 해당하는 행이 없으면 **이 기준월에는 비교 자료가 없어요**라고 안내한다.

| 확인 사례 | 기대 표시 |
| --- | --- |
| 월성1동 · 입시·교과학원 | 실제 136곳, 추정 약 244곳 |
| 월성1동 · 카페 | 실제 71곳, 추정 약 70곳 |
| 행정동 코드 2711069000 · 입시·교과학원 | 실제 0곳, 추정 약 10곳 |
| 구지면 기존 코드 2771038000 · 카페 | 비교 자료 없음 |

전체 247개 중 83개 업종이 두 시점 모두 모델 비교 기준을 충족했다. 164개 업종은 적어도 한 시점에서 기준을 충족하지 못했다. [검증 기록](README.md)에는 연동 후보의 큰 오차 사례도 있다. 이 자료의 상태는 연동 준비로, 앱 조회 구현과 운영 반영은 별도 단계다.

저장소 루트에서 `python scripts/evaluate_a10_all_industries.py` 실행 후 `python scripts/export_a10_app_comparison.py`로 CSV를 재생성한다.
