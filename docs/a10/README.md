# A-10 배후 여건을 고려한 대구 업종별 점포 수 비교

담당 김선경 · 2026-11-17 · 카페 시범 분석 및 전체 업종 확대

## 전체 업종 확대

2025년 6월과 2026년 9월의 대구 상가업소 자료에 실제 등장한 **업종 소분류 전체**를 각각 평가했다. 관측 단위는 같은 달의 주민등록 인구가 1명 이상인 읍·면·동이다. 대상 업종이 없는 지역도 실제 점포 수 0으로 포함했다.

업종마다 대상 점포를 상가 입력에서 모두 빼고, 카페 실험과 동일한 포아송 회귀를 구·군 단위로 검증했다. 비교 방법은 학습 지역의 인구 비율, 다른 업종 상가 수 비율, 학습 지역의 점포 수 중앙값, 인구와 기타 상가 규모만 사용한 포아송 회귀다. 평균 절대오차가 작을수록 같은 달의 실제 점포 수에 가깝다.

| 기준월 | 소분류 | 읍·면·동 | 포함 점포 | 모형이 비교 방법 4개보다 오차가 작은 소분류 |
| --- | ---: | ---: | ---: | ---: |
| 2025-06 | 247 | 152 | 114,924 | 91 |
| 2026-09 | 247 | 152 | 115,954 | 97 |

두 달에 동일한 247개 코드가 있었고, **83개 업종**에서 두 달 모두 네 비교 방법보다 오차가 작았다. 2026-09에는 주민등록 인구가 0명인 구지면 기존 코드에 연결된 674개 점포를 제외했다. 두 시점의 기록은 서로 겹칠 수 있다.

[전체 업종 성능표](industry_evaluation.csv)에 247개 업종의 월별 오차와 기준 충족 여부를 담았다.

| 두 달 모두 개선된 업종 예시 | 2026-09 가장 낮은 비교 오차 | 2026-09 모형 오차 |
| --- | ---: | ---: |
| 백반/한정식 | 14.82곳 | 13.20곳 |
| 미용실 | 11.27곳 | 9.85곳 |
| 카페 | 8.28곳 | 6.89곳 |
| 입시·교과학원 | 13.76곳 | 7.91곳 |

83개는 앱 시안 확장 시 우선 검토할 후보군이다. 업종별 점포 분포, 대표 후보지 오차와 추정치 해석을 확인한 뒤 실제 표시 범위를 정한다. 업종별 성능 CSV에는 점포가 한 곳 이상 있는 지역 수와 해당 지역만의 모델 오차도 포함했다. 두 저장 결과에서 행정동·업종 키 중복, 성능표 재계산, 기존 카페 모델 추정치 일치를 확인했다.

저장소 루트에서 `python scripts/evaluate_a10_all_industries.py`로 실행한다. 로컬 `data/raw/a10/`에 월별 `industry_comparison_YYYY-MM.csv`, 업종별 성능표 `industry_evaluation.csv`, 입력 자료 해시와 표본 정보 `industry_inputs.json`을 저장한다.

## 연구 질문과 앱 활용

배후 주민과 다른 업종의 점포 구성을 고려하면, 대구의 창업 후보 행정동에는 카페가 대략 몇 곳 분포할까? 앱에서는 같은 기준월의 실제 카페 수와 해당 지역의 여건에서 모델이 추정한 카페 수를 후보지별로 나란히 보여주는 방안을 검토한다. 추정치는 다른 지역에서 학습한 현재 분포의 참고값이다. 매출·방문 수요, 적정 점포 수 또는 미래 경쟁점포 수를 추정한 결과와는 범위가 다르다.

## 데이터와 방법

- 2025-06과 2026-09의 대구 상가업소와 같은 달의 행정동별 주민등록 거주자 자료를 재사용했다. 타깃은 소진공 소분류 `I21201`(카페)이다. 각 시점에 대구 9개 구·군의 주민등록 거주자가 있는 읍·면·동 152곳을 평가했다. 2026-09에는 주민등록 인구가 0명으로 표시된 구지면 기존 코드와 그 코드의 카페 41건을 제외했다. 평가 카페 수는 각각 5,363건과 5,281건이다. [소진공 상가업소](https://www.data.go.kr/data/15083033/fileData.do) · [행안부 인구](https://jumin.mois.go.kr/ageStatMonth.do)
- 각 시점에 구·군 하나를 통째로 평가 대상으로 남기고, 나머지 구·군에서 학습과 기준율 계산을 했다. 모든 상가 입력에서 카페 기록을 뺐다. 실제 카페 수는 학습 목표와 평가에 사용했다.
- 포아송 회귀의 입력은 로그 변환한 총인구·기타 상가 수, 연령대별 비중, 카페를 제외한 대분류별 상가 수다. 비교용으로 총인구와 기타 상가 수만 쓰는 포아송 회귀도 실행했다. 표준화는 각 학습 구·군에서 수행했고 L2 규제 계수는 0.1로 고정했다.

## 첫 검증 결과

행정동별 실제와 추정 점포 수의 오차를 구하고, 행정동에 동일 가중치를 부여해 평균했다.

| 방법 | 2025-06 평균 절대오차 | 2026-09 평균 절대오차 |
| --- | ---: | ---: |
| 주민 규모에 학습지역의 카페 비율 적용 | 17.05곳 | 16.74곳 |
| 카페 외 상가 수에 학습지역의 카페 비율 적용 | 8.80곳 | 8.28곳 |
| 인구·기타 상가 규모만 사용한 포아송 회귀 | 9.43곳 | 8.79곳 |
| 인구·연령·기타 업종 구성을 사용한 포아송 회귀 | **7.61곳** | **6.89곳** |

두 시점에서 더 강한 단순 기준선인 카페 외 상가 비율 대비 평균 오차가 각각 13.58%, 16.78% 줄었다. 구·군별로는 2025-06의 9곳 중 5곳, 2026-09의 9곳 중 7곳에서 모형 오차가 더 작았다. 두 시점의 상가가 겹칠 수 있으며, 모형은 동일 월의 지역 차이를 평가했다.

2026-09 예시로 중구 성내1동은 실제 231곳과 추정 약 150곳, 수성구 범어3동은 실제 51곳과 추정 약 68곳, 달서구 월성1동은 실제 71곳과 추정 약 70곳이었다. 성내1동의 약 81곳 차이는 최신 평가의 가장 큰 오차 사례다. 이런 차이에는 모델에 포함하지 않은 상권 요인과 측정 한계가 함께 반영될 수 있다.

## 구·군과 상가 규모별 오차

기준선은 카페 외 상가 수에 학습지역의 카페 비율을 적용한 추정이다. 각 셀은 **기준선 / 포아송 모형**의 평균 절대오차(곳)다.

| 구·군 | 각 시점 읍·면·동 수 | 2025-06 | 2026-09 |
| --- | ---: | ---: | ---: |
| 군위군 | 8 | 3.48 / 3.82 | 3.77 / 2.71 |
| 남구 | 13 | 8.46 / 5.27 | 8.41 / 4.83 |
| 달서구 | 23 | 9.39 / 5.75 | 9.18 / 6.83 |
| 달성군 | 11 | 9.57 / 4.73 | 7.25 / 4.27 |
| 동구 | 22 | 7.16 / 7.88 | 6.44 / 7.17 |
| 북구 | 23 | 7.28 / 7.96 | 7.11 / 6.98 |
| 서구 | 17 | 7.87 / 4.70 | 6.52 / 3.62 |
| 수성구 | 23 | 6.58 / 8.44 | 5.70 / 7.82 |
| 중구 | 12 | 22.41 / 20.21 | 23.35 / 16.55 |

| 카페 외 상가 수 | 2025-06 지역 수 | 2025-06 오차 | 2026-09 지역 수 | 2026-09 오차 |
| --- | ---: | ---: | ---: | ---: |
| 500곳 미만 | 53 | 4.61 / 3.79 | 55 | 4.19 / 3.18 |
| 500~1,499곳 | 91 | 9.42 / 8.23 | 89 | 8.91 / 7.90 |
| 1,500곳 이상 | 8 | 29.62 / 25.76 | 8 | 29.28 / 21.13 |

상가 규모 구간은 오차를 요약하기 위해 정했다. 두 달 모두 중구에서 모형 오차가 가장 컸으며, 실제 점포 수가 추정치보다 평균 19.65곳과 15.38곳 많았다. 동구와 수성구에서는 두 달 모두 단순 기준선의 오차가 더 작았다. 상가 1,500곳 이상 구간은 시점별 표본이 8곳이다.

## 두 시점의 차이 방향과 앱 표시 권고

행정동 코드와 이름이 일치하는 151곳을 비교했다. 구지면과 구지읍은 이 비교에서 제외했다. 실제 카페 수가 추정치보다 높거나 낮은 방향은 127곳(84.1%)에서 유지됐고 24곳에서 바뀌었다. 두 시점 모두 차이의 절댓값이 10곳 이상인 25곳에서는 모두 같은 방향이었다. 10곳 조건은 사후 탐색에 사용했다. 두 시점의 상가 자료가 일부 겹칠 수 있으므로 이 비율은 관찰된 패턴의 지속성을 보여준다.

앱 시안에는 기준월과 **실제 카페 수 · 지역 여건 기반 모델 참고값**을 표시하는 것을 권고한다. 오차가 큰 도심에서는 참고값의 불확실성을 함께 설명한다. 과밀·부족 판정과 후보지 순위는 별도의 기준과 검증 자료가 확보될 때 검토한다.

## 비교 카드 시안

[비교 카드 HTML](cafe_comparison_preview.html)은 성내1동, 범어3동, 월성1동의 2026년 9월 결과를 0~250곳의 같은 눈금으로 보여준다. 카페·미용실·백반/한정식·입시·교과학원을 선택할 수 있다. 두 시점 모두 네 비교 방법보다 오차가 작았고 최신 자료에서 점포가 2,500곳 이상 분포한 업종을 골랐다. 모델 참고값은 가장 가까운 정수로 반올림했다. HTML 파일을 브라우저에서 열 수 있다.

| 업종 | 2026-09 절대오차 최대 지역 | 실제 / 모델 참고값 |
| --- | --- | ---: |
| 카페 | 중구 성내1동 | 231 / 149.85 |
| 미용실 | 중구 대신동 | 11 / 50.11 |

| 입시·교과학원 | 수성구 범어4동 | 271 / 78.40 |

입시·교과학원은 전체 평균 오차가 줄었지만, 시안에 포함된 월성1동에서도 136곳과 약 244곳으로 차이가 컸다. 업종별 최대 오차 사례와 시안 내 큰 차이를 앱 표시 범위 논의에 사용한다.

팀원에게 시안만 먼저 보여주고 **“두 숫자는 각각 어떤 뜻으로 보여?”**, **“성내1동의 두 숫자 차이에서 어떤 판단을 할 수 있을 것 같아?”**를 묻는다. 참고값을 적정 점포 수로 읽거나 차이로 창업 위험을 판단한다면, 안내 문구를 고친 뒤 다시 확인한다. 팀원 피드백은 수집 전이다.

## 재현과 다음 작업

`python scripts/evaluate_a10_cafe_concentration.py`로 행정동별 추정 CSV와 요약 JSON을 Git 제외 경로 `data/raw/a10/`에 생성한다. `python scripts/audit_a10_cafe_comparison.py`로 구·군과 규모별 오차, 두 시점 방향 일치 결과를 다시 계산한다.

[앱 연동 자료](app_handoff.md)에 4개 업종의 조회용 CSV, 표시 규칙과 확인 사례를 정리했다. 다음 단계는 앱의 행정동·업종 코드 매핑과 후보지 조회를 연결해 검증하는 것이다.


[개선 계획과 실험 결과](improvement_plan.md)에 다른 모델 비교와 주변 지역 정보 추가 결과를 정리했다. 포레스트·부스팅은 평균 오차를 줄이지 못했다. 주변 정보는 백반/한정식과 학원에서 두 시점 모두 개선됐고, 구군 두 곳 동시 제외 평가에서도 개선이 이어졌다. 새 시점의 독립 검증은 남아 있다.

[개선 후보 연동 자료](improved_candidate_handoff.md)에 업종별 방법을 적용한 608행, 기존값·후보값·전체 적합값 비교와 지역별 악화 사례를 정리했다.

2026-06 공식 과거 분기 자료를 추가 확보해 고정한 두 업종 개선 후보를 검증했다. 백반/한정식·학원 모두 평균·최대 오차 감소가 이어졌다. [추가 시점 결과](improvement_plan.md#추가-시점-2026년-6월-검증)에 표본과 수집 근거를 기록했다.
