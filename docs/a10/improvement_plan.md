# A-10 업종별 점포 수 추정 개선 계획

김선경 · 2026-11-19 · 계획 수립

동네 인구와 다른 업종의 점포 구성을 사용해 같은 달의 점포 수를 추정하는 A10의 오차를 줄인다. 우선 카페·미용실·백반/한정식·입시·교과학원으로 실험하고, 개선이 확인되면 전체 업종에 적용한다.

현재 247개 업종 중 83개에서 두 시점 모두 네 비교 방법보다 평균 절대오차가 작았다. 개별 동네에서는 큰 오차가 남았다. 아래 방법의 개선 효과는 아직 확인 전이다.

## 1. 오차가 큰 사례와 데이터 확인

- 업종별로 실제와 추정의 차이가 큰 동네를 추리고 과소·과대 추정을 구분한다.
- 행정동 코드 변경, 주민등록 인구 0명 제외, 업종 코드·중복·집계 합계를 다시 대조한다. 원천 근거가 확인된 오류를 수정하고 수정 전후 표본과 오차를 남긴다.
- 성내1동 카페, 대신동 미용실, 논공읍 백반/한정식, 범어4동 학원을 우선 점검한다.

완료 산출물은 업종·지역별 오차표와 데이터 점검 기록이다. 큰 차이의 원인을 자료로 확인하지 못한 경우에는 원인 미확인으로 기록한다.

## 2. 후속 평가 방법 고정

- 구·군 하나를 통째로 제외하는 기존 평가와 현재 기준선을 유지한다. 대상 업종은 모든 상가 입력에서 제외한다.
- 모델 설정을 고르는 과정은 남겨 둔 평가 구·군을 보지 않고 나머지 구·군 안에서 수행한다. 표준화와 결측 처리도 학습 자료에서 정한다.
- 전체 평균 절대오차와 함께 구·군별 오차, 상가 규모별 오차, 실제 점포가 있는 지역의 오차, 큰 오차 사례를 보고한다.
- 기존 두 시점은 이미 결과를 확인했으므로 후속 비교를 탐색 실험으로 기록한다. 새 시점 자료가 확보되면 모델·설정을 고정하고 추가 평가한다.

완료 산출물은 고정한 분할·후보 모델·평가 지표·선택 절차다.

## 3. 기존 자료로 다른 모델 비교

- 같은 입력으로 기존 포아송 회귀, 랜덤포레스트, 부스팅 회귀를 비교한다. 가능한 경우 음수가 나오지 않는 점포 수용 손실함수를 사용한다.
- 후보 설정을 소수로 정하고 2단계 절차로 선택한다. 업종마다 동일 표본에서 기존 네 비교 방법과 새 모델을 비교한다.
- 평균 오차가 줄어도 특정 구·군이나 큰 오차 사례가 악화되는지 함께 확인한다.

완료 산출물은 업종별 성능 비교표와 지역별 개선·악화 사례다. 먼저 이 단계를 실행해 새 자료 없이 개선할 여지가 있는지 확인한다.

## 4. 주변 지역 정보 추가

- 기존 상가 좌표와 행정동 연결 자료를 확인해 이웃 동네의 다른 업종 점포 분포를 입력으로 만드는 방안을 검토한다.
- 경계 근처 상권이 여러 동에 걸친 경우를 살펴본다. 주변 정보에도 평가 대상 업종의 실제 점포 수가 직접 들어가지 않도록 한다.
- 동일한 평가에서 주변 정보 추가 전후 오차를 비교한다.

완료 산출물은 주변 범위와 집계 정의, 연결 성공률, 추가 전후 성능표다.

## 5. 부족한 지역 특성 자료 추가

- 유동인구·직장인 규모·도시철도 접근성·대학·관광 및 집객시설 자료의 확보 가능성과 이용 조건을 확인한다.
- 기존 보유 자료부터 기준월·좌표·행정동 연결 가능성을 확인한다. 새로운 자료는 출처, 관측 시점, 지역 단위와 결측률을 기록한다.
- 자료를 한 종류씩 추가해 어떤 정보가 어느 업종의 오차를 줄이는지 확인한다. 확보가 어려운 항목은 기존 자료 실험과 독립적으로 진행한다.

완료 산출물은 자료 목록과 추가 입력별 성능 비교표다. 자료 확보와 성능 개선을 미리 확정하지 않는다.

## 6. 적용 범위와 연동 자료 갱신

- 각 업종의 가장 잘 맞은 비교 방법과 새 모델을 대조해 앱에 제공할 추정 방식을 정한다.
- 두 시점 개선 여부와 지역별 오차를 함께 기록한다. 현재의 83개 업종 목록도 새 결과에 따라 다시 계산한다.
- 선택 근거가 정리되면 조회용 CSV, 업종별 성능표, 비교 카드와 연동 설명을 함께 갱신한다. 기존 파일과 값이 달라진 이유를 남긴다.

완료 산출물은 모델 버전·입력 기준월·업종별 방법·검증 결과가 연결된 연동 자료다. 공개 앱 반영은 연동 담당자의 요청 범위에서 진행한다.

## 바로 시작할 작업

1단계의 네 업종 오차표와 원천 집계 대조부터 시작한다. 이후 2단계를 고정하고 3단계 모델 비교를 실행한다.

## 첫 개선 실험 결과

기존 두 기준월의 네 업종에서 원천 점포 수와 저장된 실제 점포 수, 대상 업종을 제외한 입력 합계가 모두 일치했다. 업소 ID 중복·필수 필드 누락·인구 코드 연결 검사를 기존 로더에서 다시 수행했다. 원본 상가 CSV와 인구 입력의 저장된 해시가 일치했고, 평가 결과의 행정동·업종 키와 평균 오차를 다시 계산해 대조했다. 이번 대조로 실제 현장 업종 분류나 주소의 정확성까지 확인한 것은 아니다.

구·군 하나를 제외해 평가하는 방식과 기존 입력을 유지했다. 설정은 결과 확인 전에 고정했다. 랜덤포레스트는 트리 150개, 최소 말단 표본 5개, 입력 선택 비율 0.8이다. 부스팅은 포아송 손실, 반복 150회, 최대 말단 7개, 최소 말단 표본 10개, 학습률 0.05, L2 규제 1이다. 두 모델의 시드는 7이다. 설정 탐색은 수행하지 않았다.

| 카페 | 7.61 / 9.55 / 9.40 | 6.89 / 8.97 / 8.38 |

단위는 점포 수다. 네 업종 모두 두 시점에서 기존 포아송 회귀의 평균 오차가 가장 작았다. 최신 백반/한정식의 최대 절대오차는 기존 119.50곳에서 포레스트 92.01곳으로 줄었으나, 나머지 세 업종은 최대 오차도 커졌다. 이번 고정 설정 비교로는 모델 교체를 권고하기 어렵다.

저장소 루트에서 `python scripts/evaluate_a10_improvements.py`로 재현한다. 로컬 `data/raw/a10/improvement_predictions_YYYY-MM.csv`에는 지역별 결과, `improvement_evaluation.json`에는 방법별 평균·최대·구군별 오차를 저장했다. 기존 두 시점을 재사용한 탐색 결과다. 다음은 보유 자료의 기준월과 좌표를 확인하고 주변 지역 정보 또는 집객시설 입력의 추가 효과를 비교하는 것이다.

## 주변 지역 정보 추가 실험

각 기준월의 상가 좌표를 사용해 가까운 3개 읍·면·동의 인구와 다른 업종의 점포 정보를 추가했다. 위치 대표점은 대상 업종을 제외한 상가 위도·경도의 중앙값이다. 대표점 간 대원거리로 이웃 3곳을 고르고, 이웃 값의 단순 평균에 로그 변환을 적용했다. 거리는 동 경계나 보행 접근성을 나타내는 값과 다를 수 있다. ‘주변 규모’는 이웃의 총인구·기타 점포 수, ‘주변 업종 구성’은 여기에 대분류별 기타 점포 수도 추가한 방식이다.

학습·평가 구군 분할과 포아송 설정은 유지했다. 이웃 지역에서도 대상 업종 점포 수는 사용하지 않았다. 평가 구군의 같은 달 인구와 다른 업종 상가 정보는 관측 가능한 입력으로 사용했다. 기존 자료의 해시와 실제 점포 수·기타 점포 수를 대조했고, 원래 모델 예측도 재현했다. 두 달 각각 608개 지역·업종 결과의 키와 평균·최대 오차를 재계산했다.

| --- | ---: | ---: |
| 카페 | 7.61 / 7.83 / 7.83 | 6.89 / 7.19 / 6.87 |
| 미용실 | 8.94 / 9.01 / 9.44 | 9.85 / 10.07 / 9.70 |
| 백반/한정식 | 13.16 / 12.80 / 12.67 | 13.20 / 12.36 / 12.69 |
| 입시·교과학원 | 7.59 / 7.71 / 6.94 | 7.91 / 7.88 / 6.64 |

평균 절대오차 단위는 점포 수다. 백반/한정식은 두 추가 방식 모두 두 시점에서 평균 오차가 줄었다. 주변 규모 추가 시 최대 오차도 88.72→85.23곳, 119.50→89.01곳으로 줄었고 두 시점 모두 구군 9곳 중 7곳에서 개선됐다. 학원은 주변 업종 구성 추가 시 평균 오차가 두 시점에서 약 8.5%, 16.1% 줄었다. 최대 오차는 164.03→116.38곳, 192.60→147.72곳으로 줄었고 개선된 구군은 각각 5곳과 6곳이었다.

카페와 미용실은 최신 시점의 작은 개선이 앞선 시점에서 이어지지 않았다. 따라서 다음 검증 후보는 백반/한정식의 주변 규모 입력과 학원의 주변 업종 구성 입력이다. 기존 두 시점으로 후보를 골랐으므로 독립적인 새 시점 또는 더 엄격한 공간 평가로 검증한 뒤 연동 자료 변경 여부를 정한다.

원본 점포 좌표 자체의 결측은 없었다. 다만 대상 업종 이외 상가가 없는 지역은 2025-06 2곳(2771025400, 2771025700), 2026-09 3곳(앞의 2곳 및 2771026800)이었다. 이 지역은 주변 입력을 0과 결측 여부 표시로 넣었고 전체 평가에 포함했다. 최신 구지면 기존 코드의 인구 0명 제외 규칙도 유지했다.

`python scripts/evaluate_a10_nearby_context.py`로 재현한다. 로컬 `data/raw/a10/nearby_predictions_YYYY-MM.csv`와 `nearby_evaluation.json`에 예측·오차·좌표 점검 정보를 저장했다. 외부 집객시설 자료는 이번 실험에 추가하지 않았다.

## 구·군 두 곳 동시 제외 검증

앞선 실험에서 고른 백반/한정식의 주변 규모 입력, 학원의 주변 업종 구성 입력을 고정했다. 구군 9곳 중 2곳을 학습에서 제외하는 36개 조합에서, 남은 7개 구군으로 각각 기존 포아송 회귀와 입력 추가 모델을 학습했다. 각 지역은 서로 다른 제외 조합에서 8번 평가됐다. 그 반복 관측을 독립적인 지역 표본으로 해석하지 않는다. 대상 업종의 실제 점포 수는 주변 입력에도 포함하지 않았다.

| 업종 | 기준월 | 기존 평균 오차 → 입력 추가 | 기존 최대 오차 → 입력 추가 | 개선된 제외 조합 |
| --- | --- | ---: | ---: | ---: |
| 백반/한정식 | 2025-06 | 13.42 → 13.29 | 114.03 → 112.96 | 25/36 |
| 백반/한정식 | 2026-09 | 13.60 → 12.85 | 162.20 → 121.62 | 31/36 |
| 입시·교과학원 | 2025-06 | 7.60 → 6.97 | 182.83 → 134.73 | 23/36 |
| 입시·교과학원 | 2026-09 | 7.98 → 6.91 | 199.50 → 169.83 | 28/36 |

단위는 점포 수다. 더 많은 구군을 학습에서 제외해도 두 업종의 평균·최대 오차가 두 시점 모두 줄었다. 백반/한정식의 2025-06 평균 개선은 약 0.14곳으로 작다. 이번 결과는 동일한 두 시점에서 공간 분할을 바꾼 강건성 점검이다. 별도 시점의 독립 검증은 남아 있다.

`python scripts/evaluate_a10_two_districts.py`로 실행한다. 월별 `data/raw/a10/nearby_two_districts_predictions_YYYY-MM.csv`와 `nearby_two_districts_evaluation.json`에 결과를 저장했다. 두 달 각각 2,432행에서 지역·업종·제외 조합 키 중복 없음, 지역별 8회 평가, 조합별 평가 구군 일치, 평균·최대 오차 재계산을 확인했다.

다음은 백반/한정식과 학원의 개선 후보에 대해 최신 한 구군 제외 추정치를 기존 앱 자료와 나란히 비교하고, 최신 자료 전체를 학습한 경우의 추정치와 차이를 확인해 연동 자료 버전을 정하는 것이다. 구군 제외 평가값과 전체 자료 학습값의 역할을 명시한다. 카페·미용실은 기존 후보를 유지한다.

## 새 시점 자료 공개 확인

2026-11-19에 [공공데이터포털 공식 파일 페이지](https://www.data.go.kr/data/15083033/fileData.do)를 확인했다. 실제 HTML의 제목과 Dataset 메타데이터는 **소상공인시장진흥공단_상가(상권)정보_20260930**이며, 페이지 수정 시각은 **2026-10-30 09:00:56**이다. 제공 주기는 분기로 안내돼 있다. 페이지 수정월과 자료 기준월을 구분해야 한다. 이번에 확인한 공식 페이지에는 기존 2026-09보다 뒤의 기준월 자료가 제시돼 있지 않아 추가 평가를 실행하지 못했다.

새 자료 확보 시 백반/한정식은 주변 규모, 학원은 주변 업종 구성 입력과 기존 포아송 설정을 고정해 비교한다. 같은 달의 주민등록 인구를 연결하고, 행정동 코드 변경·인구 0명·업종 분류 변경·중복·좌표를 먼저 점검한다. 구군 한 곳 제외 평가의 평균·최대·구군별 오차를 기존 모델과 비교한다. 이 평가는 같은 달 점포 수의 지역별 추정력 확인이다. 미래 시점 예측력을 확인하려면 과거 자료만 학습하는 평가도 별도로 설계해야 한다. 새 자료를 확인하기 전에 선택한 설정을 바꾸면 변경 이력을 남긴다.

이전에 보지 않은 과거 분기 자료를 추가 확보하면 추가 시점의 재현성을 먼저 확인할 수 있다. 이미 결과를 확인한 2025-06·2026-09와 시간상 겹치는 점포가 있을 수 있으므로 과거 분기 검증의 한계를 함께 기록한다. 다음 분기 자료의 정확한 공개일은 확인되지 않았다.

## 추가 시점 2026년 6월 검증

2026-11-19 공식 포털의 주기성 과거 데이터 목록에서 **20260630** 파일을 확보했다. 공개 이력 식별자는 `uddi:b3094bc9-8756-4ecc-9141-9144b98a531e`다. 다운로드 제한 확인 결과 CAPTCHA 요구가 없었다. 전국 압축파일은 스트리밍으로 읽어 대구 CSV만 보관했다. 대구 파일 크기는 63,309,879바이트이며 압축 항목 CRC와 길이를 확인했다. 원본 SHA-256은 `e8b6bd64429c2fc41352cff3b8f6879e566b48994e4d2feacc30e27465a579b0`다.

원본 점포 118,357건을 같은 달 인구와 연결해 읍면동 152곳을 평가했다. 기존 로더의 업소 ID 중복·필수 필드 누락·인구 코드 연결 검사를 통과했고 인구 0명 제외 지역은 없었다. 원천 집계와 기존 모형 추정 재현을 확인했다. 학습은 기존과 같이 구군 하나를 제외하는 9개 분할에서 진행했다. 앞서 정한 백반/한정식의 주변 규모 입력, 학원의 주변 업종 구성 입력과 포아송 설정을 고정해 적용했다.

| 업종 | 기존 평균 오차 → 고정한 개선 후보 | 기존 최대 오차 → 개선 후보 | 개선 구군 | 개별 지역 오차 감소 / 증가 |
| --- | ---: | ---: | ---: | ---: |
| 백반/한정식 | 13.16 → 12.86 | 107.60 → 96.02 | 7/9 | 74 / 78 |
| 입시·교과학원 | 7.32 → 6.95 | 188.30 → 151.02 | 6/9 | 85 / 67 |

단위는 점포 수다. 두 업종 모두 처음 사용한 추가 시점에서도 평균·최대 오차가 줄었다. 백반/한정식은 평균이 좋아졌지만 오차가 증가한 개별 동네가 더 많았다. 모든 동네의 개선으로 해석하지 않는다. 카페와 미용실도 진단용 결과를 남겼으나, 개선 후보 선택을 이 추가 시점 결과에 맞춰 바꾸지 않았다.

서로 다른 분기에도 같은 점포가 존재할 수 있다. 이번 결과는 추가 기준월에서 같은 달의 지역별 점포 수 추정이 개선됐는지 확인한 결과다. 미래 예측 성능이나 완전히 독립적인 신규 점포 검증으로 해석하지 않는다.

`python scripts/collect_a10_202606.py`로 공식 원본을 수집하고 `python scripts/evaluate_a10_additional_month.py`로 재현한다. 원본은 `data/raw/a08/daegu_stores_202606.csv`, 수집 근거는 `data/raw/a10/202606_source.json`, 결과는 `data/raw/a10/additional_month_evaluation.json`과 `nearby_predictions_2026-06.csv`에 저장했다. 608행의 키 유일성·업종별 152행·평균 및 최대 오차 재계산 검증을 통과했다.
