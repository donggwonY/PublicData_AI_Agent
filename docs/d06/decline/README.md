# D-06 대구 프랜차이즈 가맹점 감소 예측

2026-11-19. 질문: 대구에 가맹점 3개 이상인 브랜드의 다음 회계연도 가맹점 수가 감소하는가?

## 자료와 시점

현재 보유한 공정위 지역별 매출 API의 가맹점 수·업종을 사용했다. 목표 회계연도 직전의 점포 수와 그 이전 연도의 변화만 입력한다. 매출 공개 여부로 제한하지 않는다. 목표 기록 자체가 없는 경우는 제외하고 명시적0은 유지했다. 원천 자료 부재에 따른 선택 편향이 남는다.

이전의 t-2 대비 증가·유지·감소 실험과 다른 이진 목표다. 직전 회계연도 자료가 실제로 언제 공개됐는지 확인되지 않아 실시간 향후1년 예측으로 표현할 수 없다. 차기 공표값에 대한 회고적 실험이다. 개발 목표연도2022~2023, 평가2024, 미완결 가능성이 있는2025는 잠정 결과다. 같은 연도 자료를 기존 연구에서 확인했으므로 독립된 미사용 시험이라고 주장하지 않는다.

브랜드 목록·전국 개점/종료/해지·지역별 가맹/직영 추가 원본은 현재 PC에 없다. 로컬 인증키로 API3종 최소 요청은 모두HTTP403이었다(access_check.json). 추가 변수 실험은 아직 수행하지 않았으며 브랜드 나이·전국 추세·매출 변화도 이번 모델에 포함하지 않았다.

## 결과

개발 기간의 확률 오차(Brier score, 낮을수록 좋음)로 업종 평균 감소율 기준선과 부스팅 모델을 선택한 뒤 평가했다. 경고 문턱0.5는 고정했다.

| 목표 회계연도 | 표본 | 업종 평균 확률 오차 | 부스팅 확률 오차 | 부스팅 전체 적중 | 감소 경고 중 실제 감소 | 실제 감소 중 탐지 |
|---|---:|---:|---:|---:|---:|---:|
|2024|813|0.23942|0.22409|64.45%|62.77%|35.01%|
|2025 잠정|672|0.24184|0.23022|62.35%|63.35%|34.46%|

과거 감소 방향을 그대로 쓰는 방법의 전체 적중률은2024년62.85%,2025년60.71%였다. 모델의 전체 적중 개선은 각각1.60%p,1.64%p로 작다. 확률 오차는 업종 평균보다 약6.40%,4.81% 줄었지만 경고가 실제 감소의 약35%만 탐지한다. 전체 정확도만으로 경고 기능 품질을 판단하지 않는다. 미래 실시간 이용 가능성과 신뢰구간·경고 문턱 검증도 남는다.

## 판단과 후속

현재 입력만으로도 확률 예측 개선이 관측됐다. 다만 경고가 놓치는 감소 사례가 많아 완성된 상담 기능으로 확정하지 않는다. 추가 자료의 계약 종료·해지·전국 추세·브랜드 나이를 연결해 개선 여부를 비교하고, 개발 기간에서 경고 문턱을 선택해 경고 정확도와 탐지율의 균형을 평가한다. 서비스 사용 방식은 이 검증 결과로 판단하며 단일 임의 성능 기준만으로 자동 배제하지 않는다.

중복·학습 정답시점·3개 이상 대상·정답 정의 검증 통과. 코드 scripts/evaluate_d06_decline.py, 계획 protocol.json, 개발 선택 selection.json, 상세 결과 results.json. 운영 DB·앱 변경 없음.

## 추가 자료 확보·비교 완료
