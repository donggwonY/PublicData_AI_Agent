# 감소 확률 보정 검토

2026-11-19. 저장된 추가변수 모델의 예측만 사용했다.2022년 예측의 로짓에 로지스틱 보정(C=1)을 적합하고2023년 Brier score로 원본 유지 여부를 선택했다. 선택 후 보정식을 재적합하지 않고2024년과 잠정2025년을 비교했다. 기존 평가 연도를 재사용한 탐색 결과로 독립 검증은 아니다.

2023년 원본 확률 오차0.223594, 보정0.224907로 보정이 나빠 원본 유지로 선택했다.2024년도 원본0.219856·보정0.220850,2025년도 원본0.227574·보정0.228605였다. 보정이 항상 개선되는 것은 아니며 이번 보정은 적용하지 않는다. 이는 모델 전체의 서비스 사용 여부 결정과 구분한다.

원본 평균 감소 확률은2024년40.01%, 실제 감소 비율41.45%,2025년41.71% 대44.05%였다. 전체 평균은 비교적 가깝지만 개별 브랜드의 정확성이나 모든 확률 구간의 신뢰성을 보장하지 않는다. 고정된20% 폭 확률 구간별 표본 수·예측 평균·실제 감소율은 calibration_bins.csv에 함께 기록했다. 작은 구간은 불확실성이 크므로 확정적 확률로 표시하면 안 된다. 미래 실제 공표 시점과 최신 자료 완결성도 여전히 확인이 필요하다.

시그모이드 변환은 순서를 보존하므로 AUC는 변하지 않았다. 감소를 놓치는 문제를 보정만으로 해결했다고 주장하지 않는다. 현재는 추가변수 원본 모델을 비교 후보로 유지한다. 운영 DB·앱 변경 없음.
