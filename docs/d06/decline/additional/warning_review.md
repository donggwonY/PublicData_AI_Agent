# 경고 기준 및 추가 변수 개선 불확실성

2026-11-19. 모델 재학습 없이 저장된 예측을 사용했다. 개발2022~2023에서 경고 정확도60% 이상·경고50건 이상 조건으로 탐지율을 최대화하는 기준을 탐색했다(0.10~0.90,0.01간격). 60%는 실험용 조건이며 팀이 승인한 서비스 채택 기준이 아니다. 선택값을 저장한 뒤 이후 연도를 평가했다. 기존 평가 기간 재사용 한계가 유지된다.

선택 문턱0.51. 개발1,470건 중321건 경고,193건 실제 감소(60.12%), 실제 감소 탐지33.10%. 개발 전체 조건이며2022년 단독 경고 정확도는56.96%로60%에 미달한다.

경고 정확도는 조금 올랐지만 감소를 더 놓친다. 경고 문턱 조정만으로 판별력이 높아졌다고 해석하지 않는다. 경고가 없다는 이유로 안전한 브랜드라고 설명할 수 없다.

추가 입력과 기본 입력의 확률 오차 차이를2024~2025 합쳐 브랜드 단위2,000회 재표집했다. 평균 차이 -0.00352,95% 구간 -0.00804~+0.00072로0을 포함한다. 연도별 오차 감소는 관측됐지만 개선이 확실하다고 단정할 근거는 부족하다. 이 계산에는 잠정2025가 포함되고 사후 반복 실험의 선택 불확실성은 반영하지 않는다.

현재 서비스 검토 방향은 단정적인 감소 경고보다 자료 기준일·과거 점포 수 흐름과 함께 보여주는 참고용 감소 신호다. 실제 미래 이용 가능 시점, 브랜드별 누락·최신성, 확률 보정 및 사용자에게 설명 가능한 범위를 더 확인해야 한다. 이 문서는 배포 승인이나 서비스 채택 확정이 아니다. 운영 DB·앱 변경 없음.
