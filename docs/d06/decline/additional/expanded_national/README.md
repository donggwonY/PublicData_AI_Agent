# 미사용 전국 매출·점포 증감 추가 실험

2026-11-20. 기존 대구 가맹점3개 이상 감소 예측과 동일 표본·고정 부스팅 설정으로 비교함. 아직 사용하지 않은 전국 평균매출·매출 변화·전국 가맹점 수 변화·전국 신규 개점 대비 계약 종료 및 해지 차이를 추가함. 전국 자료 기준년도는 기존과 동일한목표연도-1 및 그 이전연도만 연결함. 미확인·매출0은 실매출0으로 대체하지 않고 학습기간 중앙값과 누락표시로 처리함.

외식 통합 API15165094는 로컬 키로403이어서 이번 학습에 사용하지 않음. 현재 결과는 기존 승인자료에서 미사용 정보를 추가한 실험임. 실제 과거 공개일·자료 정정·브랜드 이름 연결 한계는 유지함. 전국 금액 단위는 미확인이며 원화 금액으로 표시하지 않음.

개발2022~2023 합산 확률 오차로 확장 모델을 선택함.2024평가 및2025잠정을 개발 이후 비교함. 이미 확인한 평가 기간을 재사용한 탐색 실험임.
