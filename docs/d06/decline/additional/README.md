# 추가 정보 비교 결과

2026-11-19. 대구 가맹점3개 이상 브랜드의 차기 회계연도 감소 여부. 기존 고정 표본 그대로 사용한 탐색적 후속 비교다. 과거 평가 기간을 재사용했으므로 독립적인 최종 검증이 아니다.

기본 입력은 대구 점포 수·증감·업종이다. 추가 입력은 브랜드 나이, 대구 직영점 수, 전국 가맹점 수, 신규 개점·계약 종료·해지·명의변경 비율이다. 전국 통계는 시점 혼입을 줄이기 위해 지역 입력의 공표 기준연도보다1년 이전 자료만 연결했다. 실제 과거 공개일은 미확인이다. 비율은 해당 전국 자료의 가맹점 수를 나눈 비교 변수로 엄밀한 사건 발생률이 아니다. 매출 변화와 전국 증감은 이번 비교에는 포함하지 않았다.

브랜드 목록의 동일 정보 중복은 합치고 상충하는 브랜드 번호는 메타정보 연결에서 제외했다. 전국 통계는 브랜드명·법인명 정확 일치의 고유 기록만 연결했다. 연결 실패 표본을 삭제하지 않고 학습 자료의 중앙값과 누락 표시를 사용했다. 원본 수집29파일의 행수·SHA256을 확인했으며 상세 연결률은 ../source_join_audit.json, 추가 변수 가용률은 results.json에 있다.

추가 정보로 네 연도 모두 확률 오차가 줄었고 AUC도 올랐다. 개선 폭은 작지만 추가 변수 검토의 근거가 생겼다. 경고 기준0.5에서2025 탐지율은34.46%에서41.89%로 올랐으나 경고 정확도는63.35%에서60.78%로 낮아졌다. 따라서 모든 품질 지표가 개선됐다고 표현하지 않는다. 개선의 불확실성 평가와 개발 기간에서 경고 문턱 선택이 남았으며 서비스 적용 여부를 확정하지 않는다.
