2026-11-20. 승인 후2017~2026기준년도10개년49,617행을 수집함. 연도별 행수·SHA256은 ../eatout_manifest.json. 원본은 data/raw/d06_franchise/eatout_*.jsonl.gz에 보관함.

이 서비스에는 브랜드명·원래 관리번호 대신 가명 번호가 있어 기존 브랜드와 직접 연결하지 않음. 업종별 가맹비·교육비·보증금·기타비용·예치금·인테리어비 및 최초/연장 계약기간 중앙값으로 요약함. 브랜드 개인 비용으로 설명하지 않음. 금액 단위는 공식 확인 전 금액 표시하지 않음. 비용0은 제공된 숫자로 유지하고 음수·누락은 미확인 처리함.0이 비공개 표시인지 해석은 추가 확인 필요함.

전국 계약 변수와 동일하게 목표 회계연도-1기준년도만 입력함. 실제 과거 공개일·사후수정 시점은 미확인. 신규 자료의 효과를 비교하기 위해 업종 맥락이 연결된 외식 표본 안에서 기존정보 모델과 비용/기간 추가 모델을 모두 재학습함. 이 표본 점수를 이전 전체 업종 모델과 직접 비교하지 않음.
