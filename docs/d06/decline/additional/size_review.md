# 가맹점 규모별 감소 예측 진단

2026-11-19. 저장된 예측과 원래 평가 표본을 브랜드·연도로 일대일 연결했다. 대상은2024년813건, 잠정2025년672건이며 입력 시점 대구 점포 수로3~5,6~10,11개 이상으로 나눴다. 경고 문턱은 개발 기간에서 선택한0.51로 고정했다. 평가 결과를 보고 규모별 문턱을 바꾸지 않았다.

|규모|2024 경고 정확도 / 감소 탐지율|2025 잠정 경고 정확도 / 감소 탐지율|
|---|---|---|
|3~5개|60.47% / 19.12%|54.72% / 23.39%|
|6~10개|63.89% / 47.42%|66.67% / 50.00%|
|11개 이상|67.53% / 50.00%|60.56% / 51.19%|

3~5개 브랜드의 감소 탐지가 특히 낮다. 추가 입력은 이 구간의 확률 오차를 두 해 모두 줄였으나, 현재 경고 문턱에서는 실제 감소의 약5분의1만 찾았다.6~10개는2024년에 추가 입력으로 개선했지만2025년 확률 오차는 악화했다.11개 이상은2024년 거의 같거나 미세하게 악화했고2025년 개선했다. 전체 개선이 모든 규모에서 일관된 것은 아니다.

3개 이상은 현 연구의 범위이며 최적 기준으로 검증된 수치가 아니다. 이번 진단에는1~2개 브랜드가 없으므로3개 제한의 우월성이나1~2개 예측 불가능을 주장할 수 없다. '한 곳 변동의 비중이 크다'는 범위 설정 이유와 예측 성능의 실증 근거는 구분한다.3~5개를 제거하면 서비스 대상이 달라지므로 평가 점수를 높이기 위한 사후 제외는 하지 않는다.

다음 검토는 개발 기간만 사용한 규모별 확률 점검 및 경고 기준 비교다. 규모별 기준을 쓰더라도 이후 연도에서 경고 정확도·탐지율·표본수를 모두 보고한다. 경고 없음은 안전을 뜻하지 않는다. 운영 DB·앱 변경 없음.

세부 수치: size_validation.csv. 입력은 predictions.csv와 ../eligible_cells.csv이며, 중복 브랜드·연도·모델 없음 확인. 기존 평가 연도 재사용에 따른 탐색 한계와2025 미완결 가능성을 유지한다.
