# 상담 참고정보 사례 검증

2026-11-19. 2024 회계연도에 대한 과거 예측 사례이며 현재 브랜드 상태나 앞으로1년의 예측이 아니다.2024 기준년도 지역 자료는2023 회계연도, 전국 계약 통계는 그보다1개 기준년도 이전인2023 자료를 사용했다. 실제 과거 공개일 미확인으로 당시 실시간 상담 가능성을 확정하지 않는다.

## 선정과 대조

전체813건에서 기존 매출 API의 과거 점포 수와 별도 지역 API를 대조했다. 불일치 행은 source_count_discrepancies.csv에 기록하고 이번 상담 예시에서는 제외했다. 모델 평가 표본에서 삭제한 것은 아니다. 실제 대조 결과는 두 API 모두 존재하는764건의 점포 수가 전부 일치했고,49건은 별도 지역 API에 행이 없었다. 이49건의 누락 원인은 미확인이며 운영 입력을 혼용하기 전에 확인해야 한다. 예측 기준0.5에서 맞은 경고·틀린 경고·놓친 감소·감소 없는 비경고 네 유형을 나눈 뒤, 이름 및 전국 기록이 연결된 사례 중 확률 중앙 순서의 브랜드를 각1개 선택했다. 결과를 잘 보이게 하는 성공 사례만 고르지 않았다. 이4개 사례는 전체 품질의 추정 표본이 아니다.

- 연구 모델의 2024년 감소 확률: 35.5%.
- 전국 2023 기준년도 통계: 신규 2건, 계약 종료 4건, 해지 0건. 대구 사건 수로 해석하지 않는다.
- 사후 검증용 실제 2024년 대구 가맹점 수: 3개. 이 값은 상담 입력에 사용하지 않는다.
- 상담 확인 사항: 대구 점포 수 흐름과 전국 계약 변동이 서로 같은 방향인지, 본사 설명과 최신 정보공개서를 추가 확인한다. 계약 종료·해지는 사업 실패나 대구 점포 감소 원인으로 단정하지 않는다.

## 활용 판단

예측·대구 과거 수치·전국 계약 변동을 구분해 나란히 제시하는 상담 구조는 구성 가능하다. 다만 이 검증은 자료 대조이며 실제 사용자 평가나 LLM 상담 응답 검증은 아니다. 전국 자료를 대구 자료로 바꾸어 설명하거나, 특정 변수가 예측의 원인이라고 설명하지 않는다. 별도 기여도 검증 없이 수치 나열을 모델 설명으로 부르지 않는다.

실제 상담에서는 사후 결과를 숨기고 예측 대상 기간과 자료 기준일을 표시해야 한다. 자료가 빠진 브랜드는 누락이라고 밝힌다. 낮은 확률을 안전·추천으로 표현하지 않는다. 브랜드별 현재 경고를 게시하거나 운영 DB·앱을 변경하지 않았다. 60% 등 시험용 문턱 하나의 미달을 서비스 부적합 근거로 사용하지 않는다.
