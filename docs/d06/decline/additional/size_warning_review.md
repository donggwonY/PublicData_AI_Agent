# 연도 분리 규모별 경고 기준 검증

2026-11-19. 기존 추가변수 모델의 저장 예측을 재사용했다.2022에서 규모별 후보 문턱을 정하고2023에서 검증·고정한 뒤2024 평가,2025 잠정 평가 순서로 실행했다. 모델 자체는 각 예측 목표연도보다 앞선 학습 정답을 사용한다. 이번 절차의 고정은 이미 확인한 평가 자료가 새 독립 시험으로 바뀐다는 뜻은 아니다.

2022 후보 조건: 경고 정확도60% 이상·20건 이상 중 탐지율 최대.2023에서 정확도60% 이상과 기존0.5보다 높은 탐지율을 모두 만족한 규모에만 후보 적용. 조건 미충족 시 기존0.5 유지.60%와20건은 시험용 조건이며 서비스 전체 채택 여부를 정하는 팀 합의 기준이 아니다. 이전0.51은2022~2023을 합쳐 정했으므로 이번2023 독립 선택 비교의 기준선으로 쓰지 않았다.

3~5개와11개 이상은 변경 후보가 채택되지 않았고,6~10개는2022에서0.41 후보가 나왔으나2023 검증 조건을 통과하지 못했다. 최종 정책은 모든 규모0.5 유지다.

검증을 통과하지 못한 후보도 투명하게 기록한다.6~10개에0.41을 적용하면2024 탐지율37.98%→41.84%, 경고 정확도62.44%→62.39%;2025 탐지율41.89%→45.27%, 정확도60.78%→59.56%였다. 이후 연도 수치가 좋아 보인다는 이유로2023에서 탈락한 후보를 채택하지 않았다.

결론: 규모별 문턱 변경의 일관된 이점을 확인하지 못했다. 이는 추가변수 모델 자체를 폐기한다는 뜻이 아니다. 기존0.5 기준과 과거에 따로 정한0.51 참고 기준의 검증 이력을 구분하며 이번 선택을0.51보다 우월하다고 설명하지 않는다. 더 낮은 경고 정확도를 허용할지 등 사용자 효용은 별도 결정사항이다. 현재 모델은 감소 신호의 참고 후보이며 운영 DB·앱은 변경하지 않았다.
