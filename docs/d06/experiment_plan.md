# D-06 가맹점 감소 예측 실험계획과 실행 정리

정리일: 2026-11-21. 실험 전에 저장한 설정은 decline/protocol.json과 decline/additional/protocol.json이며, 이 문서는 해당 설정·실행 코드·저장 결과를 모아 정리한 통합본임. 모든 내용을 사전에 고정한 새 실험계획서로 소급해서 설명하지 않음.

## 1. 질문과 대상

대구에 가맹점이3개 이상인 브랜드의 다음 회계연도 가맹점 수가 감소하는지 예측함. 입력연도t의 점포 수가3개 이상이고t-1 비교 기록이 있는 브랜드를 사용함. 정답은 count[t+1]<count[t]임. 가맹점 수 감소는 사업 실패·계약 부적합과 동일하지 않음. 3개 기준은 연구 범위이며 최적 기준으로 검증된 수치는 아님.

## 2. 사용 자료와 연결

- 공정위 브랜드별 지역 매출 API15125494의 대구 가맹점 수: 초기·감소 모델의 지역 수치와 정답에 사용함.
- 브랜드 목록15125467: 관리번호·브랜드명·업종·가맹사업 시작일.
- 지역 가맹/직영15125490: 직영점 수와 지역 점포 수 교차 대조.
- 전국 가맹점 현황15110241: 전국 가맹점·개점·계약 종료·해지·명의변경.

수집 기준년도2017~2026, 지역 회계연도2016~2025임. 브랜드 관리번호·연도로 연결하고, 전국 현황은 브랜드명과 법인명이 정확히 맞는 고유 기록만 사용함. 상충 이름·다중 기록은 임의 선택하지 않음. 목표 기록이 없는 브랜드는 학습 정답에서 제외하고 원본에 명시된0은 유지함. 따라서 관측이 이어진 브랜드에 대한 선택 편향이 남음.

## 3. 기간과 입력

목표 회계연도가Y일 때 지역 입력은회계Y-1·Y-2, 지역 기준년도Y 자료임. 전국 변수는기준년도Y-1을 연결해 한 기준년도 더 지연시킴. 실제 과거 공개일·사후 정정 이력은 미확인이라 회고적 실험으로 해석함.

|역할|목표 회계연도|학습 정답 범위|
|---|---|---|
|개발 비교|2022·2023|각 목표연도보다 이전|
|평가|2024|2023까지|
|잠정 평가|2025|2024까지|
|최신 보유 자료 전망|2026|2025까지|

개발·평가 연도보다 앞선 가용 과거 표본을 학습에 사용함.2024·2025 자료를 앞선 연구에서 이미 살펴봤고 후속 실험도 같은 기간을 재사용했으므로 미사용 독립 최종시험으로 설명하지 않음.

입력은 대구 매장 수·과거 증감·업종,대구 직영점 수,전국 가맹점 수,신규개점/계약 종료/해지/명의변경 비율,브랜드 나이임. 비율의 분모는 해당 전국 가맹점 수이며 엄밀한 사건 발생률과는 구분함. 결측은 학습 표본에서 계산한 중앙값과 누락 표시로 처리하며 전달 데이터에는 원래 누락을 유지함.

## 4. 비교 방법과 평가

기준선은 전체 감소 비율·업종 평균 감소 비율·과거 감소 방향 유지임. 로지스틱 회귀와 HistGradientBoostingClassifier를 비교함. 추가정보 부스팅 설정은100회,학습률0.05,최대리프7,최소리프표본30,L2=10,seed20261119임.

개발 기간의 Brier score로 기본 후보를 비교함. Brier는 낮을수록 좋은 확률 오차임. AUC,경고 정확도,실제 감소 탐지율을 함께 보고함.0.5는 비교용 문턱이며 서비스 공통 경고 기준으로 승인된 값이 아님. 뒤의60% 경고 정확도 조건은 탐색용 조건으로 서비스 사용 금지 기준이 아님.

## 5. 실행 결과와 선택

|목표 연도|표본|기본정보 Brier|추가정보 Brier|추가정보 경고 정확도(0.5)|감소 탐지율|
|---|---:|---:|---:|---:|---:|
|2024|813|0.22409|0.21986|62.44%|37.98%|
|2025잠정|672|0.23022|0.22757|60.78%|41.89%|

추가정보 원본 부스팅을 전달 후보로 유지함. 확률 보정은 검증에서 악화했고,전국 매출/매장 증감 추가와 외식업종 비용/계약기간 추가는 평가시기별 개선이 일정하지 않아 반영하지 않음. 지역 확장 예측도 이번 상담 연결 대상에서 제외함. 추가정보 개선의 브랜드 재표집 구간은0을 포함해 확정적인 성능 우월성을 주장하지 않음. 상담 참고정보 활용은 단일 임의 기준의 통과 여부와 구분함.

## 6. 최신 전망과 전달

2025년까지의 정답5,451건으로 고정된 추가정보 부스팅을 재학습해738브랜드를 계산함. 브랜드명 확인727개,전국자료 연결713개. 자료는 delivery/current/consultation_current.json,조회 함수는 scripts/d06_franchise_lookup.py임.

예측 대상은2025년말 대비2026년말 감소 여부임. 생성일2026-11-20 이후 향후12개월이나2027년말 전망이 아님. 기존 매장 수 변화와 예측 기간을 함께 표시함. 과거 평가 결과와 최신 전망의 검증 상태는 구분함.
