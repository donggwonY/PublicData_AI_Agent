# 최신 보유 자료 기반 상담용 전망 데이터

생성일2026-11-20. 전달 파일 consultation_current.json·consultation_current.csv. 대구2025년말 가맹점3개 이상이고2024년말 비교 기록이 있는738브랜드. 이름 확인727개,전국 계약 자료 연결713개. 미확인 이름11개 및 전국 자료25개는null/빈칸과unavailable로 구분함.

## 예측 기간과 항목

예측 질문:2026년말 대구 가맹점 수가2025년말보다 줄어들까? target_accounting_year=2026,baseline_accounting_year=2025. 생성일 이후 향후12개월 또는2027년말 예측이 아님. 상담 도구는 target와baseline을 그대로 반환하고 기간을 생략하지 않아야 함.

지역 자료의 기준년도2026은 회계2025년 자료임. 전국 신규 개점·계약 종료·해지 자료는 기존 실험과 동일하게2025기준년도를 연결함. 전국 사건 수를 대구 사건 수로 표시하지 않음. 최신2025자료 완결성은 확인되지 않았고 브랜드명 변경·누락도 있을 수 있음.

회계2025년까지의 정답5,451건으로 기존 추가정보 부스팅의 고정 설정을 재학습함. 보정하지 않은 원래 확률을 사용함. 이 전망은 생성 후 실제 결과로 아직 검증되지 않았으며 과거 평가 성능은 별도 delivery 데이터와 구분함. 실제2026년 수치·정답은 파일에 포함하지 않음.

## 연결 시 표시 예시

“2025년 말 기준 대구 가맹점은 ○개예요. 과거 흐름과 계약 변동 자료를 바탕으로2026년 말의 감소 가능성을 계산했어요. 최신 매장 현황과 계약 조건도 함께 살펴보면 좋겠어요.”

개별 숫자·변화 방향은 데이터로 생성하고 고정 문장에 임의 대입하지 않음. 이름 미확인은 관리번호로 보존하고 검색 대상에 추정 이름을 넣지 않음. 실제0과 자료 없음은 status로 구분함. 경고 문턱을 서비스 공통값으로 확정하지 않았으며 모델 전망·실제 관측값을 구분함.

재현 scripts/build_d06_current_scores.py. 브랜드 키 유일·확률0~1 확인. generation.json에 생성 조건·표본 수 기록. 앱·DB 연결은 수행하지 않음.
