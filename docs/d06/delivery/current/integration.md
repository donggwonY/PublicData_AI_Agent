# D-06 오늘 연결할 기능 정리

## 선택한 기능

브랜드별 대구 가맹점 변화와2026년말 감소 가능성을 상담에서 함께 조회함. 기존 추가정보 부스팅의 보정하지 않은 확률을 유지함. 전국 매출·점포 증감 추가 및 외식업종 비용·계약기간 추가 실험은 이후연도에서 일관된 개선이 없어 이번 적용에서 제외함. 구군 확장 예측도 이점이 작아 이번 적용에서 제외함. 실험 기록은 보존함.

## 연결 위치

- 조회 코드: scripts/d06_franchise_lookup.py 의 lookup_franchise(query)
- 데이터: docs/d06/delivery/current/consultation_current.json
- 반환 예시: lookup_examples.json
- 구성·검증·파일 지문: integration_manifest.json

외부 API나 모델 재학습 없이 저장된738브랜드 점수를 조회함. 정확한 브랜드명 또는관리번호로조회. 비슷한 이름만 있으면 후보 목록을 반환하며 임의로 다른 브랜드를 선택하지 않음. 이름 확인된 브랜드727개,미확인11개. 실제0은observed,없는값은unavailable와null로 반환함. 기존 미확인 국가계약 자료도숫자를만들지않음.

반환의 observed에는 과거 대구 점포 수와 전국계약 정보·각기준연도,forecast에는 예측대상기간·확률을 담음. title과message에2026년말임을 표시함. 2025년말 대비2026년말 감소 전망으로,생성일 이후향후1년이나2027년 전망으로 바꾸어 표시하지 않음. 이 기간은 모델 정답 정의에서 비롯되므로 문구만 바꾸면 안 됨.

모든 값을 과거자료 기반 참고정보로 안내하며,브랜드 계약 여부를 대신 결정하지 않음. 전달된message는 숫자를 이용한기본 설명이고 전국변동이원인이라고 단정하지않음. 고정60%와 같은 서비스 채택문턱은 두지않음.

## 준비 상태

738브랜드키유일·확률범위,실제브랜드검색,누락/0,빈질문/미등록브랜드,기간표시 확인완료. 연결용예시3건저장.서비스앱코드·DB·배포는변경하지않음. 동권님이상담도구에연결할준비까지완료함. 실제앱에서브랜드질문과기간·숫자표시를대조한뒤서비스적용완료로표시함.
