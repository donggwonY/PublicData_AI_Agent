# D-06 분석 결과·전달 데이터

## 전체 분석 흐름

|분석|대상·질문|주요 결과|
|---|---|---|
|브랜드 매출 예측|대구 브랜드의 다음 회계연도 평균 매출 범위 중간값|2023~2024 587건. 마지막 공개 매출 유지의 평균 상대오차26.81%. 회귀·부스팅·강건한 방법에서 안정적 개선 미확인.|
|가맹점 변화 예측|초기: 대구 가맹점1개 이상 브랜드의 증가·유지·감소 → 현재:3개 이상 브랜드의 다음 회계연도 감소 여부|초기 실험은 단순 추세45.42%·부스팅52.37%의 전체 적중률을 보였으나 규모별 개선이 일정하지 않았다. 현재는 전국 신규 개점·계약 변동 등을 추가해 확률 오차가 소폭 줄었으며, 이 분석의 결과를 전달 데이터로 정리했다.|

### 가맹점 변화 예측의 진행 과정

1. **초기 실험:** 대구 가맹점1개 이상 브랜드를 대상으로 증가·유지·감소를 구분했다. 2023~2024년3,124건을 평가했다. 공개 시차를 반영해 목표연도와2년 전 공개 수치의 변화 방향을 비교했다.
2. **현재 분석:** 대구 가맹점3개 이상 브랜드의 다음 회계연도 감소 여부로 질문을 좁혔다. 전국 신규 개점·계약 종료·해지·브랜드 나이 등을 추가했고,2024년813건과2025년 잠정672건을 평가했다. 현재 전달 데이터는 이 단계의 결과다.

1개 이상 분석과3개 이상 분석은 대상뿐 아니라 예측 기간과 정답 종류도 달라 점수를 직접 비교해3개 제한이 더 좋다고 결론 내릴 수 없다.3개는 최적 기준으로 검증된 수치가 아니다.

후속 비교로 확률 보정, 매장 규모별 오류, 경고 문턱 조정, 기간 분리 검증을 진행했다. 확률 보정은 개발 검증에서 악화해 원본 확률을 유지했다. 경고 문턱을 낮추면 감소를 더 찾는 대신 틀린 경고가 늘었다. 실험용 조건 충족 여부와 상담 참고정보 활용 여부는 구분한다.

## 현재 전달 모델의 분석 결과

질문은 대구 가맹점3개 이상 브랜드의 다음 회계연도 가맹점 감소 여부다. 로지스틱 회귀·부스팅을 비교했고, 추가 정보를 넣은 부스팅의 보정 전 확률을 전달한다. 추가 정보는 전국 신규 개점·계약 종료·해지·명의변경, 전국 가맹점 수, 대구 직영점 수, 브랜드 나이다.

|평가 회계연도|표본|기본 모델 확률 오차|추가 모델 확률 오차|0.5기준 경고 정확도|감소 탐지율|
|---|---:|---:|---:|---:|---:|
|2024|813|0.22409|0.21986|62.44%|37.98%|
|2025 잠정|672|0.23022|0.22757|60.78%|41.89%|

확률 오차는 Brier score이며 작을수록 좋다. 추가 정보로 평균 오차가 소폭 줄었고, 확률 보정은 개발 검증에서 악화해 적용하지 않았다. 규모별 경고 문턱 변경도2022설정·2023검증에서 선택되지 않았다. 확률 자체를 전달하며 서비스 공통 경고 기준을 확정한 것은 아니다.

- consultation_data.json / consultation_data.csv: 과거2024·2025 예측1,485행·930브랜드. 현재 전망값이 아니라 저장된 과거 평가 예측이다.

## 누락 처리 기준

JSON의 null 및 CSV의 빈칸은 미확인 값이다. 이를0으로 채우지 않는다. 원본에서 확인된0은 observed로 유지한다. 누락 여부는 값별로 표시하며 다른 확인된 항목은 그대로 사용할 수 있다.

- 확인된0: “계약 해지0건”
- 누락: “계약 해지 정보는 아직 확인되지 않았어요.”
- 브랜드명 누락: 이름을 추정하지 않고 관리번호로 구분한다. 사용자용 브랜드명 검색에는 이름이 확인된 행만 연결한다.

현재1,485행 중 브랜드명 미확인50행, 전국 계약 항목 미확인182행이다. 모델 입력에서 누락값을 학습용으로 보완했더라도 전달 데이터에서는 실제 관측값처럼 표시하지 않는다.

## 상담 설명 방식

확인된 과거 수치와 모델 예측을 구분해 표시한다. 예: “당시 대구 가맹점 수가 조금 줄었어요. 예측에서도 감소 가능성이 나타나지만, 실제로는 달라질 수 있어요. 관심 있는 브랜드라면 최신 매장 현황과 계약 조건도 함께 살펴보면 좋겠어요.”

위 문구는 실제 과거 점포 수가 감소했고 예측 신호도 해당하는 경우의 예시다. 증가·유지 사례에 동일 문구를 사용하지 않는다.2024·2025 과거 평가라는 기간을 함께 표시한다.
