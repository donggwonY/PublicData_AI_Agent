# D-06 상담 연결 자료

2026-11-21 수정본. 이전 delivery/current의 738개 전용 파일 대신 이 폴더의 brand_registry.json과 scripts/d06_franchise_lookup.py를 함께 사용함.

## 제공하는 내용

과거 대구 가맹점이 3개 이상이었던 1,912개 브랜드를 검색할 수 있음. 확인된 과거 매장 수 흐름과 마지막 자료 연도를 표시함. 전망을 제공할 수 있는 브랜드는 927개이며 아래 두 방식으로 구분함.

|자료 상태|브랜드 수|전망|
|---|---:|---|
|2025년 수치 및 전년 비교 가능|753|2025년 말 대비 2026년 말 감소 여부. 1년 모델|
|2025년 미확인, 2024년 및 전년 비교 가능|174|2024년 말 대비 2026년 말 감소 여부. 별도 2년 모델|
|최근 관측이 더 오래됐거나 필요한 비교 자료 부족|590|확인된 과거 매장 수만 표시|
|마지막 확인 수치가 3개 미만|395|확인된 매장 수만 표시. 전망 미제공|

최근 관측이 2024년이어도 마지막 수치가 3개 미만이면 모델 대상이 아님. 590개는 최신 미확인 574개와 전년도 비교 부족 16개의 합계임. 이 숫자는 모든 운영 중 프랜차이즈 수를 뜻하지 않음.

## 최신 누락을 처리한 방법

공정위 지역 가맹/직영 API와 지역 매출 API의 같은 브랜드·회계연도 가맹점 수를 대조함. 유효한 지역 수치를 우선 사용하고, 없을 때만 같은 연도의 매출 API 수치로 보완함. 둘 다 수치가 있으면서 다른 2개 브랜드·연도는 충돌로 처리해 사용하지 않음. 행 없음·빈 숫자를 0개로 채우지 않고 원본의 명시적 0만 관측으로 유지함.

맘스터치·CU는 공식 API 개별 재조회에서도 2026 기준년도 수치가 비어 있었고, BBQ·세븐일레븐은 조회 행이 없었음(live_source_recheck.json). 이 확인은 저장 누락과 구분한 것이며, 등록 지연 등 전체 원인을 확정한 것은 아님.

이들 브랜드의 2025년 수치를 만들어 넣지 않음. 마지막 확인된 2024년 말 수치로 2026년 말까지 2년 간격을 예측하는 모델을 별도 구성함. 현재일부터 향후 12개월 또는 2027년 전망이 아님.

## 2년 모델 검증

정답은 count[Y]<count[Y-2], 대상은 Y-2년 3개 이상이며 그 전년도 관측이 있는 브랜드임. 지역 변수는 Y-2년까지, 전국 변수는 해당 지역 기준년도보다 1년 이전을 사용함. 학습 정답도 Y-2년까지로 제한함. 최신 2026 전망의 학습 정답은 2024년까지임.

개발 2022~2023에서 업종 평균 감소율과 고정 추가정보 부스팅을 비교해 확률 오차가 낮은 부스팅을 선택함. 2024 평가와 2025 잠정 평가는 다음과 같음.

|목표연도|표본|업종 평균 Brier|2년 부스팅 Brier|경고 정확도(0.5)|감소 탐지율|
|---|---:|---:|---:|---:|---:|
|2024|736|0.24674|0.23243|70.32%|53.69%|
|2025 잠정|644|0.24394|0.22994|67.09%|58.08%|

두 기간 합산 Brier 차이는 -0.01417, 브랜드 단위 재표집 95% 구간은 -0.02200~-0.00613임. 2025는 자료 미완결 가능성이 있고, 이미 탐색한 시기·최신 스냅샷을 재사용한 회고적 실험임. 실제 최신 미확인 브랜드들의 2026년 결과가 검증된 것은 아님. 1년 모델과 2년 모델은 정답 기간이 달라 점수를 그대로 비교하거나 혼합 순위로 보여주지 않음.

기존 1년 모델도 원천 대조 후 재학습함. 2024 표본 814건 Brier 0.21998, 2025 잠정 682건 0.22847로 이전과 비슷함. 상세 validation_metrics.csv 참조.

## 연결 함수와 응답

scripts/d06_franchise_lookup.py의 lookup_franchise(query)를 호출함. 정확 이름/관리번호로 조회하고 모호한 검색은 후보 목록을 반환함. 별도 API 호출이나 상담 중 재학습 없이 고정 JSON을 읽음.

- observed: 마지막 확인 연도·매장 수, history 시계열, 확인 가능한 전국 계약 자료와 기준년도
- forecast: 대상연도 2026, 기준연도 2025 또는 2024, horizon_years 1 또는 2, model_kind, 감소 가능성
- message: 자료 연도와 예측 기간을 구분한 설명
- data_status: current_projection / two_year_projection / latest_count_unavailable / below_three_stores / prior_year_unavailable

status가 ok여도 forecast는 null일 수 있음. 그때는 확인된 점포 수만 안내함. 전국 자료는 대구 사건 수가 아니며 누락은 unavailable로 유지함. 확률은 참고정보로 제공하고 계약 여부를 대신 판단하지 않음.

2년 전망 예시: “마지막으로 확인된 2024년 말 대구 가맹점은 ○개예요. 2025년 말 수치는 아직 확인되지 않아, 2024년 말 자료에서 2년 뒤를 예측하는 별도 모델을 사용했어요. 이를 바탕으로 계산한 2026년 말 감소 가능성은 약 ○%예요.”
