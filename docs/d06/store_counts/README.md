# D-06 가맹점 수 증가·유지·감소 예측: 첫 비교

2026-11-19. 현재 자료의 매출 실험 정리 후 별도 목표로 수행했다. 서비스 미반영.

## 질문과 시점

대구에서 가맹점이 있는 브랜드의 마지막 공개 점포 수보다 목표연도 점포 수가 늘어날지, 같을지, 줄어들지 예측한다. 공개 시차 때문에 목표연도 t에 t-2·t-3의 점포 수와 t-2 업종만 입력한다. 정답은 count[t]-count[t-2]의 부호다. 따라서 직전 실제 연도 대비 1년 증감 예측이 아니라 마지막 공개값 대비 변화이며, 실제 과거 공개일과 수정 이력은 미확인인 회고적 실험이다.

매출 공개 여부로 대상을 제한하지 않았다. t-2 점포 수가 양수이고 t-3 기록이 있는 브랜드가 대상이며, 목표연도 원본의 명시적 0은 유지하고 기록 자체가 없는 경우는 제외했다. 목표 기록이 없는 브랜드는 2023년 350개, 2024년 246개로, 이들의 변화는 알 수 없다. 따라서 관측이 이어진 브랜드에 대한 평가라는 선택 편향이 있다.

## 비교

개발 2021~2022에서 과거 방향 유지 기준선과 로지스틱 회귀를 선택한 뒤 2023~2024를 평가했다. 모든 시점의 학습 정답은 t-2까지다. 평가 대상은 3,124개 브랜드·연도, 1,873브랜드다. 2025는 자료 미완결 가능성이 있어 잠정 결과로 분리했다.

| 방법 | 전체 정답 비율 | 세 방향을 동등하게 평가한 점수 |
|---|---:|---:|
| 과거 증가·유지·감소 방향 유지 | 45.42% | 49.38% |
| 로지스틱 회귀(개발 기간에서 선택) | 49.94% | 51.21% |
| 부스팅 | 52.37% | 50.63% |

주지표는 각 실제 방향의 적중률을 평균한 balanced accuracy다. 단순 다수 방향 예측은 이 점수가 33.33%다. 회귀의 주지표 개선은 1.83%p이고 2023·2024 각각 개선했으나, 사전에 정한 3%p 개선 기준에 미달했다. 부스팅의 전체 정답 비율이 더 높더라도 평가 결과를 본 뒤 선택 모델을 바꾸지 않는다.

회귀는 실제 감소 1,362건 중 477건(35.02%), 유지 1,055건 중 741건(70.24%), 증가 707건 중 342건(48.37%)을 맞혔다. 특히 감소 탐지가 약해 브랜드 확장·축소 판단에 그대로 적용하기에는 부족하다. 매장 수 증감은 매출·수익·성공 여부를 의미하지 않는다.

## 결론과 다음 확인

단순 추세보다 작은 개선은 확인했지만, 이번 첫 비교는 서비스 채택 기준 미충족이다. 확정된 서비스 결과로 안내하지 않는다. 다음으로 목표연도 누락과 브랜드 규모별 오류를 확인해 자료 구성 문제인지, 작은 점포 수 변동을 구분하기 어려운지 살펴본다. 전체 방향 적중과 증가·감소 각각의 적중을 함께 확인한다.
