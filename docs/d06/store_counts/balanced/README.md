# 규모 기준선·균형 학습 후속 비교

2026-11-19. 같은 증가·유지·감소 정의와 2023~2024 평가 3,124건 유지. 이미 확인한 기간을 재사용한 탐색 실험으로 독립 검증이 아니다. 개발 2021~2022에서 기준선을 선택한 뒤 평가했다. 학습 정답은 항상 평가연도-2까지다.

규모별 다수 방향과 전체 클래스 비율로 보정한 규모 기준선을 추가했지만 개발 기간에서 선택된 기준선은 기존 과거 방향 유지였다. 부스팅에는 학습 클래스 빈도의 역수 가중치를 적용했다. 기존 회귀도 이미 클래스 균형 옵션을 사용했으므로 이번에 회귀의 균형 학습을 처음 도입한 것은 아니다.

세 방향 적중률을 동등하게 평균한 주지표는 기준선49.38%, 균형 부스팅51.89%(+2.51%p), 규모 보정 기준선46.20%, 규모 다수 기준선43.63%였다. 균형 부스팅 전체 정확도는50.42%다. 브랜드 단위 1,000회 재표집의 주지표 개선 95% 구간은 +0.70~+4.21%p였다. 이 구간은 사후 반복 실험에 따른 선택 불확실성을 포함하지 않는다.

사전 기준인3%p 개선에는 미달했다. 규모별 주지표도 네 구간 모두 과거 방향 기준선보다 낮았다. 실제 감소1,362건 중468건(34.36%)을 탐지해 감소 탐지의 약점이 남았다. 전체 개선만으로 규모 전반의 안정적 개선이나 서비스 적용을 주장하지 않는다.

결론: 소폭 개선은 있으나 서비스 채택 기준 미충족. 연구 결과로 보관하고 운영 앱·DB에는 반영하지 않았다. predictions.csv와 results.json 주지표 재계산, 중복·학습시점 검증 통과. 재현: scripts/evaluate_franchise_store_balanced.py.
