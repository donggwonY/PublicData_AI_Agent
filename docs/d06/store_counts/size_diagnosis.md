# 가맹점 수 예측: 규모별 오류 진단

2026-11-19. 저장된 2023~2024 평가 예측만 재집계했으며 모델 재학습은 하지 않았다. 구간은 마지막 공개 점포 수 기준 1~2, 3~5, 6~10, 11개 이상이다. 사후 탐색이므로 별도 독립 검증 결과가 아니다.

| 마지막 공개 점포 수 | 브랜드·연도 | 기준선 균형 정확도 | 회귀 균형 정확도 | 부스팅 균형 정확도 |
|---|---:|---:|---:|---:|
| 1~2개 | 1,709 | 44.17% | 40.95% | 38.89% |
| 3~5개 | 588 | 49.35% | 48.86% | 45.94% |
| 6~10개 | 361 | 50.39% | 40.76% | 38.63% |
| 11개 이상 | 466 | 50.60% | 41.28% | 43.78% |

균형 정확도는 증가·유지·감소 각각의 적중률 평균이다. 전체 표본에서는 회귀가 1.83%p 개선했지만 규모별로 나누면 모든 구간에서 기준선보다 낮았다. 전체 개선이 규모별로 고르게 나타난 것은 아니며, 규모마다 실제 방향의 구성과 예측 성향이 다르므로 집계 결과만으로 안정적인 개선을 주장하지 않는다. 이를 인과적 원인으로 확정하지 않는다.

1~2개 브랜드가 전체의 약55%다. 이 구간에서 실제 감소한 616건 중 회귀가 감소로 맞힌 비율은 16.23%였다. 목표연도 점포 수가 명시적으로 0인 459건도 포함되며, 자료 미존재를 0으로 만든 것은 아니다. 원본 0이 실제 점포 소멸을 정확히 반영하는지는 별도 원천 확인이 필요하다.

회귀의 실제 변화 폭별 전체 적중률은 변화 없음 70.24%(1,055건), 1개 변화 27.34%(1,035건), 2개 변화 42.34%(385건), 3~5개 변화 54.81%(405건), 6개 이상 변화 61.89%(244건)였다. 이 구간은 미래 실제 변화로 나눈 오류 설명용이며 예측 대상 선별이나 입력 변수로 사용하면 안 된다.

결론: 기존 모델의 서비스 적용 근거는 더 약해졌다. 소규모 브랜드를 임의 삭제하거나 1개 변화를 유지로 바꿔 성능을 높여 보이지 않는다. 다음 실험은 같은 증가·유지·감소 정의와 표본을 유지하면서 규모별 방향 비율을 쓰는 단순 기준선과 클래스 균형 학습을 비교하는 것이 우선이다. 설정은 개발 기간에서 선택하고 이미 평가한 기간을 재사용하는 후속 탐색임을 명시한다.
