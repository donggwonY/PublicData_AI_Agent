# 진입 후보 정제 결과

2026-11-20. 전년도 대구 다른 구군에 연결 활동이 있던 진입 후보1,108건을 점검함. 전년과 당해 브랜드 목록에 모두 존재하는4자 이상 고유 별칭을 사용하고, 목표연도 신규 인허가 중 연말 영업 기록과 대조함.

- 안정된 별칭이 상호 시작에 있고 신규 인허가도 있는 후보:1,044건.
- 안정된 별칭과 신규 인허가는 있으나 상호 중간에 포함된 경우:38건. 법인명·지역명이 앞에 붙은 정상 사례도 있을 수 있어 오류로 확정하지 않음.
- 전년·당해 공통 고유 별칭을 확보하지 못한 경우:26건. 이름 변경·목록 누락 등의 확인 필요함.
- 시작 일치1,044건 중 재진입 후보를 제외한 후보:1,000건.

1,000건은 2017년 이전 최초 진출까지 보장하지 않는 관측기간 내 후보임. 이번 작업은 기존 양성 후보만 점검했으므로 전체 브랜드 연결 정확도나 음성 정답 정확도를 검증한 것이 아님. 상호 시작 일치도 가맹 관계를 증명하지 않으며, 정칼국수처럼 흔한 이름과 긴 별도 브랜드가 겹칠 가능성은 추가 확인이 필요함.

26건·38건을 잘못된 기록으로 단정하거나 자동 음성으로 바꾸지 않음. 모델 평가에 사용하려면 모든 브랜드·구군·연도 후보에 동일 규칙을 적용해 정답을 다시 구성하고, 원래 표본과 차이를 보고해야 함. 이번 양성 후보 정제만으로 기존 점수가 개선됐다고 주장하지 않음. 다음은 동일 규칙의 전체 패널 적용 및 모호한 이름 표본 검토임.
