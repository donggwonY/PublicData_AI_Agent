# 대구 내 구·군 확장 후보 분석

2026-11-20. 3개 브랜드 점검에서 브랜드 범위를 확대해 구·군 새 진입 후보를 집계하고 첫 모델 비교를 완료함.

## 자료 구성

인허가286,896행과 공정위 과거 브랜드 목록을 사용함. 이름을 정규화한 후4자 미만 별칭4,175개, 서로 다른 관리번호가 공유하는 별칭506개를 제외함. 문자 포함 연결이므로 개인 가게와의 혼동·관련 브랜드명 부분 일치·누락은 여전히 수작업 검토가 필요함. 해당 연도의 브랜드 이름을 사용했으나 원자료의 신고 정정·수정 이력과 실제 공개일은 미확인임.

기존8개 구·군으로 고정했고 군위군은 편입 경계 문제로 이번 분석에서 제외함. 연결된 인허가19,798행·3,249브랜드, 연도별 패널3,106브랜드. 새 기록 출현 후보1,830건 중 전년도 대구 다른 구·군에서 활동이 관측된 후보1,108건. 이 중54건은 과거 활동 후 다시 등장한 재진입 후보임. 엄밀한 최초 진출로 모두 부르지 않음. 전년도 대구 합계가 공정위 가맹+직영 합계와 정확히 맞는 진입 후보는231건이며 정확 일치만으로 개별 매장 연결의 정확성이 입증되지는 않음.

인허가에서는 건물 단위 영업 기록을 집계하므로 공정위의 가맹점 수와 정의가 다름. 기록0은 연결된 인허가가 없다는 뜻이며 실제 점포가 없다는 확인이 아님. 예측 정답은 '연결된 영업 건물 기록이 없던 구·군에 다음 해 기록이 생김'으로 한정함.

## 첫 예측 비교

전년도에 대구 다른 구·군에서 연결 기록이 있고, 그 이전 연도의 자료가 있는 브랜드를 사용함. 입력은 과거 대구 전체 연결 건물 수·증감·진출 구군 수·업종·대상 구군. 목표연도 자료를 입력에 사용하지 않음. 각 평가연도보다 이전의 정답만 학습함. 개발2021~2022에서 구군 평균 기준선과 로지스틱 회귀를 선택한 후2023~2024를 평가하고2025는 잠정 결과로 분리함. 이번 목표의 첫 모델 비교지만 앞서 자료를 탐색한 회고적 실험임.

|연도|구군 후보 표본|새 기록 출현|기준선 AP|회귀 AP|기준선 AUC|회귀 AUC|
|---|---:|---:|---:|---:|---:|---:|
|2023|4,671|101|0.0292|0.0691|0.600|0.696|
|2024|5,044|134|0.0347|0.0815|0.594|0.734|
|2025 잠정|4,599|89|0.0257|0.0793|0.576|0.739|

AP는 가능성이 높은 후보를 앞에 놓는 성능으로 높을수록 좋으며 전체 정답률이 아님. 실제 새 기록은 약2~3%로 적어 단순 전체 정확도를 성과로 쓰지 않음. 회귀의 순위 구분은 구군 평균보다 세 연도 모두 나았음. 다만 이 점수만으로 특정 브랜드의 '어느 구군'을 잘 맞힌다고 판단할 수 없어 브랜드별 후보 순위를 별도 계산함(within_brand_ranking.csv). 이 순위 검토는 실제 진입한 브랜드이면서 선택 가능한 구군이2개 이상인 사례에 한정된 사후 설명임. 최고 확률 동률은 무작위 선택 기대 적중률로 처리함.

## 현재 판단

확장 후보를 구분하는 신호는 관측됐으므로 이름 연결과 구군 순위 검토를 진행할 근거가 있음. 실제 프랜차이즈 확장 예측으로 확정하려면 원천 이름 연결 표본 검토와 시점별 자료 가용성 확인이 필요함. 상담에서는 확장 가능성을 단정하거나 현재 출점 예정 정보로 표시하지 않음. 결과 파일은 과거 관측 검토용이며 앱 변경 없음.

세부 결과 experiment/results.json, protocol.json, selection.json, predictions.csv. 재현 scripts/screen_d06_expansion_all.py → scripts/evaluate_d06_expansion.py. 브랜드·연도·구군·모델 중복 없음 확인. 품질 점검 중간 파일은 entry_quality_*.csv/json에 보관함.

### 브랜드별 구군 순위 결과

실제 진입 기록이 생긴 브랜드 중 후보 구군2곳 이상인 사례에서 최고 순위 구군 적중은2023년84브랜드36.90%,2024년99브랜드45.45%,2025년잠정71브랜드53.52%로 기준선과 회귀가 모두 같았음. 현재 회귀는 브랜드와 구군의 상호작용 변수가 없으므로 브랜드마다 다른 지역 선호를 학습하기 어려움. 전체 후보 순위 개선을 '어느 구군으로 갈지' 개선으로 설명하면 안 됨. 다음 비교는 브랜드 특성과 지역 특성의 조합을 반영한 모델의 브랜드 내 순위를 확인하는 것임. 모델 확대에 앞서 이름 연결의 정확도도 병행 확인해야 함.

### 부스팅의 브랜드별 지역 순위 비교 — 2026-11-20

새 학습 없이 저장된 부스팅 예측도 같은 브랜드·후보 구군에서 비교함.2023년 단순 구군 기준36.90%·부스팅39.29%,2024년45.45%·45.96%,2025년잠정53.52%·52.11%.2023의 개선은84브랜드에서 정답2개가 늘어난 수준이고2024 차이도 작으며2025는 악화함. 따라서 브랜드와 구군의 조합을 반영할 수 있는 부스팅도 일관된 지역 선택 개선을 확인하지 못함.

2021~2022 개발 기간의 브랜드 내 순위로 모델을 선택해도 회귀가 선택됨(회귀47.87%,부스팅46.63%,구군 기준46.81%). 평가연도 결과를 보고 부스팅으로 교체하지 않음. 이 선택은 저장 결과를 이용한 사후 진단이며 독립 사전 검증으로 설명하지 않음.

정답은 실제 진입한 브랜드이면서 후보구군2개 이상인 조건부 표본임. 특정 브랜드가 실제로 확장할 확률이나 모든 브랜드 대상 정확도와 다름. 이름 연결 오류와 관측 누락에 따라 이 순위 결과도 달라질 수 있음. 다음 우선순위는 모델 수 확대보다 연결된 상호 표본 점검과 업종별 지역 점포 구성·과거 개업 흐름 등 당시 지역 정보를 붙일 수 있는지 확인하는 것임. 기존 계산만 재사용해 추가 학습하지 않았음.
