# 구군 진입 후보 이름·날짜 표본 점검

2026-11-20. 미리 고정된 무작위 표본30건(seed20261120)을 사용함. 기존 신규 후보 중 전년도 대구 다른 구군에 연결 활동이 있는 사례에서 뽑은 표본이며 전체 상호 연결의 정확도 추정 표본은 아님.

## 점검 결과

30건 모두 해당 연도 목록의 별칭으로 영업 인허가를 재검색할 수 있었음.28건은 검색된 영업 기록이 전부 해당 연도 신규 인허가였고,2건은 이전 연도 인허가가 포함됐음. 이것은 해당 상호가 실제 동일 가맹 브랜드라는 검증과 다름. 이번 재검색은 개별 브랜드 별칭 포함으로 수행해 최초 전체 브랜드 매칭의 경쟁·겹침 처리와도 다름. 결과 차이에는 최초 매칭 규칙의 영향이 포함될 수 있음.

- 리 에스테틱: 리에스테틱뷰티연구소뿐 아니라 몰리올리에스테틱도 포함됨. 문자열 일부가 같아 생기는 잘못된 연결 가능성이 있으며, 기존 기록이 있었는데 새 기록으로 보이는 이유는 전체 별칭의 겹침 처리도 확인해야 함.
- 정칼국수: 동래정칼국수가 포함됨. 별도 브랜드의 이름 일부를 잡았을 가능성이 있어 확인 필요함.
- 르뽀미에: 쁘띠르뽀미에 케이스마트점이 포함됨. 관련 브랜드인지 다른 브랜드인지 원천 검수 필요함.
- 찐이야숯불두마리치킨: 표본의2024년 달서구 진입 후보에서 검색된3개 영업 기록은 모두 이전 연도 인허가였음. 당해·전년 별칭이 달라 실제 신규 진출 대신 이름 연결 범위 변화가 정답에 반영됐을 가능성이 있음.

따라서28/30을 브랜드 연결 정확도93.3%라고 표시하면 안 됨. 실제 신규 인허가 날짜가 맞더라도 브랜드 소속은 확인되지 않았음. 진입 후보의 증가 일부가 이름 연결 규칙에서 생길 수 있어 지금까지의 확장 예측은 임시 관측 정답에 대한 탐색 성능으로 유지함. 기존 D-06 감소 예측은 공정위 가맹점 수로 정답을 만든 별도 실험이므로 이번 이름 연결 문제의 동일한 정답 오류로 취급하지 않음.

## 다음 정리 기준

1. 같은 브랜드에서 전년에도 사용 가능한 별칭으로 연결되는 신규 인허가만 별도 집계해 이름 변경 효과를 구분함.
2. 다른 브랜드명의 일부로 겹치는 별칭과 흔한 상호는 자동 확정하지 않고 검수 대상으로 표시함. 문자열4자 이상 조건만으로 충분하지 않았음.
3. 실제 신규 인허가가 없는 연도별0→양수 전환은 신규 출점 정답과 분리함. 재진입도 최초 진출과 구분함.
4. 정제 후 동일한 연도·브랜드 범위에서 기준선과 모델을 다시 비교해야 하며 정답을 바꾸고 이전 점수와 직접 비교하지 않음.
