# 지역 업종 구성·개폐업 흐름 추가 비교

2026-11-20. 기존 확장 후보 표본을 유지하고 예측 직전 회계연도 말까지의 인허가만으로 지역 변수를 생성함. 현재 영업 상태 대신 인허가일·폐업일로 과거 활동을 복원함. 당시 자료가 실제 공개돼 있었는지와 사후 정정 이력은 미확인임.

추가 변수는 구군 전체 영업 기록 규모·증감, 전년도 개업·폐업 비율, 일반음식점·휴게음식점·미용업·담배소매업·제과점영업의 구성 비중과 개업 비율임. 인허가 대상 업종의 구성으로 상권 전체 점포 구성은 아님. 업종과 구군 조합 범주도 추가함. 브랜드 이름 연결과 구군 관측0의 한계는 앞선 실험과 동일함.

개발2021~2022에서 브랜드·연도별 1순위 지역 적중으로 추가변수 회귀/부스팅을 비교함. 부스팅45.21%,회귀39.36%로 부스팅을 선택함. 개발 표본은 실제 진입한 브랜드·연도 중 후보구군2개 이상188건임. 평가2023~2024,잠정2025를 구분함. 앞서 결과를 본 연도를 재사용한 탐색 비교임.

실제 새 기록이 생긴 브랜드에서 최고 순위 구군을 맞힌 비율임. 모든 브랜드의 진입 예측 정확도가 아님. 동률은 동률 후보 중 정답 비중으로 계산함. 지역 변수 추가는2024년 크게 악화했고2025년 소폭 개선으로 일관되지 않음. 전체 후보 AP도2023년0.06689,2024년0.07205,2025년0.09579로 기존 부스팅 대비 효과가 일정하지 않았음.

현재 판단: 이번 지역 변수 묶음으로 브랜드별 확장 지역 예측을 안정적으로 개선하지 못함. 기존 감소 예측 결과와는 별도임. 확장 후보 기록 자체는 확인됐으므로 다음 우선 확인은 표본 이름 연결의 정확도와 가맹점/건물 기록 차이임. 모델 설정을 계속 늘리기보다 정답 품질을 먼저 점검할 근거가 생김.
