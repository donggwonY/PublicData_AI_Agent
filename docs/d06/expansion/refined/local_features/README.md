# 정제 자료의 지역 변수 추가 비교

2026-11-20. 정제 패널의 같은 표본에 과거 구군 업종 구성·개업/폐업 흐름과 업종×구군 범주를 추가함. 변수 생성과 모델 설정은 앞선 지역 변수 실험과 동일함.2021~2022 개발의 브랜드·연도별1순위 적중에서 부스팅51.67%,회귀45.83%로 부스팅 선택. 해당 개발 표본120브랜드·연도임.2023~2024평가,2025잠정 평가로 분리함. 이미 본 기간과 정제 규칙을 재사용한 탐색 결과임.

후보구군2개 이상이며 실제 신규 기록이 생긴 브랜드의1순위 구군 적중임. 지역 변수 부스팅은 단순 구군 평균 대비2023년 약1건,2024년 동률 기대점수0.5건만큼의 차이,2025년 동일함. 확실한 활용 개선으로 단정하기 어려움. 기본 회귀 대비2023악화,2024미세 개선,2025동일로 일관된 개선이 아님. 전체 후보 AP도 기본 회귀보다2024·2025낮았음.

부가적으로 상위2개 구군을 보여주는 경우도 top_two_ranking.csv에 집계함. 정답이 하나 이상 포함될 확률이며 동률은 무작위 선택의 기대값으로 계산함.1개보다2개를 제시하면 적중은 자연스럽게 올라가므로 단순 기준선의 동일한2개 제시와 비교해야 함. 후보가2개뿐인 사례는 자동으로 맞는 구조이므로 수치를 전체 실무 정확도로 해석하지 않음. 이 진단으로 모델을 다시 선택하지 않음.

현재 결론: 기록상 신규 진입 후보를 구분하는 신호는 있으나, 특정 브랜드의 다음 구군을 단순 지역 순위보다 안정적으로 잘 고르는 근거는 아직 작음. 자료 정제와 지역 변수 추가까지 수행한 현 범위에서 점수 개선 실험을 반복할 우선순위는 낮아짐. 구군별 과거 확장 이력은 상담 자료로 활용 검토할 수 있고, 미래 지역 예측은 별도 후보로 유지함. 기존 가맹점 감소 모델의 활용과는 별개임.

모호한 브랜드 이름·군위군 제외·가맹/직영/인허가 건물 단위 차이·실제 공개일·사후 정정의 한계 유지. 현재 자료에서 연도별 관측0은 실제 부재가 아님. 앱·운영 DB 변경 없음.
