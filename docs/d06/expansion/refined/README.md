# 이름·진입 규칙 정제 후 첫 비교

2026-11-20. 전체 패널에 전년과 당해 모두 존재하는4자 이상 고유 브랜드명, 정규화 상호 시작 일치 규칙을 적용함. 구군의0→양수 활동 전환과 해당 연도 신규 인허가가 모두 있는 경우를 진입 후보로 정의함. 동일 브랜드의 이름 연결이 불가능한 연도는 행을 제외해 미확인을0개로 바꾸지 않음. 해당 연도에 처음 등장한 이름은 이 범위에서 다루지 않음.

기존 패널 범위에서90,528개 브랜드·구군·연도 기록을 구성함. 과거 대구 다른 구군 활동이 있던 후보 중 진입779건이며, 모델에는 추가로2개 과거연도 기록이 필요해 표본이 달라짐. 이전 자료의 점수와 직접 비교해 정제 효과라고 주장하지 않음. 이번 정제 기준은 사후 탐색에서 결정됐으며 독립 최종 검증이 아님.

|평가연도|후보 표본|진입 후보|구군 평균 AP|개발 선택 회귀 AP|회귀 AUC|
|---|---:|---:|---:|---:|---:|

AP는 가능성이 높은 후보를 앞에 놓는 성능이며 전체 정답률이 아님.

과거2021~2022 개발AP로 구군 평균 기준선·회귀를 선택한 후2023~2024 평가,2025 잠정 평가로 구분함. 구군별 새 기록 출현 후보의 순위 구분은 평균 기준보다 나았음. 다만 회귀의2023 확률 오차는 기준선보다 나빴고, 순위 개선을 정확한 개별 확률 개선으로 해석하지 않음.

브랜드 안에서 어느 구군인지 맞힌 성능은 experiment/within_brand_ranking.csv에 별도 기록함. 전체 후보의 구분 성능과 구군 선택 성능을 구분함. 이름 시작 일치만으로 가맹 관계가 증명되지 않고, 연결되지 않은 기록의 실제 소속도 미확인임. 군위군은 고정 경계 분석에서 제외, 재진입은 여전히 별도 분리가 필요함. 실제 과거 공개 시점·사후 수정의 한계 유지.

전국 브랜드 간 공유 별칭을 이용해 고유성을 확인한 부분은 전체기간 목록으로 계산한 보수적 제외 기준이므로 당시 사전만으로 구축한 배포 재현이 아님. 현재 연구용 정제 규칙이며 실시간 제공 가능성을 확정하지 않음. previous_count_agrees 필드는 이번 재구성에서 미대조 상태로False를 채운 호환 필드이므로 공식자료 불일치 판정에 사용하지 않음.
