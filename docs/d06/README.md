# D-06 대구 프랜차이즈 브랜드별 연간 매출 예측

최신 상태(2026-11-19): 자료 수집·첫 예측·추가 모델 비교 완료. 기준선 대비 안정적 개선은 미확인, 서비스 미반영. [최신 실험 결과](RESULTS.md)를 우선 참조한다.

연구 질문: 대구의 같은 업종 프랜차이즈 브랜드를 비교할 때, 공개된 과거 자료로 다음 연도 브랜드 평균 매출을 얼마나 예측할 수 있는가? 개별 신규 점포의 매출이나 수익을 예측하는 연구는 아니다.

이하 11월 18일 접근 점검과 수집 과정은 당시 기록이다.

공식 지역별 매출 API: https://www.data.go.kr/data/15125494/openapi.do . 기준년도와 브랜드 관리번호로 지역별 가맹점수·연간평균매출·단위면적당 연간평균매출을 조회한다고 명시. 브랜드번호는 선택 입력이다. 원본 명세는 api_schema.json. 공개 설명만으로 실제 대구 행·과거 연도 범위·연속 브랜드 수가 확보됐다고 판단하지 않는다.

실제 요청: 기준년도2023, 1페이지10행. 응답 HTTP403, SERVICE_KEY_IS_NOT_REGISTERED_ERROR, 이유코드30(등록되지 않은 서비스키). 인증키와 요청 URL의 키 값은 기록하지 않는다. 현재 프로젝트 공공데이터 키가 해당 서비스에서 인식되지 않았다. 활용신청 미승인인지 키 폐기/변경/등록 지연인지는 확정하지 않는다. 해당 API 활용신청과 유효한 키 확인이 필요하다. 자동으로 인증을 우회하지 않는다.

자료 확보 후 첫 점검: 지역명 대구 실제 행, 가맹사업 기준연도와 회계연도 차이, 매출 단위와 범위값 여부, 소규모 비공개·0값 의미, 동일 브랜드 연도 연결 및 등록취소 브랜드 누락. 가명/합성 자료는 실제 브랜드 예측의 정답으로 사용하지 않는다. 대구 자료로 평가하고 전국평균을 대구 정답으로 대체하지 않는다.

질문 후보는 대구에서 가맹 창업을 고려할 때 같은 업종 브랜드의 다음 연도 평균매출과 변동을 비교하는 것이다. 브랜드 평균은 신규 개별 점포의 예상매출·이익·투자수익이 아니다. 동일 브랜드의 관측 점포 구성이 바뀌면 평균 변화 해석이 달라진다. 충분한 과거 자료가 확보되면 직전 값·과거 평균과 시간순으로 검증하고, 자료 확보 전 서비스 적용 일정이나 예측 성능을 확약하지 않는다.

## 승인 후 전체 수집 완료 — 2026-11-18

인증 승인 후 같은 로컬 키로 HTTP200/resultCode00 확인. 앞의 인증 실패는 해결됐다. 기준년도2017~2026의 전체 페이지를 10,000행 단위로 수집했고 각 연도 수신 행수와 API totalCount가 일치했다. 모든 페이지 원본 SHA256은 acquisition_manifest.json에 기록. 대구90,613행, 브랜드·지역·기준연도·회계연도 키 중복0. 실제 회계연도는 모두 기준년도보다1년 이전(2016~2025).

양수 매출 범위를 읽을 수 있는 기록4,563행·1,137브랜드. 5개 회계연도 이상 유효값이 있는 브랜드405개(반드시 연속5년이라는 뜻 아님), 10년 모두91개. 전체23,516브랜드에는 대구 가맹점0/매출미공개 등도 포함되므로 대구 영업브랜드 수로 설명하지 않는다. 세부 연도별 가용성은 availability.json·availability_by_year.csv.

원본 API는 매출금액 범위(편차5%)를 제공한다. 중간값은 비교용 대체값이지 실제 정확매출이 아니다. 0·빈값·기타 비공개 표시를 실매출0으로 보간하지 않는다. 현재 저장된 유효성은 양수 하한~상한 문자열 기준이며, 범위 외 표기의 해석은 별도 점검한다. 금액 단위가 공식적으로 확인되기 전 원 단위로 표시하지 않는다.

분석 가능성: 여러 해에 걸친 대구 브랜드 자료는 확보됐다. 다음은 연속 관측 가능 브랜드, 업종분류 변경, 실제 공개일과 정보 이용 지연을 점검하고 직전 관측값 대비 예측을 비교하는 것이다. 현재 모델 학습·성능 개선·서비스 적용은 미실시. 최신2025자료의 등록 완결성도 아직 보장하지 않는다.

수집 재현: collect_franchise_probe.py → collect_franchise_full.py → audit_franchise_daegu.py. 원본은 data/raw/franchise에 로컬 보관, 운영DB 적재 없음.

## 예측 및 후속 비교 완료 — 2026-11-19

앞선 미실시 상태를 갱신한다. 첫 예측 실험, 급변 원본 대조, 강건한 방법 3개 추가 비교, 단순 예상의 범위·브랜드 순서 진단을 완료했다. 현재 기준선 대비 안정적인 모델 개선은 없으며 운영 서비스에는 반영하지 않았다. 최신 결론은 [RESULTS.md](RESULTS.md), 세부 결과는 experiment 및 robust 폴더를 참조한다.
