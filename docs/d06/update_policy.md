# D-06 데이터와 모델 갱신 기준

확인일:2026-11-21.

## 공식 데이터 제공 주기

공공데이터포털의 브랜드 목록15125467,브랜드별 가맹점 현황15110241,지역 가맹/직영15125490은 업데이트 주기를 모두 **실시간**으로 표시함. 이 표기를 모델을 매 요청마다 재학습한다는 뜻이나 매장 현황이 즉시 신고·반영된다는 뜻으로 해석하지 않음.

## 연간 통계와 구분

모델의 관측 단위는브랜드×회계연도임. 지역 API의2026기준년도는 실제2025회계연도 수치임. 따라서 '연간 통계를 사용하는 모델'은 맞지만'공식 API 갱신주기1년'은 아님. 정확한 새 연도 자료의 공개일·완결 시점은 이번 확인으로 확정하지 않음.

## 서비스 갱신 운영안

- 원천:새 기준년도 자료 공개 또는 기존자료의수정 여부를 확인한 때 재수집함. 현재 자동 점검 일정은 설정되지 않음.
- 검증:원본·행수·해시·브랜드/연도키·회계연도·결측·최신연도 가용성을 대조함. 최신연도 행이 일부 나왔다고 완결 자료로 단정하지 않음.
- 재계산:새 회계연도 자료가 충분히 확보되면 동일 정의로 재학습·전망을 갱신함. 같은 연도의 유의미한 수정도 재검증 후 재계산 후보가 됨. 계산 결과 파일의입력버전·생성일·대상기간을 함께 바꿈.
- 연결:점수표와 설명의 기간·모델버전을 함께 갱신함. 대화마다 학습하지 않고 저장된 결과를 조회함. 운영 전환 시점은앱 담당자와 조율함.

이는 자동 스케줄 배포 완료를 뜻하지 않음. 정리하면'연도별 자료가 새로 나오면 갱신하고,중간 수정이 있으면 추가 갱신을 검토하는 방식'임. 달력 기준매년특정일이나API조회주기1년으로 확정하지 않음.

현재 전달 데이터는2026년말 전망이고 생성일은2026-11-20임.2027년말 전망이 필요하면 최신입력의 가용성과예측 간격을 맞춘 별도평가가 필요하며 연도표시만 바꾸지 않음.
