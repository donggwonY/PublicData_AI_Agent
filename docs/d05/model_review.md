# D-05 입점 층수 비중 예측: 첫 비교 결과

2026-11-17 · 탐색적 시간순 평가 · 운영 적용 없음

## 결론
현재 입력과 설정에서는 로지스틱 회귀·부스팅이 직전 3년의 입점 비중보다 안정적으로 우수하지 않았다. 예측 모델 채택 기준 미충족이다. 과거 입점 분포는 기술통계로 활용할 수 있으나 성공 가능성이나 상층 창업 적합성을 입증하지 않는다. 모든 가능한 모델이 불가능하다는 결론은 아니다.

## 자료와 평가
공유 DB app.stores v6에서 2010~2025년 신규 대표 인허가(단기 행사 제외)를 읽었다. 복수 층·도로명/지번 층 불일치 후보를 제외한 층수 확인 기록으로 구×원천업종×연도 패널을 만들었다. 입력 파일 해시는 model_results.json에 기록했다.

목표 연도 직전 3년의 층수 확인 기록이 60건 이상이고 확인율이 80% 이상인 구·업종만 그 시점에 선정했다. 2015년부터 전년도까지 학습하여 2020~2025년을 각각 예측했다. 동일 160개 구·업종·연도 칸, 층수 확인 24,346건을 다섯 방법으로 비교했다. 이는 전체 상권이나 모든 업종에 대한 결과가 아니다. 지역·업종 조합은 37개다. 평가 대상에 포함된 실제 표본이 작은 칸도 제외하지 않았다.

## 전체 결과
MAE는 예측 비중과 실제 비중의 평균 절대 차이이며 단위는 퍼센트포인트다. 정확도 백분율로 환산하지 않는다.

|방법|칸별 동일 가중 MAE (%p)|건수 가중 MAE (%p)|
|---|---:|---:|
|직전 연도 비중|4.88|3.61|
|직전 3년 합산 비중|4.48|3.29|
|대구 같은 업종 비중으로 보정|4.48|3.32|
|로지스틱 회귀|5.49|3.89|
|부스팅|6.20|3.93|

## 연도별 동일 가중 오차
|연도|직전 3년|회귀|부스팅|
|---|---:|---:|---:|
|2020|6.45|9.92|8.44|
|2021|5.23|6.48|6.66|
|2022|4.13|4.44|6.84|
|2023|4.89|5.78|5.88|
|2024|2.99|2.87|5.44|
|2025|3.57|4.24|4.48|

회귀가 직전 3년 기준보다 오차가 작은 해는 2024년 한 번이다. 부스팅은 6개 연도 모두 더 컸다. 대구 업종 비중으로 보정한 방법도 전체 오차는 거의 같아 뚜렷한 개선을 보이지 않았다.

## 불확실성과 오류 확인
구·업종 묶음 단위 2,000회 재표집에서 회귀−직전3년 MAE 차이는 +1.01%p(95% 구간 +0.52~+1.56), 부스팅은 +1.73%p(+0.25~+4.05)였다. 양수는 모델 오차가 더 큼을 뜻한다. 같은 연도의 공동 충격을 완전히 반영한 구간은 아니므로 일반적인 미래 성능 보장으로 사용하지 않는다.

과거 자료만으로 표본을 고르는 조건과 직전3년 비중을 원패널에서 다시 계산해 일치를 확인했다. 다섯 방법의 평가 칸, 예측값 범위, 저장된 MAE도 대조했다. 모델 설정은 결과 확인 전에 model_protocol.json으로 고정했으며 이번 결과에 맞춰 재조정하지 않았다.

## 해석과 한계
- 초기 학습 칸은 63개, 마지막 평가의 학습 칸도 194개로 모델 학습 자료가 제한적이다. 인허가 수가 많아도 독립적인 구·업종·연도 사례 수가 많은 것은 아니다.
- 표본이 작은 평가 칸의 오차가 크다. 청소년게임제공업 1개 칸은 층수 확인 8건, 기준선 오차 60.36%p다. 결과를 보고 해당 칸을 삭제하지 않았고 건수 가중 결과도 함께 보고했다.
- 일반음식점 42칸의 직전3년 오차는 2.24%p, 휴게음식점 31칸 3.95%p, 미용업 40칸 4.55%p. 사후 업종별 진단이며 서비스 대상 선정 기준으로 확정하지 않는다.
- 층수 미상은 정답에서 빠진다. 알려진 주소만의 입점 경향을 전체 점포의 경향으로 확장할 수 없다. 복수 층 탐지는 정규표현식 기반이며 모든 주소 오류를 보장해서 검출하지 않는다.
- 현재 주소가 개업 당시 주소인지 검증되지 않았다. 원천업종이 넓어 카페·네일 등 세부 업태와 구별된다.
- 과거 집계를 이미 확인한 탐색이며 독립 최종시험이라고 주장하지 않는다.
