# 세부 업종 구분 추가 비교 — 2026-11-18

D-03 집단 예측 확장 후보의 마지막 자료 구분 점검. 개인 점포 확률·지역 추천·AI 개선으로 해석하지 않는다.

2020~2024년 동일 496개 구군×세부업종×개업연도 집단을 비교했다. 예측연도 y에서 y-4~y-2까지 관측완료된 개업집단 합계가 60건 이상인 경우만 사용했다. 통닭(치킨)→호프/통닭, 까페→커피숍 두 별칭만 합쳤다. 기타 분류 이동은 검증하지 않았다. 미래 개업 수는 입력에 사용하지 않았다.

| 방법 | 평균오차(%p) | 개업 수 가중오차(%p) | 지역쌍 순서 적중 |
|---|---:|---:|---:|
| 넓은 인허가 업종의 과거 비율 |5.5323|4.2794|54.62%|
| 세부 업종의 과거 비율 |5.4864|4.2685|57.19%|
| 세부 업종 + 대구 같은 업종 30건 보정 |5.3746|4.1646|57.36%|

세부 보정은 5개 연도 중 4개에서 평균오차가 낮았으나 2020년에는 악화했다. 구군×세부업종 묶음 재추출 2,000회 개선 차이 구간은 -0.404~+0.063%p로 0을 포함한다. 순서 평가는 같은 연도·세부업종 내 구군쌍 중 실제 동률을 뺀 1,168쌍이고 예측 동률은 0.5점이다. 반복 지역쌍을 독립 표본으로 해석하지 않는다. 이전 303개 넓은 업종 집단과 목표·표본이 달라 점수를 직접 비교하지 않는다.

결론: 업종 구분만으로 서비스에 사용할 만한 안정적 개선을 확인하지 못했다. 이 확장 후보의 모델/분류 조합을 계속 늘릴 근거가 부족하다. 원본 스냅샷의 사후 정정·등록 지연·비점포 세부업태 혼재 제한도 유지한다. 앱·DB 변경 및 서비스 채택 없음. 연구 기록은 보존한다.
