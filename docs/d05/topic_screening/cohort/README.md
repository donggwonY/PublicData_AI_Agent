# 신규 개업 집단의 1년 이내 폐업 신고 비율 — 첫 탐색

기존 D-03의 집단 단위 확장 후보다. 독립된 신규 연구로 확정하지 않았다. 개인 가게의 폐업 확률, 전체 영업점의 폐업 건수, 실제 사업 실패를 예측한 결과가 아니다. 서비스 적용 없음.

## 질문과 비교
지역·업종별 다음 개업연도 집단에서 첫 365일 이내 폐업 신고 비율을 예측한다. 2020~2024년 303개 지역×업종×연도를 평가했다. 실제 미래 개업 수를 입력으로 사용하지 않는다. 평가 가중 지표만 해당 연도 개업 수로 가중한다. 2025년 전체 개업 집단은 1년 관측이 끝나지 않아 제외했다.

예측연도 y에서 y-4~y-2의 개업 집단을 사용한다. 직전 연도 집단은 1년 결과가 모두 관측되지 않아 쓰지 않는다. 과거 3개 집단 합계 60건 이상인 지역·업종만 평가했다. 회귀 학습도 개업연도 y-2까지만 사용한다. 날짜 역전, 겸업 중복, 단기 행사 제외. 현재 스냅샷이므로 신고 지연·사후 정정·과거 업종 정의 한계는 남는다.

| 방법 | 지역·업종 집단을 동일하게 본 평균오차(%p) | 개업 수 가중 오차(%p) |
|---|---:|---:|
| 과거 3개 관측완료 개업집단 비율 |4.9844|3.3727|
| 같은 업종 대구 비율을 30건만큼 섞음 |4.8754|3.3192|
| 릿지 회귀(alpha=100) |5.0312|3.2842|

업종 정보를 섞는 고정 방식은 5개 연도 모두 평균오차가 낮지만 전체 개선은 약 0.109%p로 작다. 회귀의 가중 지표 개선만 골라 우수하다고 판단하지 않는다. 독립 기준선 재계산 및 구군×업종 묶음 부트스트랩은 checks.json에 있다. 예측값과 정답은 predictions.csv, 연도별 지표는 annual.csv.

이전 연구에서 이미 본 기간을 재사용한 탐색이다. 새로운 최종평가가 아니며 비교 두 지표 간 결론 차이, 작은 집단 오차, 업종별 데이터 일괄 등록과 변경을 추가 확인해야 한다. 전체 연도·업종에 동일한 오차가 보장되지 않는다. 연구 주제 중복은 D-03의 확장으로 명시하고 E-06의 전체 폐업 건수 목표와 구분한다. 이 결과만으로 지역 추천·신규점포 성공을 주장하지 않는다.
