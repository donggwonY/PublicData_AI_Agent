# D-05 세부 업종 분리 비교

2026-11-17 · 탐색 비교 · 서비스 채택 전

## 결론
같은 세부 업종의 신규 상층 입점 비중을 예측할 때 넓은 원천업종 평균보다 세부 업종별 과거 비중이 더 정확했다. 이는 업종 구분의 효과이며 복잡한 AI 모델의 우수성이 아니다.

## 자료 및 공정 비교
공유 DB app.stores v6의 2010~2025 기록을 연도별 읽기 전용 조회했다. 이전 분석과 연도·구·원천업종별 전체/층수확인/상층 건수가 동일함을 확인했다. 복수층·주소 불일치 제외 규칙을 유지했다. 통닭(치킨)→호프/통닭, 까페→커피숍만 기존 분류 연결 방식으로 합쳤다.

각 목표 연도 이전 3년의 세부 업종 층수확인 기록 30건 이상·확인율 80% 이상 및 기존 상위 업종 선정 조건으로 대상을 정했다. 2020~2025년 동일 479개 구·세부업종·연도 칸, 층수 확인 21,679건을 세 방법으로 비교했다. 목표 연도의 실제값으로 선정하지 않았다.

|방법|칸별 평균 오차(%p)|건수 가중 오차(%p)|
|---|---:|---:|
|큰 업종의 과거3년 비중|8.04|5.92|
|세부 업종의 과거3년 비중|6.73|4.79|
|세부 업종 비중을 큰 업종 평균으로 일부 보정|6.63|4.71|

세부 업종 분리는 약 16.3%, 보정 포함은 약 17.6% 오차 감소다. 두 방법 모두 6개 연도에서 큰 업종 기준보다 개선됐다. 보정은 고정 강도 30을 사용했고 시험 결과로 조정하지 않았다. 보정 자체가 세부 업종 기준보다 확실히 좋다고 검증한 결과는 아니다.

구·원천업종·세부업종 단위 2,000회 재표집 95% 차이 구간: 세부 비중−큰 업종은 −2.02~−0.65%p, 보정−큰 업종은 −2.02~−0.84%p. 다중 비교 보정이나 공통 연도 충격을 완전히 반영하지 않았으며 독립 최종시험은 아니다.

## 주의
- 이전 4.48%p 결과는 큰 업종 자체를 맞히는 평가였다. 이번 8.04/6.63%p는 세부 업종 자체를 맞히므로 서로 직접 비교할 수 없다.
- 현재 업태·주소가 개업 당시와 같은지 확인되지 않았다. 층수 확인 기록에 한정되며 미상은 여전히 대표성 한계다.
- 입점 비중은 매출·성공·입지 적합성을 의미하지 않는다. 이 결과만으로 2층 창업을 추천하지 않는다.
- 처음 결과 이후 정한 탐색 비교다. 모델 성능 확정이나 자동 서비스 적용으로 해석하지 않는다.
