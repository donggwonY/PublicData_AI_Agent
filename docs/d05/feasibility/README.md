# 신규 인허가의 입점 층수 예측: 자료 가용성 점검

2026-11-16 · 김세은 · 자료 점검 완료, 모델 실험 전.

## 질문과 판단
지역·업종별 다음 해 신규 인허가 중 지상 2층 이상에 등록되는 비중을 예측할 수 있는지 검토한다. 입점 장소 탐색의 참고 자료이며 성공 가능성·매출·임대료·입지 적합성을 예측하지 않는다. 현재는 자료가 있어 소규모 실험은 가능하다는 판단이며, 상담 활용 가치나 예측 개선이 입증된 것은 아니다.

## 출처와 정제
공유 DB app.stores v6, 기준일 2026-11-06을 app_reader로 읽기 전용 조회했다. 원본 286,896건 중 is_primary=true, short_event=false, 유효 개업일 조건 후 254,967건. 현재 영업 여부로 표본을 제한하지 않았다. 층수는 주소에서 추출한 floor 원값을 사용하며 자리 키의 추정 층수를 사용하지 않는다. 누락을 1층으로 보정하지 않는다. 2026년은 미완료 연도이므로 완결 연도 검토에서 제외한다.

전체 기간 층수 확인 101,713건, 미상 153,254건. 확인된 값은 지하 7,838건, 1층 71,075건, 지상 2층 이상 22,800건이다. 오래된 자료의 층수 누락이 커 전체 기간을 그대로 합친 비율은 대표성이 부족하다.

## 기존 연구와 구분
A-05는 다음 분기 점심·저녁 카드매출 비중, E-06은 개업·폐업 건수 변화, E-05는 재입점 기간을 다룬다. E-05에서 층수는 입력 변수로 이미 사용했으나 입점 층수 비중 자체가 예측 목표는 아니다. E-06의 ‘1층/2층 모델’은 구/동의 계층을 뜻한다. 확인한 계획 문서에서는 동일 목표를 찾지 못했으며 문서 밖의 팀 계획까지 확인한 것은 아니다.

## 다음 실험 전에 확인할 사항
1. 주소의 복수 층·층 범위와 도로명/지번의 불일치를 점검한다. 현재 추출기는 먼저 발견한 층만 사용하므로 다층 점포를 단일 층으로 오분류할 수 있다.
2. 최신 주소가 개업 당시 주소·층이라는 보장은 없다. 역사적 스냅샷 미확보 시 회고적 연구로 한정한다.
3. 층수 미상 가게가 모두 상층/모두 비상층인 두 경우의 범위를 함께 산출해 누락에 따른 결론 변화를 확인한다.
4. 과거 비중을 그대로 사용하는 방법과 단순 회귀를 먼저 비교한다. 평가 기준은 비중 오차(퍼센트포인트)와 연도별 개선이다. 층수 예측만으로 매장 추천을 하지 않는다.
