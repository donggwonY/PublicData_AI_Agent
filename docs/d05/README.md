# D-05 지역·업종별 신규 입점 층수 비중 예측

담당 김세은 · 2026-11-16 시작 · 진행: 자료 검증.

## 연구 질문
지역과 업종에 따라 다음 해 신규 인허가 중 지상 2층 이상에 입점하는 비중을 예측할 수 있는가?

상담에서는 사용자가 매장 위치를 찾을 때 다른 점포의 입점 층 분포와 예상 변화를 참고할 수 있다. 상층 입점 비중은 매출·수익·생존·입지 적합성의 척도가 아니므로 ‘2층 창업 추천’으로 연결하지 않는다. 예측이 과거 통계보다 도움이 되는지 검증한 뒤 서비스 반영을 판단한다.

## 범위와 데이터
공유 DB app.stores v6의 개업일·업종·지역·주소·층수를 사용한다. 겸업 대표 기록만 유지하고 단기 행사 기록을 제외한다. 층수 미상을 1층으로 간주하거나 현재 영업 중인 점포만 남기지 않는다. 층수 추정은 건물의 미래 입점 기록을 사용하지 않는다. 2026년은 미완결 연도다. 과거 주소가 개업 당시 상태인지 확인되지 않았으므로 초기 결과는 회고적 분석으로 한정한다.

D-03의 생존·폐업 예측과 분리한다. E-05의 재입점 기간 및 E-06의 개폐업 건수, A-05의 시간대 매출 비중과 예측 대상이 다르다. 층수는 E-05에서 이미 입력 변수로 사용했으며, 층수 정보를 사용한다는 사실 자체를 연구 차별점으로 주장하지 않는다.

## 진행 결과
- [자료 가용성 점검](feasibility/README.md): 완료. 원본 286,896건, 정제 254,967건. 최근 주요 업종의 층수 확인율 약 86~91%.
- 주소 품질·누락 민감도: [결과 JSON](address_quality.json), [연도별 집계](address_quality_annual.csv), [업종별 집계](address_quality_services.csv). 복수 층·도로명/지번 불일치는 자동 탐지 후보이며 확정 오류가 아니다.
- 2020~2025년 43,703건 중 복수 층 후보 275건, 주소 간 층 불일치 15건(중복 제거 합계 284건). 이 후보를 제외한 층수 확인 기록은 34,128건이다. 자동 탐지는 완전한 주소 해석이 아니며 번지 뒤 쉼표와 층수 구분을 점검했다.
- 모델 학습 및 공개 앱 연결: 미수행.

## 비교 실험 계획
1. 예측 대상은 층수를 확인할 수 있는 신규 인허가의 상층 입점 비중이다. 미상 비율과 전체 기록에 대한 최저·최고 가능 비중을 함께 제시해 선택 편향을 드러낸다.
2. 구×업종부터 시작한다. 표본 선정·묶음·최소 건수는 각 학습 시점의 자료만 보고 결정한다. 가용성 점검의 ‘2020~2025 모두 충분한 18개 조합’을 사후 평가 대상 선정에 사용하지 않는다.
3. 직전 연도 비중, 직전 3년의 건수 가중 비중을 기준선으로 두고 단순 이항 회귀와 비교한다. 전년도까지의 비중·신규 인허가 수·업종·지역만 입력하며 목표 연도 실적은 입력하지 않는다.
4. 2015~2019 자료 품질을 먼저 점검해 초기 학습 가능 범위를 정한다. 이후 연도는 과거로 학습하고 다음 해를 평가하는 방식으로 순서대로 비교한다. 이미 2025 층수 집계를 확인했으므로 완전 봉인 시험이라고 주장하지 않는다.
5. 비중 오차(퍼센트포인트)를 지역·업종 칸별 동일 가중과 건수 가중으로 각각 평가한다. 개별 기록에 대한 확률 오차와 연도별 결과도 확인한다. 한 해 또는 특정 업종에서만 좋아진 결과로 전체 채택하지 않는다.
6. 복수 층·주소 불일치 제외 전후, 누락이 적은 표본, 세부 업종 구분에 따라 결론이 달라지는지 확인한다. 자료 부족 또는 기준선 대비 개선이 없으면 예측 도입 근거가 없다고 보고한다.

## 재현
저장소 루트의 service/.venv/Scripts/python.exe로 scripts/audit_floor_feasibility.py, scripts/audit_d05_floor_addresses.py를 실행한다. 읽기 전용 공유 DB 계정이 필요하다. 결과는 이 폴더에 저장한다. 운영 DB와 서비스 화면은 변경하지 않는다.
