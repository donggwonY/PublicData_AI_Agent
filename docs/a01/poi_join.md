# A-01 출구 300m 상가 결합 점검

학생 선택: 300m를 기준으로, 500m를 민감도 비교에 사용한다. 도보거리가 아닌 출구와 상가 간 구면 직선거리 근사다.

- 상가 원본 118,357행, 전체 컬럼 동일 중복 초과 673행. 원천 점포 ID가 없어 본 집계는 행 수로 표시하고 전체 동일 행 제거 결과를 병기한다.
- 환승역 호선을 묶어 87개 역 묶음으로 집계. 정평·임당·영남대는 대구 한정 POI 범위 밖이라 분석 제외 표시.
- 같은 역 여러 출구의 범위에 들어와도 같은 POI 행은 한 번만 집계. 역 사이 중복은 유지·계량하며 독립 표본으로 단정하지 않는다.
- 출구가 없는/이름 미확인 4항목은 0으로 넣지 않았다. 사월 등 경계 지역의 범위 완전성은 추가 확인 대상.
- 입력 해시, 분류별 합계와 총계, 300m⊆500m 검증 통과. 좌표계 datum·승하차 원천 관측연도·시점 정합성은 미확인.

## 역 사이 상권 겹침

| 반경 | 한 역 이상 포함된 POI 행 | 여러 역에 포함된 POI 행 |
| --- | ---: | ---: |
| 300m | 36,538 | 578 |
| 500m | 59,037 | 14,071 |
