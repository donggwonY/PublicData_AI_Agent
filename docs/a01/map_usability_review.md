# 카페 지도 사용성 — AI 검토

검토일: 2026-10-12. 사용자의 요청으로 현재 대화 AI가 수행했다. 김선경의 실제 사용 경험이나 만족도 응답으로 대체하지 않는다. 앞서 확인한 브라우저 지도 화면·선택 동작과 최종 지도 데이터/표시 코드를 근거로 검토했다. 이번에는 별도 사용자 테스트를 수행하지 않았다.

## 선택 주소: 대구광역시 동구 동부로 156

지도에 포함된 기록은 ‘마티네’다. 해당 기록 좌표에서 직선거리로 가장 가까운 출구는 보유 자료의 2번 출구이며, 약 170m이다. 도보 접근성·실제 영업 여부를 확인한 정보는 아니다.

| --- | --- | --- |
| 어느 출구 쪽인지 쉽게 알 수 있는가? | 선택 후에는 알 수 있음 | 상세 정보에 최근접 2번·170m가 표시되고 출구 번호와 색상 범례가 있음. 선택하지 않은 상태에서는 주변 점이 가까워 구분이 어려울 수 있음. |
| 주변에 카페가 모여 있는지 판단할 수 있는가? | 대략적인 분포는 알 수 있으나 제한 있음 | 앞서 확인한 화면에서 2번 출구의 동쪽·남동쪽에 여러 좌표가 보임. 다만 점 개수는 카페 기록 수와 다르며, 같은 좌표는 묶여 있음. |

## 핵심 문제

도로 형상은 있지만 도로명·주요 건물 이름이 없어 실제 장소를 찾기 어렵다. 300m 원은 있으나 거리 눈금이 없어 점 사이 거리를 즉시 비교하기 어렵다. 모든 위치의 기본 점 크기가 같아 여러 카페 기록이 있는 좌표를 단일 기록과 혼동할 수 있다. 숫자 표시는 있지만 지도에 익숙하지 않은 사용자에게 뜻이 충분히 명확하지 않을 수 있다.

‘주변에 모여 있다’는 시각적 관찰은 밀집도 통계나 경쟁 강도 검증이 아니다. 이 지도만으로 매출·창업 적합성·실제 이동 동선을 판단하지 않는다.

## 개선 우선순위

1. 확인된 도로명·주요 건물명을 배경에 표시해 주소와 실제 위치를 연결한다.
2. ‘점 위 숫자 = 같은 좌표의 카페 기록 수’ 범례를 지도 안에 표시한다.
3. 거리 눈금과 선택 위치에서 최근접 출구까지의 연결선을 표시한다. 선에는 직선거리라고 명시한다.

판정: **탐색용 초안으로는 사용 가능, 실제 위치 안내용으로는 개선 필요.** 개선사항은 이번 검토에서 제안했으며 구현 완료로 처리하지 않는다. 서비스 반영·실제 사용자 재평가도 미수행이다.

## 개선 반영 및 확인

위 판정 이후 사용자의 진행 요청에 따라 지도에 OSM 도로명과 건물명(신세계백화점 대구점·동대구터미널·파미에타운·아펠리체·대구 메리어트 호텔)을 추가했다. 지도 범위와 글자 겹침에 따라 일부 이름은 생략한다. 임의 위치가 아닌 OSM 도형을 투영하고, 이름이 도형에서 떨어져 배치되면 안내선을 표시한다. 배경 자료의 출처·조회일·해시는 [cafe_map_sources.json](cafe_map_sources.json)에 기록했다. OSM 이름은 현재 영업을 별도로 검증한 정보가 아니다.

100m 거리 눈금, 같은 좌표의 기록 수 범례, 선택 카페에서 최근접 출구까지의 직선 연결선도 추가했다. 좁은 화면에서는 선 위 거리 글자가 겹칠 경우 생략되지만 아래 상세 정보에 거리는 유지한다.

브라우저에서 일반 화면 및 390px 화면의 지도 표시를 확인했다. 동부로 156은 2번 출구 직선 약 170m, 동부로22길 9를 선택하면 상세 정보가 2번·112m로 바뀌는 것을 확인했다. 카페 기록은 41건·좌표 그룹은 23개로 유지됐다. 이는 구현·표시 검증이며 사용자 만족도 평가나 도보 안내 정확도 검증이 아니다. 서비스 반영과 사용자 재평가는 여전히 미수행이다.
