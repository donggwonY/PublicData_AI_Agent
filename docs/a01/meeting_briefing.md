# 데이터 결합·분석 브리핑

2026-10-15 · 김선경. 기존 로컬 산출물을 확인해 정리했으며 이번 문서 작성에서 원격 최신 상태나 원자료를 다시 조회하지 않았다.

## 회의에서 보여줄 순서

1. [결합 결과](poi_join.md): 역 출구 주변에 어떤 상가 기록이 들어오는지 집계.
2. [가설 분석](hypothesis.md): 역 이용량과 카페·간편식 비중의 관계 탐색.
3. [동대구역 출구 비교](dongdaegu_exit_cafes.md)와 [지도](cafe_map.html): 실제 상담 사례.
4. [후보 업종 비교](candidate_sectors.md): 회의에서 결정할 업종·범위.

## 어떤 데이터를 어떻게 연결했나

공식 출구 좌표, 역별 승하차, 대구 상가 정보를 사용했다. 승하차의 94개 역·호선 항목 중 90개를 출구 자료와 연결했다. 환승역을 묶으면 87개 역 묶음이며, 경산권 3개와 경계 범위 확인이 필요한 사월을 제외한 83개를 주 가설 비교에 사용했다. 역·호선 항목 수와 실제 역 묶음 수를 구분한다.

상가와 역에 공통 점포 ID를 붙인 것이 아니라, 출구와 상가의 좌표 간 직선거리로 300m 안의 기록을 골랐다. 500m도 비교했다. 같은 역의 출구 반경이 겹쳐도 상가 한 행은 한 번만 센다. 다른 역 사이의 중복은 따로 계량했다. 출구를 연결하지 못한 역은 상가 0건으로 처리하지 않았다.

## 핵심 결과

| 분석 | 결과 | 해석 |
| --- | --- | --- |
| 역 이용량과 카페 비중 | 83개 역, 300m 순위상관 0.035 | 이번 표본에서는 뚜렷한 단조 관계가 약함 |
| 역 이용량과 간편식 비중 | 같은 조건에서 0.344 | 양의 관계가 관찰되지만 원인이나 구매 수요를 확인한 것은 아님 |
| 동대구역 전체 | 300m 상가 732건 중 카페 42건 | 동일행 제거 시 전체 724건·카페 41건 |
| 동대구역 최근접 출구 배정 | 1번 3건·2번 21건·3번 18건 | 동일행 제거 시 2번 20건. 실제 이용 출구와 다름 |
| 위치 표현 | 카페 41건을 좌표 23개 그룹으로 표시 | 같은 좌표의 여러 기록을 한 점포로 오해하지 않도록 건수 표시 |

간편식의 이번 정의는 김밥/만두/분식·버거·토스트/샌드위치/샐러드·빵/도넛이다. 비중의 분모는 전체 상가 기록이다. 카페와 간편식을 합치면 300m 순위상관은 0.239다. p값이나 인과효과를 검증한 결과는 아니다.

시간대 후속 탐색도 있으나 발표의 주 결과와 구분한다. 환승역을 제외한 80개 역에서 간편식 비중과 17~20시 하차 비중의 순위상관은 0.399였다. 이는 실제 퇴근·식사 목적을 측정하지 않는다. 주거 원인 연구는 보류했다.

## 1분 발표문

저는 공식 역 출구 좌표와 승하차 자료, 대구 상가 데이터를 연결했습니다. 역 출구에서 직선거리 300m 안의 상가를 집계했고, 출구 범위가 겹치는 기록은 한 번만 세었습니다.

83개 역을 비교했을 때 역 이용량과 카페 비중의 관계는 거의 없었고, 간편식 비중에서는 양의 관계가 관찰됐습니다. 그래서 사람이 많으면 카페 비중도 높을 것이라는 가설을 그대로 받아들이기보다는 업종별로 구분해야 한다고 봤습니다.

이를 상담 예시로 구체화해 동대구역을 살펴보니 300m 안에 카페 기록이 42건, 동일행 제거 시 41건이었습니다. 카페 이름과 주소, 최근접 출구를 확인할 수 있는 지도까지 만들었습니다. 다만 현재 영업 점포 수나 매출을 확인한 결과는 아닙니다.

이제 팀에서 대상 업종과 포함 범위를 정하면 그 기준으로 데이터 정의를 맞추고 실제 AI 답변 평가를 진행하려고 합니다.

## 현재 한계와 상태

상가 설정 기준은 2026년 6월, 동대구역 출구 자료는 2024년 기준이다. 자료 시점 정합성·좌표계·최신 운영 상태 확인이 남아 있다. 역 간 공간 겹침도 있어 표본을 완전히 독립적으로 보지 않는다. 분석·지도는 오프라인 결과이며 서비스 도입과 실제 서비스 AI 평가는 미수행이다. 업종 비교표와 이 브리핑 문서는 아직 별도 커밋·푸시가 필요하다.
