## 범위와 증거

11/03 평가의 E1 지역 비교, E2 자리 이력, E3 생존 통계를 다시 대조했다. E1·E2는 11/05 대화에 제공됐고 E3는 11/07 제공됐다. 실제 실행 시각·응답 시간·질문별 새 대화 여부는 확인하지 않았다. 세 유형 모두 화면 모델은 `gemini-3.5-flash`이며 이전 `flash-lite`와 달라 개선을 프롬프트 변경만의 효과로 해석하지 않는다.

11/05 원격 deploy `7bfed8d`에 수정 `e98b4ef`가 포함된 것을 확인했다. 이는 개별 응답 실행 커밋·DB 버전 확인과는 다르다. 에이전트 직접 앱 실행이 아닌 사용자 캡처를 근거로 한다. 전체 원본 도구 JSON은 확보하지 않았다.

## 보완

`service/agent.py` 공통 응답 지침과 `service/core/tool_specs.py` 도구 설명을 보완했다.

1. 동시 영업 표시를 기록 기간의 중첩으로 설명하고 물리적으로 독립된 공간이라고 확정하지 않는다. 뒤의 현장 확인 안내로 앞의 단정을 상쇄하지 않는다.
2. 폐업 기록만의 평균 기간과 중도절단을 포함한 전체 코호트 KM 중앙값으로 직접 우열을 판단하지 않는다.
3. 지역 차이는 수치로 설명하고 검증되지 않은 중요성·유의성·입지 변수의 영향력 크기를 단정하지 않는다.

이는 응답 지침 보완이며 숫자 계산·데이터·모델 학습 변경은 아니다. 모델의 실제 준수는 배포 후 E1·E2 재평가가 필요하다. E3를 다시 반복할 필요는 없으며, 지도 설명 불일치 등 기존 범위 밖 미확인 항목도 해결로 처리하지 않는다. A-03 전체 완료 또는 서비스 전체 정확도로 일반화하지 않는다.
