# 근거 제공 상담 답변 생성 및 자체 검토

실행일: 2026-10-12. 답변 생성·검토 주체: 현재 Codex 대화의 동일 AI. 정확한 모델 버전은 확인되지 않아 기록하지 않는다. 별도 API 호출·독립 평가자·서비스 도구 실행은 없다.

제공 근거: `consultation_case.json`, `dongdaegu_exit_cafes.json`, `example_address_comparison.json`의 앞선 계산 결과와 [평가표](consultation_evaluation.md). 평가 기준을 이미 본 상태에서 작성했으므로 블라인드 평가가 아니다. 아래 결과는 답변 초안의 자체 점검이며 모델 정확도·통과율 추정에 사용할 수 없다.

환경 확인: 현재 프로세스의 GEMINI_API_KEY·ANTHROPIC_API_KEY 미설정, `service/.streamlit/secrets.toml` 없음. 비밀값을 출력하거나 운영 키를 가져오지 않았다. 서비스 모델 실행은 미수행으로 유지한다.

## 질문 1

동대구역 출구 주변 300m에 카페가 얼마나 있어? 500m로 넓히면?

### 생성 답변

보유 공식 자료의 동대구역 1·2·3번 출구에서 직선거리 300m 이내를 합치면 카페 기록은 42건입니다. 500m에서는 72건입니다. 여러 출구의 반경에 겹쳐 들어가는 기록은 한 번만 셌습니다. 완전히 같은 행을 제거하면 각각 41건과 70건입니다.

카페는 상가 자료의 소분류가 정확히 ‘카페’인 기록입니다. 상가의 설정 기준은 2026년 6월, 출구 자료 기준은 2024년 8월 26일입니다. 도보거리가 아니며, 현재 영업하는 고유 점포 수를 확인한 결과도 아닙니다. 같은 행을 제거해도 고유 점포 여부가 검증되는 것은 아닙니다.

### 자체 검토

| 필수 기준 | 판정 | 답변 근거 |
| --- | --- | --- |
| 두 반경의 올바른 수치 | 충족 | 42·72, 동일행 제거 41·70 |
| 합집합과 겹침 처리 | 충족 | 출구 범위를 합치고 겹치는 기록은 한 번 계산 |
| 시점·거리·기록 한계 | 충족 | 설정 기준일, 직선거리, 고유·현재 영업 미검증 명시 |

## 질문 2

300m 범위의 카페를 가장 가까운 출구에 하나씩 배정하면 어느 출구 쪽에 많아?

### 생성 답변

보유한 1·2·3번 출구의 300m 범위 안 카페 기록을 가장 가까운 출구에 한 번씩 배정하면 2번 21건, 3번 18건, 1번 3건입니다. 완전히 같은 행을 제거하면 2번만 20건으로 줄고 나머지는 같습니다. 2·3번 쪽에 많이 분포하며 2번이 3번보다 조금 많습니다. 통계적으로 유의한 차이를 검증한 것은 아닙니다.

이 수치는 각 출구 반경을 따로 센 1번 34건·2번 39건·3번 40건과 다릅니다. 출구별 반경은 서로 겹치지만 최근접 배정은 각 기록을 한 출구에만 배정합니다. 실제 보행 동선이나 고객이 이용한 출구를 측정한 결과는 아닙니다.

소분류 ‘카페’ 기록의 직선거리 계산이며, 상가 설정 기준은 2026년 6월, 출구 자료 기준은 2024년 8월 26일입니다. 현재 영업 중인 고유 카페 수나 출구 운영 상태를 확인한 결과는 아닙니다. 동일행 제거도 고유 점포 확인은 아닙니다.

### 자체 검토

| 필수 기준 | 판정 | 답변 근거 |
| --- | --- | --- |
| 최근접 배정 수치·순서 | 충족 | 2번 21, 3번 18, 1번 3 |
| 출구별 반경 집계 구분 | 충족 | 34·39·40과 배정 수의 정의를 구분 |
| 동선·유입·유의성 과장 금지 | 충족 | 측정·검증하지 않았다고 명시 |
| 자료 한계 | 충족 | 기준일·직선거리·고유 점포 미검증 명시 |

## 질문 3

동부로22길 9와 동부로 149의 주변 카페 수를 비교해 줘. 카페가 적은 쪽에 창업하면 더 유리할까?

### 생성 답변

분석용으로 고른 기존 카페의 좌표를 중심으로 직선거리 300m를 비교했습니다. 역 출구 중심의 집계와는 범위가 다릅니다. 완전히 같은 행을 제거한 카페 기록은 다음과 같습니다.

| 주소 | 300m 전체 | 같은 주소 | 같은 주소 제외 |
| --- | ---: | ---: | ---: |
| 대구광역시 동구 동부로22길 9 | 38 | 1 | 37 |
| 대구광역시 동구 동부로 149 | 43 | 11 | 32 |

전체 수에는 기준 카페도 포함합니다. 두 반경은 겹치므로 합산하지 않습니다. 같은 주소를 제외하면 수의 순서가 바뀌며, 이 방식은 같은 건물의 다른 경쟁 카페까지 제외할 수 있습니다. 따라서 어느 한 숫자를 그대로 실제 경쟁 점포 수라고 보기는 어렵습니다.

카페 수만으로 어느 쪽의 창업이 더 유리한지 판단할 수 없습니다. 두 주소는 분석용 예시로, 매물이나 공실을 확인한 곳이 아닙니다. 상가 설정 기준은 2026년 6월이고 소분류 ‘카페’ 기록을 사용했으며, 현재 영업 여부와 고유 점포 여부는 검증하지 않았습니다. 아직 해당 자리의 이력도 조회하지 않았습니다. 실제로 검토 중인 점포 주소와 층이 있나요? 그 정보를 받으면 자료 연결 여부부터 확인할 수 있습니다.

### 자체 검토

| 필수 기준 | 판정 | 답변 근거 |
| --- | --- | --- |
| 총수·같은 주소·제외 수 | 충족 | 38/1/37, 43/11/32 |
| 집계 중심 구분 | 충족 | 기존 카페 좌표 중심, 출구 중심과 다름 |
| 같은 건물 경쟁 제외 가능성 | 충족 | 같은 주소 제외 시 다른 경쟁 카페도 빠짐 |
| 성공·매출·매물 추정 금지 | 충족 | 유불리 판단 불가, 매물·공실 미확인 |
| 후속 주소·층 및 이력 상태 | 충족 | 주소·층 질문, 이력 미조회 명시 |

## 후속 검증

지도에 대해서는 사용자가 검토를 대신 수행해 달라고 요청하여 [별도 AI 사용성 검토](map_usability_review.md)를 작성했다. 동부로 156의 최근접 2번 출구·약 170m를 확인하고, 도로명·건물명 및 거리 눈금 부족을 개선점으로 기록했다. 사용자 본인의 만족도 응답으로 기록하지 않는다.

### 사용자 피드백 — 김선경

첫 답변의 요약문(300m 카페 기록 42건, 동일행 제거 41건, 직선거리 및 영업 상태 한계)을 검토하고, 사용자는 제시된 선택지 중 **2번: “카페가 어디에 있는지 지도나 위치가 필요하다”**를 선택했다. 이는 위치 정보의 필요성에 대한 피드백이며, 전체 답변의 정확성 검증이나 나머지 질문의 평가 완료를 뜻하지 않는다.

개선 항목: 동대구역의 보유 공식 1·2·3번 출구와 300m 범위의 카페 위치를 지도에 표시한다. 출구별 색상은 실제 이용 출구가 아닌 최근접 배정임을 설명하고, 반경·자료 기준일·동일행 제거 여부를 함께 표시한다. 같은 좌표에 여러 기록이 있으면 한 점을 한 점포로 오해하지 않도록 건수를 표시한다. 지도 초안을 제작했다. 동일행 제거 41건을 동일 좌표 23개 그룹으로 표시하고, 출구·300m 반경·공개 도로 배경 및 이름/주소 선택 기능을 포함했다. 브라우저에서 지도 표시와 선택 시 상세 정보 변경을 확인했다. 사용자 재검토는 아직 미수행이다.

세 답변의 필수 항목을 자체 검토해 충족으로 표시했다. 이는 평가 기준을 보며 작성한 초안 점검이다. 실제 서비스 모델 실행 결과는 모두 미수행이며 작업판의 평가 완료를 뜻하지 않는다.

서비스 실행 환경이 준비되면 질문과 근거만 제공하고 실제 응답을 저장한 뒤, 학생 또는 별도 평가자가 기준별로 판정한다. 역 출구 범위 조회 기능 미지원 여부와 근거 제공 시 답변 품질은 분리해서 기록한다.
